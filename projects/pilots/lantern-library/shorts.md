# Шортсы из главы 1: план

Делаются только после согласования ролика. Сейчас — выбор сюжетов и правила.

## Правила

- Каждый шортс — самостоятельный сюжет с началом и концом. Понятен без ролика.
- Текст диктора — только фразы сценария главы 1, без новых утверждений. У каждой фразы остаётся номер утверждения и источник.
- Голос — куски уже синтезированной главы. Нового синтеза нет, денег на голос шортсы не требуют.
- Вертикаль 1080×1920, 30 кадров в секунду. Тот же мир и те же вставки, кадр построен заново под вертикаль, не вырезан из горизонтального.
- Субтитры в кадре, крупно, в средней трети; плюс файл .srt.
- Длина 35–55 секунд; YouTube допускает до 3 минут. Без музыки, без резких звуков.
- В описании: строка о синтетическом голосе, источники, ссылка на полный ролик. В Studio шортс связывается с роликом через «Related video»: ролик должен быть публичным или по ссылке, функция — для аккаунта с расширенными возможностями.

## Сюжеты

1. «Why lighthouse lenses wore curtains by day».
   - Текст: сцена «Занавески», утверждения c24, c2, c25~, c26.
   - Кадр: линза за льняными занавесками, занавески снимают одну за другой.
   - Около 45 секунд.
2. «Lighting a lighthouse lamp in 1892: keep the flame low».
   - Текст: сцена «Зажечь лампу», утверждения c17, c30.
   - Кадр: лампа встаёт в центр линзы, спичка, низкое пламя, линза наполняется светом.
   - Около 50 секунд.
3. «One line a day: the lighthouse keeper's journal».
   - Текст: сцена «Ночь впереди», утверждения c11, c14, c27.
   - Кадр: журнал, перо пишет строку. Строка неразборчива: содержание настоящего журнала не утверждаем.
   - Около 45 секунд.
4. «The linen apron was for the glass».
   - Текст: сцена «Форма и фартук», утверждения c22, c23, c28.
   - Кадр: вешалка с пальто и фуражкой, фартук; утренняя чистка линзы.
   - Около 40 секунд.

Рекомендую первым шортс 2: в нём главное событие главы и самый тёплый кадр.

## Пакет каждого шортса

- Видео 1080×1920 и файл .srt.
- Название до 100 знаков, описание по образцу [пакета главы 1](upload/chapter-1.md#описание): одна фраза сюжета, «вы» — собирательный образ, синтетический голос, источники, ссылка на ролик.
- Обложка шортса — кадр из него; в YouTube её выбирают из кадров при загрузке.
- Инструкция загрузки — как у главы 1, плюс «Related video».

## Что нужно доделать в коде

- Мир и вставки рисуются в кадре 1920×1080. Для вертикали размер кадра передаётся параметром, камера ставится заново на каждый сюжет.
- Композиция «Short» берёт из таймлайна главы отрезок голоса и субтитров по номерам реплик.
