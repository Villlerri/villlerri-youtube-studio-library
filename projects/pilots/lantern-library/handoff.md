## С чего продолжить

1. Новой задаче нужен свой лимит на голос: около $3,49 по [расчёту](production.md#голос-elevenlabs), просить $4.
2. Восстановить код по [probe/code.md](probe/code.md), затем `bun install` в `probe/`.
3. Проверить, что голос подключён, без трат: запрос сведений о голосе через счётчик трат задачи должен вернуть 200.

   ```
   curl -s -o /dev/null -w '%{http_code}\n' -H 'xi-api-key: board-spend' \
     http://127.0.0.1:41806/spend/v1/<worktree>/voice/elevenlabs/v1/voices/nPczCjzI2devNBz1zQrb
   ```

4. Образцы трёх голосов — 4 212 знаков, около $0,76. Голоса: A — Brian, B — Bill, C — George.

   ```
   python3 -I tools/voice.py casting A=nPczCjzI2devNBz1zQrb B=pqHfZKP75CyOlXQDQS1a C=JBFqnCBsd6RMkjVDRZzb
   ```

5. После выбора: `names <VOICE_ID>` — 98 знаков; затем `chapter <VOICE_ID>` — 11 253 знака, около $2,03.
6. Сборка с голосом — по [probe/README.md](probe/README.md#глава-1-и-оформление-канала). Перерендер обязателен: таймлайн встаёт по меткам голоса.
7. Проверка `check.py`: звук около −20 LUFS, пик не выше −2 dBTP, голос над подложкой на 12–18 дБ.
8. После синтеза заменить расчётное время: субтитры .srt и главы в [описании](upload/chapter-1.md#описание).
9. Показать Villlerri пилот с голосом вместе с [оформлением канала](branding.md).
