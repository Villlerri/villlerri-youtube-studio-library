# Moving Atlas, пилот: канал Эри

Подготовка пилотного выпуска «Clinton's Ditch: How a Canal Made New York» для канала по концепции [Moving Atlas](../../../docs/channel-concepts/moving-atlas/index.md), вариант A: карта около 60%, вставки около 40%. Тему выбрал Villlerri 2026-10-15. Канал не создан, ничего не опубликовано. Подготовка — не согласие на серию.

Документы:
- [handoff.md](handoff.md) — записка для продолжения: что сделано, что осталось, с чего начать.
- [topic.md](topic.md) — выбор темы, причины, запасные темы.
- [facts.md](facts.md) — факт-лист: каждое утверждение сценария с источником и меткой достоверности.
- [script.md](script.md) — сценарий на английском и пояснение по-русски.
- [storyboard.md](storyboard.md) — раскадровка: что в кадре и что звучит, доля карты и вставок.
- [assets.md](assets.md) — материалы и права: паспорта вставок, данные карты, шрифты.
- [voice-and-sound.md](voice-and-sound.md) — текст и расчёт озвучки ElevenLabs, словарь произношения, план звука.
- [packaging.md](packaging.md) — заголовки и обложки выпуска.
- [branding.md](branding.md) — оформление канала: название и handle, описание, аватар, баннер, инструкция.
- [production.md](production.md) — сборка, замеры, бюджет, критерии качества.
- [code.md](code.md) — весь код папки `probe/` и как его восстановить.

Файлы:
- `probe/` — код пробы стиля, пилота, выпуска, обложек и ключевых кадров (Remotion и d3-geo). В проекте хранится в [code.md](code.md).
- `voiceover-en.txt` — текст для озвучки ElevenLabs: английский, по главам, без разметки. Строки заглавными — названия глав, их не читают.
- `pilot.mp4` — видео пилота, 3 минуты 50 секунд: начало, ключ и глава 1. Без звука и субтитров, время рассчитано под будущую озвучку. В git не хранится, собирается `probe/scripts/render.sh Pilot`.
- `episode-draft.mp4` — черновик полного выпуска, 14 минут 4 секунды: главы 1–6 и финальная заставка. Без звука и субтитров, время рассчитано под будущую озвучку. В git не хранится, сборка — [production.md](production.md).
- `style-probe.mp4` — проба стиля, 26 секунд, без звука. В git не хранится.
- `branding/` — аватар, баннер, знак в видео: PNG и SVG.
- `packaging/` — три обложки 1280×720.
- `frames/` — ключевые кадры выпуска. `episode-draft-sheet.webp` — 24 кадра черновика выпуска по порядку.
- `rights/` — снимки страниц источников с пометкой о правах на дату проверки.
