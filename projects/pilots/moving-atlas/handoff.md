## Что осталось

1. Настройка голосового маршрута студии. На 2026-10-28 17:33 UTC он отвечает 503 `voice_unconfigured`: «The board has no voice LiteLLM: set VOICE_LITELLM_KEY and VOICE_LITELLM_HOST in the board's voice-litellm.env». Настраивает администратор студии.
2. Образцы 3–5 голосов на одном абзаце — начале главы 3. Выбор автора.
3. Лимит трат новой задачи поднять до $4 с ответа автора.
4. Озвучка по главам, модель Multilingual v2, с метками времени символов. Словарь произношения проверить на слух.
5. Метки голоса — в `probe/src/narration.ts`; кадр перестраивается по ним. Проверка кадров, рендер по главам.
6. Звук: подложки Freesound, музыка YouTube Audio Library, −14 LUFS. Кандидаты не прослушаны. Ещё нужно найти копыта по грунту, гавань, деревянную лодку у причала.
7. Проверка готового видео и согласование автором.
8. После согласования — шортсы, пакеты выкладки, оформление канала.

## С чего продолжить

1. Восстановить `probe/` из [code.md](code.md), раздел «Как восстановить».
2. `cd probe && bun install`, затем `./scripts/fetch-data.sh`, `bun scripts/build-region.ts`, `bun scripts/build-region.ts east`, `bun scripts/profiles.ts`.
3. Проверить черновик кадрами: `./scripts/stills.sh 0,6897,11802,15813,18120,23025 out/check Episode`.
4. Проверить голосовой маршрут бесплатным запросом — списком голосов. Без платных проб.
5. Дальше — пункты 2–8 из «Что осталось».

Замеры на сервере с 4 ядрами и 7 ГБ памяти: рендер выпуска — около 73 минут, подгонка под голос — около 2 часов.
