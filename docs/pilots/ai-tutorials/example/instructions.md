# Как повторить пример

Нужно: лист в клетку, карандаш, игральный кубик. Для проверки скриптом — Python 3 без дополнительных пакетов. Время: около 15 минут вручную.

## Вручную

1. Перепишите три сообщения из [toy-text.txt](toy-text.txt).
2. Составьте таблицу «слово → следующее слово → счёт». Ставьте чёрточку за каждую пару внутри предложения. Должно выйти 8 строк, как в [pairs.csv](pairs.csv).
3. Напишите «Mom». Смотрите только на последнее слово. Если продолжение одно — допишите его.
4. После «the» три продолжения. Бросьте кубик: 1–2 store, 3–4 gym, 5–6 park. Допишите выпавшее слово.
5. Сверьте предложение с toy-text.txt. Есть там — верно, нет — ложно.
6. Повторите шаги 3–5 для «Dad» и «Sam». Все 9 возможных предложений — в [sentences.csv](sentences.csv): 3 верных, 6 ложных.
7. Экзамен — [exam.csv](exam.csv). Вопрос знаком, если «вопрос + ответ» есть в toy-text.txt целиком. Знакомы 3 вопроса.
8. Честная игрушка: на знакомые отвечает верно, на остальные — «не знаю». Счёт 3.
9. Угадывающая: на незнакомые бросьте кубик: 1–2 первый вариант, 3–4 второй, 5–6 третий. Посчитайте баллы по двум правилам:
   - верно +1, неверно 0, «не знаю» 0;
   - верно +1, неверно −1, «не знаю» 0.
10. Один бросок даёт один расклад из 27. Средние по всем раскладам — в [scores.csv](scores.csv): 4 и 2.

## Скриптом

1. Скопируйте код из раздела «Скрипт» в [check.md](check.md) в файл check.py рядом с папкой примера.
2. Запустите: `python3 check.py example`.
3. Скрипт перезапишет pairs.csv, sentences.csv и scores.csv и напечатает итоги. Они должны совпасть с выводом в check.md.

## Своя версия

Замените предложения в toy-text.txt и вопросы в exam.csv. Формат exam.csv: question, options через «|», answer. Ответ должен быть среди вариантов. Скрипт пересчитает всё сам.
