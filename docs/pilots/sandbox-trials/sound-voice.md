# План звука и голоса

Состояние на 2026-10-15, после официального прогона. Голос не синтезирован. Синтез — только ElevenLabs и только после отдельного разрешения Villlerri.

## Звук

Весь звук синтезируется кодом из журнала расчёта. Чужих записей нет, лицензий не нужно. Код: render/sound.ts.

- Удары. Каждое столкновение из журнала Box2D даёт короткий звук. Громкость — по скорости удара, высота — по размеру фигуры. ANVIL звучит металлом с долгим звоном. Удар фигуры о фигуру выше и суше удара о трассу.
- Панорама: удар слева в кадре звучит слева. Удары за кадром тише, далёкие не звучат.
- Качение: низкий гул, громкость следует за суммарной скоростью фигур в кадре.
- Гул арены: очень тихий фон, около −50 dBFS.
- Сигналы: лязг ворот на старте, мягкий щелчок при смене лидера, короткий сигнал на финише каждой фигуры, звон победителю.
- Громкость выпуска: −16 LUFS, истинный пик не выше −1 dBTP. В пробе измерено: −16,2 LUFS, пик −1,5 dBTP. В черновике без голоса: −17,3 LUFS, пик −1,0 dBTP. Общая громкость сводится к −16 LUFS при сборке с голосом.
- Экраны со статистикой: очень тихий фон комнаты, вход и выход за 0,3 с.
- Музыки нет. Если нужна: YouTube Audio Library без требования атрибуции, тихо под правилами и статистикой, никогда под заездом.

Не проверено на слух: я не слышу звук. Оценку звучания даёт человек по пробе стиля.

## Голос

- Роль: ведущий и «стол статистики». Сухой юмор, без крика комментатора.
- Где звучит: правила до старта, приглашение к прогнозу, 3–6 коротких реплик в заезде, итог, статистика после финиша.
- Где молчит: в потоке заезда между событиями и поверх фотофиниша.
- Реплика ставится на событие из журнала, а не событие подгоняется под реплику. Метки времени слов — из ответа ElevenLabs.
- Голос выбирается из стандартных голосов ElevenLabs. Американский английский, взрослый, тёплый, средний темп, ясные цифры.
- Голос закрепляется за каналом и дальше не меняется.

## Стоимость ElevenLabs

Цены — по карточке библиотеки, проверены 2026-10-14. Перед покупкой перепроверить.

- 1 знак текста = 1 кредит на моделях Multilingual v2 и v3.
- Starter: $6 в месяц, 30 000 кредитов, коммерческое право. По карточке: первый месяц $1 по акции до 18 октября 2026.
- Бесплатный тариф не годится: нет коммерческого права.
- API без подписки: $0,08 за 1 000 знаков, но коммерческое право в этом случае не проверено. Не рекомендую.

Расчёт по готовому сценарию Event 1:

- Текст: 18 реплик, 282 слова, 1 580 знаков. Файл voice-event-1.txt.
- При темпе 2,6 слова в секунду — около 108 секунд речи.
- Кредиты: 1 580 на один проход, 2 054 с запасом 30% на переозвучку. Это 7% месячного объёма Starter.
- Синтез идёт через учётную запись ElevenLabs студии и ограничитель трат задачи, лимит $1.
- По цене API без подписки, $0,08 за 1 000 знаков: $0,13 за проход, $0,16 с запасом.
- Шортсы: 805 знаков на три ролика, около $0,06 за проход. Нужно отдельное разрешение.
- Коммерческое право зависит от тарифа учётной записи студии. Для публикации нужен Starter или выше. Тариф студии агенту не виден.

Вывод: синтез пилота укладывается в лимит $1. Для публикации нужен платный тариф: месяц Starter — $6, или $1 по акции до 18 октября.
