# Источники и права на каждый материал

Состояние на 2026-10-15. Правила — по [проверке перед публикацией](../../../docs/asset-sources/publication-check.md) и [паспорту ассета](../../../docs/asset-sources/asset-passport.md). Это сведения из лицензий, не юридическая консультация.

Главное: в пилоте нет ни одного чужого кадра, звука или трека. Чужие файлы в видео — только два шрифта и, после отдельного разрешения, голос ElevenLabs.

## Что попадает в видео

1. Картинка: фигуры, трасса, плашки, таблица, обложки, аватар, баннер и водяной знак канала.
   - Чьё: наше. Нарисовано кодом пилота по утверждённому макету «Лиги» (задача 47).
   - Права: наши, лицензия не нужна.
2. Движение фигур.
   - Чьё: наш расчёт на движке Box2D 3.1.1.
   - Лицензия движка: MIT, Copyright 2022 Erin Catto, файл LICENSE в архиве исходников. MIT касается программы, а не видео.
   - Если код будет опубликован: приложить текст лицензии Box2D.
3. Звук: удары, качение, гул арены, сигналы.
   - Чьё: наше. Синтезирован кодом из журнала столкновений, без чужих записей.
   - Права: наши. Претензий Content ID на синтез ждать неоткуда, кроме случайного совпадения.
4. Шрифт Barlow Condensed (Medium, SemiBold, Bold).
   - Источник: репозиторий google/fonts, папка ofl/barlowcondensed, скачано 2026-10-15.
   - Лицензия: SIL Open Font License 1.1, Copyright 2017 The Barlow Project Authors. Текст лицензии сохранён рядом со шрифтом: assets/fonts/OFL-BarlowCondensed.txt.
   - Коммерческое использование: разрешено. Атрибуция в видео не нужна.
5. Шрифт JetBrains Mono (переменный).
   - Источник: репозиторий google/fonts, папка ofl/jetbrainsmono, скачано 2026-10-15.
   - Лицензия: SIL Open Font License 1.1, Copyright 2020 The JetBrains Mono Project Authors. Текст: assets/fonts/OFL-JetBrainsMono.txt.
   - Коммерческое использование: разрешено. Атрибуция в видео не нужна.
6. Голос диктора — пока не создан.
   - Источник: только ElevenLabs.
   - Условие: платный тариф на момент синтеза (Starter, $6 в месяц). Бесплатный тариф коммерческого права не даёт.
   - Голос: брать из стандартных голосов ElevenLabs. Для голосов из Voice Library действует отдельное приложение к условиям, оно не прочитано.
   - Синтез — только после отдельного разрешения Villlerri.
7. Музыка — в пилоте нет.
   - Если понадобится: YouTube Audio Library с фильтром "Attribution not required", паспорт на трек в день скачивания.
8. Официальное зерно: число из публичного раунда drand 6555429.
   - Чьё: открытые данные сети drand, опубликованы для всех.
   - Права: число — факт, лицензия не нужна. Имя drand на экране — только как указание источника.

## Инструменты, которые в видео не попадают

Их лицензии касаются программ, а не результата.

- @napi-rs/canvas 1.0.9 — рисование кадров, MIT.
- FFmpeg 7.0.2, статическая сборка из пакета ffmpeg-static 5.3.0 — кодирование видео. Сборка под GPL 3 с libx264. GPL касается программы, а не наших роликов. Сборку мы не распространяем.
- Bun 1.4.2, GCC 15.2 — запуск и сборка кода.

## Названия и товарные знаки

- Имена участников (ANVIL, PIP, BOUNCE и другие) — обычные английские слова. Проверка товарных знаков не делалась.
- Название канала Sandbox Trials: поиск 2026-10-15 не нашёл канала или бренда с таким именем, handle @SandboxTrials свободен на момент проверки. Юридическая проверка товарного знака не делалась. Подробнее — в документе «Оформление канала».
- Чужих логотипов, флагов, клубов, лиг и стран в кадре нет. Слово Plinko не используется.
