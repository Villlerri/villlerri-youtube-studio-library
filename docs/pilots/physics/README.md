## С чего продолжить

1. Разложить код из [code.md](code.md) по файлам в папку `prod/`. Каждый раздел `## путь` — один файл, блок кода — его текст. Скрипт ниже.
2. Набор стиля задачи 58 положить в `prod/kit/`, вырезки из `assets/p/` — в `prod/assets/p/`.
3. Шаги 2–8 раздела «Как пересобрать» в [code.md](code.md) дают тот же немой монтаж.
4. С голосом — по [плану подгонки](timing-plan.md), раздел «Что сделать, когда голос будет».
5. Голос — только ElevenLabs. Пробы — только после ответа автора.

```python
# usage: python unpack.py code.md prod
import re, pathlib, sys
src, out = sys.argv[1], pathlib.Path(sys.argv[2])
text = open(src, encoding='utf-8').read()
for path, _, body in re.findall(r'^## (\S+)\n\n.*?\n(`{3,4})\w*\n(.*?)\n\2$', text, re.S | re.M):
    p = out / path
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(body + '\n', encoding='utf-8')
```
