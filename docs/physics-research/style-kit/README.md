# Набор стиля: чёрная доска с фактурными вырезками

Стиль канала, принятый Villlerri 18.10.2026 ([подачи](../looks.md#чёрная-доска-фактурные-вставки-и-ролик-проба)). Здесь всё, чтобы пересобрать ролик-пробу и начать первый ролик в том же стиле. Сам ролик — в альбоме задачи 58 «Чёрная доска: ролик-проба».

## Что внутри

- [chalk-clip.html](chalk-clip.html): ролик-проба 60 секунд, 1800 кадров при 30 к/с. Страница отдаёт кадр по номеру через `window.renderFrame(i)`, таймлайн событий через `window.info()`.
- [common.css](common.css): общие стили и подключение шрифтов.
- [assets/p/](assets/p/): готовые вырезки с рваным краем: три котика и закат с МКС.
- [assets/passports.md](assets/passports.md): паспорта картинок: источник, лицензия, автор. Все CC0 или общественное достояние.
- [fonts/](fonts/): тексты лицензий OFL. Сами шрифты в docs не хранятся.
- [code.md](code.md): захват кадров, проверка обрезки, звук, подготовка вырезок.

## Как пересобрать

1. Шрифты: скачать с Google Fonts в `fonts/` под именами из `common.css`. Ролику нужны Caveat (мел) и Space Mono (подписи источников).
2. Код: перенести блоки из [code.md](code.md) в файлы. В них жёсткие пути: ffmpeg, chromium из Playwright и путь в `prep.py`. Поправить под новое место.
3. Таймлайн для звука: `bun capture2.mjs chalk-clip.html t.mp4 1800 --only 0 --png-dir pv`, строку `[info]` из вывода сохранить как `clip-events.json`.
4. Кадры и видео: `bun capture2.mjs chalk-clip.html clip-silent.mp4 1800 --png-dir frames`. Около 0,62–0,7 с на кадр, весь ролик 19–22 минуты.
5. Звук: `python clip_sound.py clip-events.json clip.wav` (numpy, scipy).
6. Сведение: `ffmpeg -i clip-silent.mp4 -i clip.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart clip.mp4`.
7. Проверка обрезки: `bun check-clip.mjs chalk-clip.html`. Каждые 5 кадров печатает выход текста и рисунков за край и наложения. За край могут выходить только вырезки, пока влетают и улетают.

## Правила стиля

- Чёрная доска, тонкий мел, бледные формулы только как фактура, не как объяснение.
- Вырезки: неровный край, бумажная кайма разной ширины, зерно, растр, сгибы, двойная тень, скотч.
- Числа в кадре посчитаны, не нарисованы на глаз.
- Мел дописывается до конца строки: ни одна буква и ни один рисунок не обрезаны. Проверять каждый ролик скриптом из пункта 7.
- Голос только ElevenLabs. В пробе голоса нет.
