# Wan (открытые видеомодели)

Семейство видеомоделей Alibaba. Открытые Wan2.1 и Wan2.2 (код и веса под Apache-2.0) можно запускать у себя. Новая Wan 3.0 (август 2026) вышла только через облако, без весов.

## Ссылки

- Официальный сайт: <https://wan.video>
- GitHub: <https://github.com/Wan-Video/Wan2.2> (также Wan2.1, Wan-Animate-2)
- Веса: <https://huggingface.co/Wan-AI/>
- Примеры, проверенные 2026-10-14:
  - [Thrilled to introduce Wan2.1-FLF2V-14B](https://www.youtube.com/watch?v=LlBwTUM7kt4) — канал Wan, анонс модели «первый и последний кадр». Ссылка открывается через oEmbed, содержание по названию.
  - [Wan2.2 README](https://github.com/Wan-Video/Wan2.2) — демо-ролики модели, список весов, команды запуска. Страница прочитана.
  - [Wan-Animate-2](https://humanaigc.github.io/wan-animate-2) — страница проекта (открылась), перенос движения на персонажа.

## Что реально получается

Опора: README Wan2.2 и Wan2.1, карточки весов на Hugging Face. Генераций я не запускал.

- Wan2.2: T2V-A14B и I2V-A14B (480p и 720p, архитектура Mixture-of-Experts), TI2V-5B (текст и картинка в видео, 720p, 24 кадра в секунду, размер 1280×704), S2V-14B (речь в видео, 480p и 720p), Animate-14B (замена и перенос персонажа). Первые записи README о Wan2.2 датированы 2025-07-28 (ComfyUI, Diffusers).
- Первый и последний кадр: отдельная модель Wan2.1-FLF2V-14B-720P (Apache-2.0, апрель 2025). Для Wan2.2 готового варианта в README я не нашёл. Это основной открытый способ бесшовного перехода между двумя картинками.
- VACE (Wan2.1): универсальная модель создания и редактирования видео. Подробности не читались.
- Ключевые кадры, камера: прямых параметров движения камеры нет, управление текстом. Эстетические метки (свет, композиция, цветовой тон) заложены в обучение Wan2.2.
- Wan-Animate-2 (2026-08-07, Apache-2.0 по значку лицензии в репозитории): персонаж из видео-образца, текстовое управление ракурсом, вариант Lite с задержкой «в реальном времени».
- Wan 3.0 (закрытая): по справочнику Runway 2–30 секунд, 480p–1080p, внешние референсы, родной звук. Описания Alibaba я не читал.
- Дальность и согласованность: длительность клипа — единицы секунд (Wan2.1 T2V-1.3B делает 5 секунд 480p), длиннее собирается из кусков. Согласованность между клипами не обещана.
- Вывод автора: подходит как локальный бесплатный источник вставок и экспериментов, особенно FLF2V. Требует серьёзной видеокарты и ручной настройки.

## Слабые стороны

- Видеопамять: A14B-модели на одной видеокарте требуют не менее 80 ГБ (с флагами `--offload_model`, `--convert_model_dtype`, `--t5_cpu` можно уменьшить, цены в скорости). TI2V-5B работает на 24 ГБ (RTX 4090). Wan2.1 T2V-1.3B — около 8 ГБ.
- Открытая линейка закончилась на Wan2.2: Wan2.5, 2.6, 2.7 и 3.0 по вторичным данным закрыты (Alibaba-страницу не читал).
- README заявляет лидерство среди открытых и закрытых моделей. Независимых проверок я не видел; физика и надписи не гарантированы (общий риск класса).
- Установка не выполнялась (по правилам этой библиотеки), конфликты версий CUDA и PyTorch не проверены.

## Сложность

- Для человека (4 из 5): Python, CUDA, веса десятки гигабайт, команда запуска с флагами или ComfyUI.
- Для агента (2 из 5): `generate.py` из командной строки с флагами размера, засева, подсказки; агент запускает, смотрит кадры, повторяет. Нужна машина с видеокартой.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): командная строка, многокарточный запуск (`torchrun`), интеграции с Diffusers и [ComfyUI](comfyui.md), проект DiffSynth-Studio (оффлоад слоёв, LoRA).
- Воспроизводимость (3 из 5): веса и код фиксируются версиями, есть `seed`. Результат на разных видеокартах и версиях библиотек может отличаться; детерминизм не проверялся.

## Платформа и оборудование

Linux (команды из README), Windows через [ComfyUI](comfyui.md) (в его README Wan 2.1 и 2.2 перечислены среди поддерживаемых моделей). Видеокарта NVIDIA: от 8 ГБ (1.3B) до 24 ГБ (5B) и 80 ГБ (A14B без оффлоада). Облако: Alibaba Cloud Model Studio и wan.video для Wan 3.0.

## Экспорт

- MP4 из `generate.py`. Wan2.2 TI2V-5B: 720p, 24 кадра в секунду; A14B: 480p и 720p.
- Альфа-канала нет.

## Стоимость

Проверено 2026-10-14 по README и [справочнику цен Runway](https://docs.dev.runwayml.com/guides/models/).

- Wan2.2 и Wan2.1 локально: бесплатно, оплачивается железо и электричество. Оценка стоимости 0.
- Wan 3.0 в Runway: от $0.05 в секунду (Prime от $0.068). Alibaba, по вторичным данным, берёт $0.05 / $0.10 / $0.20 за секунду на 480p / 720p / 1080p. Официальная страница цен не читалась.

## Лицензия и права

- Код: Apache-2.0 (репозиторий Wan2.2).
- Веса: Apache-2.0 (метка `license:apache-2.0` на карточке Wan2.2-I2V-A14B и Wan2.1-FLF2V-14B-720P в Hugging Face). Код и веса под одной лицензией, территориальных ограничений нет. Для Wan-Animate-2 заявлена Apache-2.0 в README.
- Результат: README Wan2.2 — «мы не заявляем прав на ваш контент». Вы отвечаете за применение: нельзя распространять контент, нарушающий закон, наносящий вред людям или раскрывающий личные данные.
- Метки происхождения: в README нет встроенного водяного знака. Раскрытие синтетических сцен для YouTube — на вас (см. [обзор класса](../classes/10-generative.md)).
- Wan 3.0 (закрытая): условия сервиса не читались.

## Когда брать и когда нет

- Брать: бесплатные эксперименты, переход между двумя кадрами (FLF2V), локальная генерация без отправки данных в облако, обучение LoRA.
- Брать как открытый запасной вариант, если закрытые сервисы закроются (пример [Sora](openai-sora.md)).
- Не брать: научные сцены с точной физикой и надписями; слабая видеокарта.
- Не брать, если нужна Wan 3.0: она платная и закрытая.
