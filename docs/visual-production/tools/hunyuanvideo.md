# HunyuanVideo

Открытые видеомодели Tencent. Текущая версия HunyuanVideo-1.5 (8,3 млрд параметров, ноябрь 2025) работает на потребительских видеокартах. Лицензия Tencent не распространяется на ЕС, Великобританию и Южную Корею и запрещает использовать результат за пределами разрешённой территории.

## Что реально получается

Опора: README HunyuanVideo-1.5 и HunyuanVideo, текст лицензии. Генераций я не запускал.

- HunyuanVideo-1.5: текст или картинка в видео (T2V, I2V), 480p и 720p, суперразрешение до 1080p отдельной сетью. 121 кадр по умолчанию, в примерах 24 кадра в секунду, то есть около 5 секунд на клип.
- Ускорения: 480p I2V step-distilled (8 или 12 шагов, до 75% быстрее на RTX 4090), кэш (deepcache, teacache, taylorcache), FP8, разрежённое внимание для 720p. Поддерживаются Diffusers, ComfyUI, LightX2V.
- Обучение: открыт код `train.py` с LoRA (запись от 2025-12-05).
- Первый и последний кадр, ключевые кадры, управление камерой: в README не нашёл. Вывод: открытая 1.5 хуже подходит для бесшовных переходов, чем Wan FLF2V или LTX-2.5.
- Согласованность, физика: README заявляет «согласованность движений», независимых проверок не видел. Общий риск класса.
- Звук: в описании 1.5 нет.
- Вывод автора: приемлемая открытая модель для вставок на среднем железе, но юридические ограничения делают её слабым выбором, если студия или аудитория в запрещённых регионах.

- П. 5(b): нельзя использовать результат для улучшения другой модели ИИ (кроме Tencent Hunyuan).
- Порог: если у лицензиата более 100 млн активных пользователей в месяц, нужна отдельная лицензия Tencent.
- Первая HunyuanVideo (2024) требует 45 ГБ видеопамяти (544×960, 129 кадров) или 60 ГБ (720×1280); рекомендуется 80 ГБ.
- Установка не выполнялась (по правилам библиотеки), совместимость не проверена.

## Сложность

- Для человека (4 из 5): Python, CUDA, веса, сложные флаги.
- Для агента (2 из 5): запуск `generate.py` из командной строки; агент проверяет кадры. Нужна машина с видеокартой.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): командная строка, Diffusers, ComfyUI, пакетные скрипты; в README есть переменные окружения для запуска.
- Воспроизводимость (3 из 5): `--seed` задаётся, веса фиксированы. Детерминизм на разных видеокартах не проверялся.

## Платформа и оборудование

Видеокарта NVIDIA с CUDA. Минимум 14 ГБ видеопамяти с выгрузкой модели (измерено с оффлоадом) для 1.5; быстрее при большем объёме. Сообщество: Wan2GP заявляет от 6 ГБ для 1.5. README требует операционную систему Linux и Python 3.10 или выше.

## Экспорт

MP4 через `export_to_video(..., fps=24)`. Разрешения 480p, 720p и 1080p (после суперразрешения). Альфа-канала нет.
