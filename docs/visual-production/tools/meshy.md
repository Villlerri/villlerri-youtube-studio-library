# Meshy

Облачный генератор 3D-моделей из текста и картинок: сетка, PBR-текстуры, авто-ригинг, готовые анимации. Последняя модель в API Meshy 7.1. Для видео — источник заготовок предметов, которые затем ставят в [Blender](blender.md) и снимают камерой.

## Что реально получается

Опора: документация API (text-to-3d), страница цен, условия. Генераций я не запускал.

- Текст в 3D и картинка в 3D. В API у стандартной генерации модели `meshy-6-lite`, `meshy-6`, `meshy-7.1` (`latest` = Meshy 7.1); `meshy-7` помечена устаревшей. Отдельная «Smart Topology» (`meshy-t2`) даёт чистую сетку; режим lowpoly выведут из работы 2026-10-30.
- Параметры: целевое число полигонов, ремеш, PBR-текстуры, `target_formats`: glb, obj, fbx, stl, usdz, 3mf.
- Дальше по пайплайну: AI-текстурирование готовой сетки, авто-ригинг скелета, анимация (600+ готовых движений на платных планах), плагины для Blender, Unity, Unreal, Godot, Maya, 3ds Max, Roblox.
- Агент и автоматизация: API, MCP-сервер, Skill для агентов, CLI («одна команда превращает подсказку или картинку в модель»).
- Для сцен: предмет, модель устройства, существо. Камеру, свет и сцену строят уже в 3D-пакете, поэтому непрерывность сцены, плавная камера и повторяемость обеспечивает Blender, а не Meshy.
- Вывод автора: быстрый путь от идеи предмета к сетке. Для точного устройства прибора или молекулы сетку придётся править и сверять с чертежом.

## Слабые стороны

- Геометрия «похожа», а не точна: научный объект с известными размерами и деталями надо проверять.
- Качество топологии и UV нужно смотреть руками; для анимации сетка может потребовать ретопологии.
- Бесплатные результаты принадлежат Meshy и идут под CC BY 4.0, нужна ссылка на Meshy.
- Meshy вправе использовать вводные данные и результаты клиентов (кроме Enterprise) для обучения и улучшения сервиса.
- Кредиты расходуются на повторы; платные «retries» ограничены.

## Сложность

- Для человека (2 из 5): веб-интерфейс, затем 3D-пакет для сцены.
- Для агента (2 из 5): API и MCP. Агент генерирует и скачивает модели (формат glb), затем собирает сцену скриптом в Blender; проверка геометрии по рендеру. Ключ и оплата — у человека.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): REST API, MCP-сервер, CLI, плагины. Пакетная работа ограничена кредитами и очередью.
- Воспроизводимость (2 из 5): закрытая модель, версии меняются. Скачанный glb фиксирован, повторная генерация даст иной результат.

## Платформа и оборудование

Браузер, приложение Meshy для телефона (на странице цен «Snap a photo, get a 3D model»), API. GPU не нужна.

## Экспорт

GLB, OBJ, FBX, STL, USDZ и 3MF (по параметру `target_formats`). PBR-текстуры. Анимированные и ригованные модели через отдельные шаги. Видео не производит.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://www.meshy.ai/pricing).

- Free: 100 кредитов в месяц, 1 параллельная задача, низкий приоритет, базовые функции, результаты под CC BY 4.0.
- Pro: $20 в месяц, 1000 кредитов (до 100 моделей), 10 параллельных, API и плагины, приватная лицензия.
- Premium: $40, 3000 кредитов (до 300 моделей), 30 параллельных. Ultra: $100, 8000 кредитов (до 800 моделей), 100 параллельных.
- Studio: $70 в месяц за пакет и $10 за место, 5500 общих кредитов.
- На страницах планов: скидка 50% на первый месяц для новых пользователей. Допкредиты со скидкой 20% на Pro.
- Пример расчёта: 20 предметов для ролика на Pro $20 — в пределах лимита 100 моделей. Оценка стоимости 1.

## Лицензия и права

- Код или программа: проприетарный сервис.
- Результат ([условия](https://www.meshy.ai/terms-of-use), редакция от 2026-09-19): на бесплатном плане Meshy владеет результатом и даёт его под CC BY 4.0 с указанием авторства. На платном плане клиент «владеет своим результатом» в той мере, в какой это допускает закон, и может держать данные приватными. Контент в публичном сообществе идёт под CC0. Meshy использует вводные данные и результаты (не Enterprise) для обучения и улучшения сервисов. Права на сторонние объекты во входных картинках — ваша ответственность.
- Метки: упоминаний водяных знаков и C2PA для 3D-файлов не нашёл.
- Ассеты в комплекте: бесплатные игровые ассеты и библиотека сообщества (CC0 для опубликованных в сообществе); условия отдельных ассетов не проверялись.

## Активность и зрелость

Зрелость (stable): частые релизы (Meshy 6, 7, 7.1, Smart Topology `meshy-t2`), условия обновлены 2026-09-19, есть агент, MCP, плагины. Развивает компания Meshy. GitHub основного кода нет.

## Когда брать и когда нет

- Брать: быстрые заготовки предметов, персонажей и декораций для 3D-сцены, фон-реквизит, оживление через авто-ригинг.
- Брать на платном плане, если нужны права на результат без указания авторства.
- Не брать: точные научные модели (молекулы, приборы по чертежу), где важны размеры и топология: взять [Molecular Nodes](molecular-nodes.md) или строить в Blender.
- Не брать на бесплатном плане для коммерческого ролика без ссылки на Meshy.
