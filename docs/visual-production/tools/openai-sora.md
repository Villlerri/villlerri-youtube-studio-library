# OpenAI Sora

Видеомодели Sora 2 и приложение OpenAI. Официально подтверждено: 2026-03-24 OpenAI уведомила разработчиков, что Videos API и модели Sora 2 удаляются из API 2026-09-24. О закрытии потребительского приложения сообщают только вторичные источники. Карточка остаётся как предупреждение: опереться на этот сервис в API нельзя.

## Ссылки

- Официальный сайт: <https://openai.com/sora> (сайт отдаёт ботам 403, содержимое не проверено).
- GitHub: открытого кода нет.
- Документация (с пометкой о закрытии): <https://developers.openai.com/api/docs/guides/video-generation>
- Уведомление о выводе из эксплуатации: <https://developers.openai.com/api/docs/deprecations> (запись «2026-03-24: Sora 2 video generation models and Videos API»).
- Примеры: рабочих официальных примеров для проверки нет, сервис закрыт. Историю закрытия подтверждает [Engadget](https://engadget.com/ai/openai-is-shutting-down-its-sora-video-generation-app-211023358.html) (вторичный источник, дополнение).

## Что реально получается

Опора: архивная страница документации, оставленная «для истории». Генераций я не видел.

- Бывшие возможности API: `sora-2` (скорость) и `sora-2-pro` (качество, 1080p). Длительность 16 и 20 секунд на генерацию, продление до 20 секунд каждый раз, до шести раз, итог до 120 секунд.
- Картинка как первый кадр (`input_reference`, размер должен совпадать с целевым). Правки через endpoint edits, «персонажи» (короткие клипы 2–4 секунды как повторяемые объекты).
- Запрещались реальные люди, защищённые авторским правом персонажи и музыка, изображения с лицами людей на входе.
- Для библиотеки: сцена, вся логика которой зависит от одного закрытого сервиса, рискует остаться без инструмента. Хранить исходные кадры и подсказки отдельно, не привязывать пайплайн к одной модели.

## Слабые стороны

- Сервис закрыт: «The Sora 2 models and Videos API were shut down on September 24, 2026 and are no longer available. No one-to-one replacement API is available.»
- По вторичным данным OpenAI назвала причиной нехватку вычислений и смену приоритетов; команда Sora переключилась на исследования симуляции мира.
- Сторонние агрегаторы, которые обещают «Sora 2», не проверялись.
