# ElectroMag Nodes

Набор групп узлов Geometry Nodes для Blender, который считает электрическое и магнитное поле по сетке или кривой и рисует результат: силовые линии, плоскость модуля поля, сетку стрелок, объёмное поле векторов. Автор — Sam Aldhaher (Samer Aldhaher). Продаётся на Superhive (бывший Blender Market). Проект подтверждён первоисточником.

## Что реально получается

- Считает электрическое поле, потенциал и магнитное поле в любой точке 3D-пространства, включая внутри проводников (с ограниченной точностью, по словам автора).
- Типы показа: линии поля, плоскость модуля поля, сетка стрелок, объёмное поле векторов. Всё внутри Blender, поэтому доступны его камера, свет, материалы и анимация.
- Электростатика работает на подразделённой сетке (до 1500 вершин) в приближении заряда на поверхности проводника. В версии Lite заряд распределён равномерно, что верно для формы, близкой к шару. Версия Pro считает неравномерное распределение, ёмкость и самоиндукцию.
- Магнитостатика работает только на кривых: линейные токи нулевой толщины, постоянный ток и низкие частоты, катушки без сердечника.
- Применения, которые автор называет в описании: индукционный нагрев, беспроводная передача энергии, RFID, двигатели на печатной плате, катушки Тесла.
- Сквозной пример (магнит на холодильнике): не подходит. Постоянных магнитов в модели нет, есть токи на кривых и заряды на поверхностях; железа и взаимодействия объектов нет («существует в свободном пространстве»). Полосатый магнит считают в [magpylib](magpylib.md), а в Blender показывают импортированные данные или линии, построенные по рецепту из [blender-geometry-nodes](blender-geometry-nodes.md).
- Для видео: непрерывная сцена и камера дают сам Blender. Поле пересчитывается узлами, поэтому его параметры (ток, форма катушки, положение заряда) можно плавно анимировать, а линии поля при этом деформируются вместе с объектом. Рисования линий по ходу рассказа в готовом виде нет: рост линии придётся строить отдельно, например через параметр длины кривой.

## Слабые стороны

- Автор честно пишет, что это «начальная версия» и «ни в коем случае не полноценный решатель, не замена профессиональным решателям».
- Нет магнитных материалов, постоянных магнитов, сил, сопротивления. Электростатика не считает сил.
- Нельзя экспортировать результаты: в вопросах и ответах «пока нет, возможно в будущем».
- Сетка электростатики не больше 1500 вершин. Рекомендуется 16 ГБ памяти и больше.
- Документация короткая, одна страница. Объёмного руководства для агента нет.
- Один автор. Дата последнего обновления на странице не указана.

## Сложность

- Для человека (3 из 5): нужны Blender и Geometry Nodes, понимание допущений решателя. Автор предупреждает, что первое применение скорее всего даст неверный результат.
- Для агента (3 из 5): Blender управляется Python-скриптами (см. [blender](blender.md)), параметры узлов можно задавать кодом. Но группы узлов поставляются как файл `.blend` и их внутренняя схема публично не описана, а настройку приходится сверять по картинке.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): Blender запускается без окна и рендерит из командной строки; значения входов модификаторов Geometry Nodes доступны из Python. Описания входов узлов в документации на странице продукта нет.
- Воспроизводимость (3 из 5): результат хранится в двоичном `.blend`. Расчёт детерминирован, но зависит от версии Blender (на странице указана 5.1).

## Платформа и оборудование

Blender на Linux, macOS, Windows. На странице указана версия Blender 5.1. Автор советует 16 ГБ памяти и более, мощная видеокарта в большинстве случаев не нужна.

## Когда брать и когда нет

- Брать: наглядные линии поля вокруг катушек, зарядов и проводников внутри Blender, когда нужна красивая картинка и дешёвый готовый набор; учебные сцены по электромагнетизму.
- Не брать: постоянные магниты и железо ([magpylib](magpylib.md), [femm](femm.md), [elmer-fem](elmer-fem.md)); точный инженерный расчёт; сцены, где нужен готовый экспорт данных или API для агента.
- Бесплатная альтернатива — собрать линии поля самим в Geometry Nodes по уроку из [blender-geometry-nodes](blender-geometry-nodes.md).
