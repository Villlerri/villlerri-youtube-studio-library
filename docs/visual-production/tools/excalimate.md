# Excalimate

Независимый проект по анимации рисунков Excalidraw: полноценный редактор Excalidraw в браузере, поверх него таймлайн с ключами (прозрачность, положение, масштаб, поворот, прогресс рисования), анимация камеры и экспорт в MP4, WebM, GIF, анимированный SVG и Lottie. Есть MCP-сервер, через который ИИ-агент создаёт рисунок и анимирует его. Проект существует и подтверждён первоисточником (репозиторий excalimate/excalimate, автор в лицензии — David Szakacs). К команде Excalidraw отношения не имеет: в README указано, что построен на Excalidraw и вдохновлён excalidraw-animate.

## Что реально получается

- Рисунок «от руки» в стиле Excalidraw оживает: блоки появляются, стрелки прорисовываются, подписи входят по очереди, камера плавно переезжает от одной части схемы к другой. Это та же идея «рисования вживую» и пошагового объяснения, что у [videoscribe](videoscribe.md), только на схеме Excalidraw, без руки.
- Три рабочих режима: Magic (быстрая авто-анимация и шаблоны), Sequence (список действий с простыми временными метками «после предыдущего», «вместе с предыдущим»), Studio (дорожки по элементам и ключи вручную).
- Плавные переходы между состояниями: можно сохранить состояние схемы, изменить её, сохранить следующее и создать переход (Smart Transition). Исчезнувшие элементы затухают, вернувшиеся появляются, группы и подписи следуют за своими контейнерами. Это ближе всего к непрерывной сцене: элементы остаются те же, меняется их положение и видимость.
- Камера: панорама, масштаб, поворот по ключам, блокировка соотношения сторон.
- Экспорт в 8 форматов: MP4, WebM, GIF, анимированный SVG, dotLottie, Lottie JSON, PNG, WebP. Рендер идёт в браузере (WebCodecs для MP4 и WebM, gif.js для GIF). Лёгкий формат dotLottie и SVG годятся для веб-вставок, для YouTube берётся MP4.
- Для агента: 35 MCP-инструментов (по README; на лендинге написано 23, цифры в документации расходятся). Действие-ориентированный набор: `auto_animate`, `apply_animation_preset`, `upsert_action_sequence`, `create_camera_move`, и «сырые» ключи. Есть 16 готовых навыков для агента (блок-схемы, архитектура, диаграммы последовательностей, объясняющие анимации и другие).
- Живой режим: агент меняет схему, браузер показывает изменения по SSE, так что результат виден сразу.
- Зашифрованная публикация ссылкой (ключ в части адреса, сервер не видит содержимое).

Чего нет в описании: озвучки и звуковой дорожки, меток по голосу, формул (кроме текста), реальной съёмки. Синхронизация с голосом выставляется по времени вручную или кодом.

## Слабые стороны

- Молодой проект: пакет в npm создан в марте 2026, версия приложения 0.5.1 от 2026-07-23. API меняется (в документации есть раздел миграции V1 в V2).
- Автор честно пишет в README, что значительная часть кода написана с помощью ИИ и «чистка и исправление ошибок продолжаются, используйте осторожно».
- Лендинг и README расходятся в числе инструментов (23 против 35): документации стоит доверять не вполне.
- Экспорт идёт в браузере, командной строки для рендера нет. Агенту нужна автоматизация браузера или человек для кнопки «Export».
- В Lottie прорисовка линий, картинки и рисунки от руки превращаются в растр, прогресс рисования на них не сохраняется (документация предупреждает при экспорте).
- Стиль Excalidraw: «карандашный эскиз». Для канала про физику это либо плюс (живая доска), либо минус (нет глянца).
- Размер и качество кадра зависят от браузера (кодеки H.264, VP8, VP9 через WebCodecs). Проверка перед экспортом отказывается, если кодека нет.

## Сложность

- Для человека (2 из 5): рисунок в Excalidraw знакомый, анимация через Magic и шаблоны за минуты. Студия с ключами сложнее.
- Для агента (3 из 5): схему и анимацию агент собирает через MCP, тексты и стрелки генерирует сам. Но MP4 получается кнопкой в браузере (экспорт в браузере), живой просмотр требует открытой страницы с парным адресом. Часть работы руками или через управление браузером.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): MCP-сервер (`npx @excalimate/mcp-server`, HTTP на `127.0.0.1:3001/mcp` или stdio), навыки, сохранение контрольных точек. Командного рендера в файл нет.
- Воспроизводимость (4 из 5): проект V2 — JSON со схемой, анимация компилируется детерминированным ядром из действий; такой проект лежит под git. Сам файл видео зависит от кодека браузера.

## Платформа и оборудование

Приложение — статичная страница, работает в современном браузере с WebCodecs, ничего ставить не нужно. MCP-сервер: Node.js, Linux, macOS, Windows. Видеокарта не обязательна.

## Экспорт

MP4, WebM, GIF, анимированный SVG (CSS-ключи или SMIL), dotLottie, Lottie JSON, PNG, WebP. Разрешение и частота кадров проверяются перед рендером (размер в пикселях, FPS, память). Пример из документации: 1920×1080, 30 кадров в секунду, 10 секунд, H.264 — пиковая память около 33 МБ по оценке. Прозрачность и звук документация не описывает.

## Когда брать и когда нет

- Брать: объяснение процессов и схем в стиле доски, где важны пошаговое появление блоков и стрелок; быстрый черновик для агента через MCP; лёгкие SVG и Lottie для веба.
- Не брать: сцены с формулами и точной математикой ([manim-ce](manim-ce.md)); непрерывная трёхмерная сцена ([blender](blender.md)); если нужен серверный рендер без браузера или зрелый инструмент с большой экосистемой ([excalidraw](excalidraw.md) с анимацией по ссылке, [remotion](remotion.md)).
