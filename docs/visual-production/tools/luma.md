# Luma Dream Machine

Видеостудия Luma AI. Собственная линейка Ray (текущая Ray3.2 от 2026-06-09) и чужие модели в том же аккаунте: Kling, Veo 3.1, Seedance, MiniMax H3, Flux 3.

- Официальный сайт: <https://lumalabs.ai>
- GitHub: открытого кода нет.
- Документация: старый API Ray 2 <https://docs.lumalabs.ai/docs/video-generation>, новый API Ray3.2 вынесен в «Luma Agents API» (<https://docs.agents.lumalabs.ai/>, по ссылке с первой страницы; сам он не читался).

  - [Luma Skills Demo: Reusable AI Creative Workflows](https://www.youtube.com/watch?v=5lA_fl6wzeY) — повторно используемые цепочки действий. Содержание по названию.
  - [Анонс Ray3.2](https://lumalabs.ai/news/introducing-ray-3-2) — страница прочитана, перечень функций ниже взят отсюда.

## Что реально получается

Опора: анонс Ray3.2, страница цен, документация Ray 2. Генераций я не запускал.

- Ray3.2: ключевые кадры до 16 штук в одном клипе (раскладка по секундам, «хореография» плана), клипы до 20 секунд в 1080p, HDR и 16-битный EXR, Reframe (смена формата, расширение кадра, замена фона), перенос исполнения актёра с отслеживанием до 8 лиц.
- Бесшовные переходы: в документации Ray 2 есть первый и последний кадр (`frame0`, `frame1`), продление вперёд и назад («reverse extend»), продление с заданным конечным кадром и склейка двух сгенерированных роликов (`interpolate`). Для нового API Ray3.2 то же не проверено.
- Камера: в API Ray 2 список «concepts» с готовыми приёмами камеры (пример `dolly_zoom`). Новый список не читался.
- Зацикливание: параметр `loop`.
- Постоянство объекта: ключевые кадры и реплики актёра сохраняют внешний вид в пределах одного клипа. Стабильность между клипами в источниках не описана.
- Другие модели: Kling 3.0 и Omni, Veo 3.1, Seedance 2.0 (до 4K) и 2.5 (до 1080p), MiniMax H3, Flux 3 видео, Gemini Omni Flash. Все видны в таблице цен.
- Вывод автора: за счёт 16 ключевых кадров и EXR Luma ближе остальных к управляемой покадровой работе. Для научных сцен действует общий риск физики класса.

## Слабые стороны

- Прайс на странице цен не показывает бесплатного плана; бесплатного Luma в источниках нет, условия «Free Use» в договоре есть.
- Кредиты быстро кончаются: Ray3.2 в 1080p стоит 400 кредитов за 5 секунд (SDR). HDR дороже в 2 раза, HDR с EXR в 3.
- По условиям Luma получает вечную лицензию на ваши входные данные и результаты, в том числе для обучения моделей, даже при платной подписке.
- Старая документация API помечена как устаревшая; актуальный API нужно искать по ссылке.

## Сложность

- Для человека (2 из 5): веб-интерфейс, ключевые кадры расставляются мышью.
- Для агента (2 из 5): REST API с задачами. Агент готовит кадры, запускает и проверяет клипы. Ключ и оплату заводит человек.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): API, SDK на Python и JavaScript (по оглавлению документации), коллбэки, апскейл до 4K, добавление звука к генерации.
- Воспроизводимость (2 из 5): закрытая модель с новыми версиями (Ray2, Ray3, Ray3.14, Ray3.2 за год). Параметр `seed` в прочитанной документации не найден.

## Платформа и оборудование

Браузер. В условиях упомянуты «Remote Apps» (мобильные клиенты), их список не проверялся. Локального запуска нет.

## Экспорт

- MP4. Для Ray3.2 заявлены HDR и 16-битный EXR; EXR-последовательности стоят в 3 раза дороже базовой.
- Разрешения в таблице цен: Draft, 540p, 720p, 1080p; чужие модели до 4K (Kling Omni, Seedance 2.0). Ray 2 в старой документации: 540p до 4K.
- Альфа-канала в источниках нет.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://lumalabs.ai/pricing).

- Plus: $30 в месяц ($300 в год), 10000 кредитов, модели Luma и сторонние, указан пункт «Commercial use».
- Pro: $90 ($900), 40000 кредитов. Ultra: $300 ($3000), 150000 кредитов. Team и Enterprise по запросу.
- Ray3.2, SDR, текст или картинка в видео, на 5 секунд: Draft 20 кредитов, 540p 50, 720p 100, 1080p 400 (на 10 секунд 60, 150, 300, 1200). Ray3.14 в секунду: Draft 4, 540p 10, 720p 20, 1080p 80.
- Примеры из таблицы: Veo 3.1 140 или 280 кредитов в секунду (без звука и со звуком), Kling 3.0 30–147, Seedance 2.5 36–191, Gemini Omni Flash до 370 кредитов за клип.
- Пример расчёта: на Plus 10000 кредитов = около 25 клипов по 5 секунд Ray3.2 в 1080p или 100 клипов по 5 секунд в 720p. Оценка стоимости 2.

## Лицензия и права

- Код или программа: проприетарный сервис.
- Результат ([условия](https://lumalabs.ai/legal/tos), редакция от 2026-05-14): клиент владеет результатом, Luma передаёт все свои права. Но использовать результат в коммерческих целях можно, «только если результат создан в период действующей платной подписки, допускающей коммерческое использование». Значит, результат, созданный без подписки, для коммерции не годится. Luma вправе встраивать водяные знаки, учётные данные контента и метаданные происхождения; удалять и обходить их запрещено. Данные клиента Luma использует для обучения и во время платной подписки.
- Ассеты в комплекте: нет.
- Для YouTube реалистичные синтетические сцены нужно раскрывать в Studio (см. [обзор класса](../classes/10-generative.md)).

## Активность и зрелость

Зрелость (stable): Ray3 (сентябрь 2025 по вторичным источникам), Ray3.14 (январь 2026, заголовок на странице новостей), Ray3.2 (2026-06-09). Развивает Luma AI.

## Когда брать и когда нет

- Брать: покадровая работа с ключевыми кадрами, EXR и HDR для композитинга, переходы между роликами, быстрый выбор модели из десятка.
- Брать, если нужен коммерческий результат: только в период оплаченной подписки.
- Не брать: научные сцены с точной физикой, любые надписи и формулы в кадре.
- Не брать, если нельзя отдавать данные для обучения моделей Luma.
