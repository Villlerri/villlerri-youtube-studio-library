# Adobe Premiere (Premiere Pro)

Монтажная программа Adobe по подписке. На странице продукта Adobe 2026 года называет её «Premiere», в текстах релизов встречаются оба названия. Id карточки оставлен `premiere-pro`.

## Ссылки

- Официальный сайт: <https://www.adobe.com/products/premiere.html>
- GitHub: открытого кода нет.
- Документация расширений (UXP): <https://developer.adobe.com/premiere-pro/uxp/>
- Справка по скриптингу, поддерживается сообществом, не Adobe: <https://ppro-scripting.docsforadobe.dev/>
- Примеры, проверенные 2026-10-14 (ссылка открывается через oEmbed; содержание по названию):
  - [Premiere Pro: Harness the Power of Text-based Editing with James Bonanno](https://www.youtube.com/watch?v=4IjOOlhWAGo) — канал Adobe Live. Монтаж по тексту расшифровки.
  - [Morph Cut: советы Adobe](https://blog.adobe.com/en/publish/2015/06/18/morph-cut-tips-tricks-for-best-results) — статья 2015 года о склейке скачков в говорящей голове.

## Что реально получается

Опора: страница продукта, объявления о релизах 26.3 и 26.5, статья о Morph Cut.

- Монтаж по тексту (Text-Based Editing): страница продукта: «уточнять, переставлять и обрезать клипы как текстовый документ», расшифровка при импорте. В 26.5 добавлен Paper Edit: из выбранных строк расшифровки собирается черновая последовательность. Работает по речи, для озвучки полезно искать место реплики.
- Morph Cut: переход, скрывающий скачок в интервью. Adobe в 2015 году назвала условия: один говорящий, неподвижная камера, статичный фон. Вне условий результат «пятнистый». Для мультяшных и графических сцен не подходит. В текущей документации подтверждение не открылось (справка Adobe отдаёт 403).
- Object Masking (AI): выделение и трекинг объекта или человека, в 26.3 ускорен.
- Переходы и эффекты 26.3: Shape Dissolve и Magnify.
- Generative Extend (Firefly): продлевает клип, добавляет кадры и фоновый звук (страница продукта). Относится к генеративным методам.
- Generative Media Tool (26.5): видео и звуковые эффекты из текста внутри таймлайна. Требует облако и кредиты, условия не уточнены.
- Непрерывная сцена, морфинг объектов, рисование линий, камера в 3D: встроенных инструментов не нашёл. Для слоёв и анимации Adobe предлагает [After Effects](after-effects.md).
- Синхронизация с голосом: ручная по дорожкам. Автоматической привязки анимации к голосу не нашёл.

## Слабые стороны

- Только подписка. Нет Linux.
- Интеграция скриптов требует запущенного приложения и панели-расширения. Режим без интерфейса не найден.
- Расширения: с ноября 2025 Premiere перешла на UXP. ExtendScript, по справке сообщества, ещё поддерживается, плана удаления у Adobe нет (источник сообщества, не Adobe).
- Генеративные функции списывают кредиты.
- Intel-Mac: с версии 27.0 Adobe требует Apple silicon (по поисковой выдаче страницы Adobe, текст не открылся напрямую).

## Сложность

- Для человека (3 из 5): базовый монтаж за дни, продвинутый (маски, цвет, звук, проекты) недели. Оценка автора карточки.
- Для агента (4 из 5): API есть (Premiere DOM: последовательности, дорожки, клипы, маркеры, элементы проекта; UXP: файлы, сеть, оболочка), но работает внутри запущенного приложения. Экспорт через API на странице UXP не подтверждён. Агент пишет плагин UXP, человек его ставит и запускает.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): UXP и ExtendScript, но без запуска из командной строки. Пакетный рендер вне GUI не найден.
- Воспроизводимость (2 из 5): проект двоичный и зависит от версии приложения и облачных функций. Результат генеративных шагов не повторяется.

## Платформа и оборудование

- Windows 11 24H2 или новее, macOS Sonoma 14 или новее, минимум 8 ГБ ОЗУ (по [странице Adobe о требованиях](https://helpx.adobe.com/premiere/desktop/get-started/technical-requirements/adobe-premiere-pro-technical-requirements.html), прочитано через поисковую выдачу: прямая загрузка дала 403).
- Linux не поддерживается (в требованиях его нет).

## Экспорт

## Когда брать и когда нет

- Брать: студия уже платит за Adobe или нужны Morph Cut и монтаж по тексту в одном окне.
- Не брать: агенту нужен код без интерфейса (выбрать [FFmpeg](ffmpeg.md), [MoviePy](moviepy.md)), Linux, или нет бюджета на подписку (выбрать [DaVinci Resolve](davinci-resolve.md)).
