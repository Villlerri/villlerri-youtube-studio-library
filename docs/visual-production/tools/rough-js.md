# Rough.js

Небольшая JavaScript-библиотека (меньше 9 КБ): рисует фигуры в «рукописном» стиле на Canvas или в SVG. На ней построен стиль Excalidraw. Анимации не умеет: она лишь превращает аккуратные фигуры в «неровные».

## Что реально получается

Опора: README, сайт проекта, вики.

- Линии, кривые, дуги, многоугольники, круги, эллипсы, SVG-пути «карандашом»: каждая фигура получает неровный контур, несколько штрихов.
- Заливки: hachure (штриховка, по умолчанию), solid, zigzag, cross-hatch, dots, sunburst, dashed, zigzag-line. Параметры: `roughness` (шероховатость, 0 даёт идеальную фигуру), `bowing`, `hachureAngle`, `hachureGap`, `fillWeight`, `strokeWidth`.
- Параметр `seed` (число) фиксирует случайные значения построения фигуры. Это делает вид фигуры воспроизводимым (вики).
- Рисование линий как процесс: библиотека не анимирует. Результат (SVG) можно вывести контурами через [Vivus](vivus.md) или через `stroke-dashoffset` в [GSAP](gsap.md). Такая связка из источников не подтверждена, это идея.
- Оживление «дрожащей» линии: менять `seed` каждые несколько кадров (идея, не проверено).
- Морфинг, камера, непрерывная сцена: библиотека не про это.
- Синхронизация с голосом: нет.

## Слабые стороны

- Развитие остановилось: последний выпуск 4.6.6 (2023-11-20).
- Анимации нет, видео нет.

- Рукописность только в линиях. Шрифты и компоновка остаются вашими.

## Сложность

- Для человека (2 из 5): несколько вызовов API на JavaScript. Оценка автора карточки.
- Для агента (2 из 5): агент пишет HTML и скрипт, результат проверяет кадром в браузере.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): код целиком. Рендер в видео через захват кадров браузера придётся добавить ([CCapture.js](ccapture-js.md), не проверялось).
- Воспроизводимость (4 из 5): текст под git, `seed` фиксирует случайность. Не 5, потому что результат Canvas зависит от браузера.

## Когда брать и когда нет

- Брать: как слой «неровных» линий поверх своей генерации схем.
- Брать: когда нужен «карандашный» стиль без Excalidraw.
- Не брать: если нужна готовая анимация рисования или инструмент для человека. Тогда [Excalidraw](excalidraw.md).
- Не брать: если нужна поддерживаемая библиотека. Придётся опираться на Excalidraw, использующий её же.
