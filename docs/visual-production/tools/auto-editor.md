# auto-editor

Консольная программа, автоматически вырезающая «мёртвые» участки из видео и звука, прежде всего паузы. Написана на Nim. Версия 31.7.2 от 3 октября 2026.

## Что реально получается

Опора: README проекта и страница сайта.

- Основной режим: анализ громкости. Участки тише порога вырезаются, порог по умолчанию `audio:threshold=0.04`, можно задать в дБ (`audio:-19dB`).
- Другие методы: по движению в кадре (`motion:threshold=0.02`), по субтитрам (страница сайта), комбинации через `or`.
- `--margin`: запас до и после реплики, по умолчанию 0,2 с. Чем меньше запас, тем резче склейки.
- Действия над метками: вырезать, ускорить, `pixelate` (в 31.7.0 анимируется).
- Экспорт таймлайна без перекодирования: XML для Premiere Pro, DaVinci Resolve, Final Cut Pro, Shotcut, Kdenlive, либо отдельными клипами. Дальше монтаж в [DaVinci Resolve](davinci-resolve.md), [Kdenlive](kdenlive.md) и других.
- В бинарниках 31.7.0 — whisper.cpp 1.9.4 и FFmpeg 9.0.2 (заметки выпуска).
- Для объясняющего ролика: чистка записи экрана, лекции или голоса от пауз. Непрерывной сцены, морфинга и рисования не делает.
- Синхронизация с голосом: работает по звуку, а не по тексту. Вывод автора: резка по паузам даёт скачки, которых канал хочет избежать. Применять к сырой записи, а не к финальной озвучке с продуманными паузами. Озвучка студии идёт через ElevenLabs, паузы там задаются заранее.

## Слабые стороны

- Резкие склейки: программа режет по порогу, без плавных переходов между фразами.
- Версия 30 и выше переписана, `pip` больше не публикует консольную программу (страница установки). На PyPI осталась старая 29.3.1.
- Бинарники не подписаны: система может показать предупреждение «Unknown developer» (страница установки).
- Не знает смысла сцены. Пауза для эффекта и пауза-брак для него одинаковы.

## Сложность

- Для человека (1 из 5): одна команда с несколькими опциями.
- Для агента (1 из 5): командная строка, результат проверяется длительностью файла и экспортом таймлайна (например, через `ffprobe`).

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): вся работа из командной строки, есть режим предпросмотра (`--when-active cut --when-inactive nil`), пакетный запуск скриптом.
- Воспроизводимость (4 из 5): те же параметры на ту же версию дают те же вырезы. Результаты версий 29 и 31 между собой не сравнивались.

## Платформа и оборудование

Windows, macOS, Linux. Официальные бинарники на странице релизов GitHub. Установка: Homebrew, AUR, из исходников (нужны nim, nimble, cmake, meson, ninja). Нужен ли отдельный FFmpeg для готовых бинарников, страница установки не говорит. Опционально yt-dlp для адресов.

## Экспорт

- Видео и звук после нарезки (кодирование через встроенные библиотеки FFmpeg).
- Таймлайны XML для Premiere Pro, DaVinci Resolve, Final Cut Pro, Shotcut, Kdenlive и клипы по отдельности.
- Параметры кодирования для YouTube см. [FFmpeg](ffmpeg.md). Какие контейнеры пишет сам auto-editor, не проверено.

## Когда брать и когда нет

- Брать: быстро почистить сырую запись, экспортировать таймлайн в редактор для ручной доводки.
- Не брать: чтобы монтировать финальный ролик «на автомате». Скачки между фразами портят плавность.
- Не брать как инструмент озвучки или графики.
