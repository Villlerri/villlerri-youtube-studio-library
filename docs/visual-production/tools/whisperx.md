# WhisperX

Распознавание речи с метками времени для каждого слова. Сначала Whisper распознаёт текст, потом выравнивание по фонемам (wav2vec2) уточняет границы слов. Отдельного сайта нет, проект живёт в репозитории.

## Что реально получается

- Слова с началом и концом. Результат — JSON с сегментами, внутри слова с `start`, `end`, у `--return_char_alignments` ещё символы. Из такого JSON строят ключевые кадры «на слове» для [Remotion](remotion.md), [Motion Canvas](motion-canvas.md) или Manim.
- Субтитры. Готовые SRT и VTT, с флагом `--highlight_words` подчёркивает слово в момент звучания. ASS-вывод убрали в версии 3 (отмечен в списке дел README).
- Скорость. Пакетный режим: до 70-кратной скорости на модели large-v2, бэкенд faster-whisper. Для large-v2 с beam_size=5 нужно меньше 8 ГБ видеопамяти.
- Диаризация. Разметка говорящих через pyannote: нужен токен Hugging Face и согласие с условиями модели `speaker-diarization-community-1`. Для монолога диктора не нужна.
- Русский. В код вшита модель выравнивания для `ru` — `jonatasgrosman/wav2vec2-large-xlsr-53-russian` (лицензия Apache-2.0 по странице модели). В списке языков, которые авторы проверили, русского нет (en, fr, de, es, it, ja, zh, nl, [EXAMPLES.md](https://github.com/m-bain/whisperX/blob/main/EXAMPLES.md)). Качество на русском не проверено.
- Роль в конвейере студии. Озвучку делает [ElevenLabs](elevenlabs.md), у него есть свои метки. WhisperX нужен для живой записи диктора, для независимой проверки меток и для готового аудио без сценария. Он работает локально и ничего не отправляет в облако.
- Непрерывность сцены, морфинг и камера — не его задача: инструмент даёт только времена.

## Слабые стороны

- Слова с цифрами и знаками (в README примеры «2014.» и «£13.60») не выравниваются и остаются без времени. В русском сценарии цифры лучше писать словами. Для остальных слов есть `--interpolate_method`.
- Распознаёт сам, а не сверяется со сценарием: слово из сценария может прийти с опечаткой. Выравнивание по готовому тексту через `whisperx.align` можно построить, но README такой режим не описывает.
- Нужна языковая модель выравнивания. Для языка без модели её ищут на Hugging Face и проверяют сами.
- Перекрывающаяся речь и диаризация обрабатываются слабо (README).
- Установка тяжёлая: CUDA 12.8, PyTorch, ffmpeg, Rust, токен Hugging Face для диаризации.
- Разработка идёт рывками: релиз 3.8.6 от мая 2026, в июне вышла предварительная 3.8.7rc1.

## Сложность

- Для человека (3 из 5): нужны Python, окружение с CUDA или терпение с процессором, правка JSON. Разовый запуск из командной строки проще.
- Для агента (2 из 5): запуск одной командой, результат JSON и SRT, агент сам проверяет монотонность времён и непокрытые слова. Руки нужны при установке CUDA и при выборе модели выравнивания для языка.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): командная строка и Python API, пакетная обработка, форматы JSON, SRT, VTT, TXT, TSV, AUD.
- Воспроизводимость (3 из 5): код открыт, версии закрепляются. Результат зависит от версии модели, точности вычислений (`float16`, `int8`) и железа, поэтому метки сохраняют в проекте и не пересчитывают заново.

## Платформа и оборудование

Linux, macOS, Windows. Python от 3.10 до 3.13 (PyPI). Видеокарта не обязательна: README даёт запуск на процессоре (`--compute_type int8 --device cpu`, в том числе для macOS), но на GPU заметно быстрее. Для GPU нужен CUDA 12.8 (Linux и Windows). Нужен ffmpeg.

## Экспорт

JSON, SRT, VTT, TXT, TSV и AUD (опция `--output_format`, по умолчанию все). Метки слов в JSON. Символьные метки включаются флагом.

## Стоимость

Проверено 2026-10-14 по README. Бесплатно. Модели Whisper и выравнивания скачиваются с Hugging Face, регистрация нужна только для диаризации. Облачный запуск на Replicate (ссылки в README) в проекте не использовался.

## Когда брать и когда нет

- Брать: для живой записи диктора, для независимой проверки меток ElevenLabs, для субтитров с пословным временем, когда есть видеокарта.
- Не брать: когда нужно строго выровнять готовый сценарий без распознавания. Тогда смотри [Montreal Forced Aligner](montreal-forced-aligner.md) и Forced Alignment API в [ElevenLabs](elevenlabs.md). Не брать на слабом процессоре для длинных роликов.
