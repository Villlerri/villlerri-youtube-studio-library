# ComfyUI

Графический узловой конструктор конвейеров генеративных моделей: картинки, видео, звук, 3D. Рабочая схема (workflow) сохраняется как JSON, поэтому конвейер можно держать в git, повторять и запускать из кода. Сама не генерирует: исполняет модели Wan, LTX, HunyuanVideo, FLUX и десятки других.

## Что реально получается

Опора: README репозитория, документация по формату JSON, страница цен облака. Установка не выполнялась.

- Видео: README перечисляет Wan 2.1 и 2.2, LTX-Video 2 и 2.3, HunyuanVideo 1.5, Kandinsky 5 Video, CogVideoX, Cosmos Predict2, Mochi; аудио и видео: MiniMax H3 и LTX-AV. Первый и последний кадр, ключевые кадры зависят от модели (см. [Wan](wan.md), [LTX-Video](ltx-video.md)).
- Изображения и правка: Stable Diffusion 1.5, SDXL, SD3.5, FLUX.1 и FLUX.2, Qwen Image, Flux Kontext, Qwen Image Edit и другие.
- 3D: Hunyuan3D 2.1 и другие (в списке README). Платные «Partner nodes» дают доступ к закрытым моделям (Nano Banana, Seedance, Hunyuan3D и т. д.) через облако Comfy.
- Объединение инструментов: одна схема связывает генерацию кадров, анимацию, апскейл, маски и экспорт. Для сцены, где нужна непрерывность, это место, где можно связать FLUX (кадры), Wan FLF2V (переход между ними) и апскейлер.
- Воспроизводимая схема: workflow JSON (формат описан схемой версии 1.0 в документации), сид внутри схемы, PNG и другие поддержанные результаты хранят схему и сиды внутри файла («Dragging a generated png on the webpage… will give you the full workflow including seeds»).
- Автоматизация: локальный API, режим App Mode (упрощённый интерфейс поверх сложной схемы), Comfy CLI, Comfy Agent (по странице Comfy строит схемы в ComfyUI по описанию).
- Вывод автора: лучший «станок» для открытых моделей, если агент и человек должны повторять цепочку. Качество определяют модели, а не ComfyUI. Оценка качества 4 условная: потолок задают лучшие подключённые модели.

## Слабые стороны

- Крутая кривая: узлы, веса, несовместимые версии кастомных узлов.
- Схема воспроизводима только при тех же версиях ядра, кастомных узлов и файлов весов. Это моя практика, README определённость не обещает; детерминизм на разных видеокартах README не гарантирует.
- Кастомные узлы сообщества: каждый с собственной лицензией и безопасностью, их надо проверять.
- Права на результат определяются моделью и партнёрским сервисом, а не ComfyUI.
- Платные Partner nodes тратят кредиты Comfy; опция `--offline` отключает их.

## Сложность

- Для человека (4 из 5): сначала готовые шаблоны, потом узлы и модели. Недели, нужен опыт.
- Для агента (2 из 5): схема JSON и локальный API позволяют запускать из кода и забирать файлы. Начальное построение сложной схемы агент делает по шаблонам; установка весов и видеокарта нужны.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): локальный API, пакетная очередь с асинхронным выполнением, частичное перевыполнение графа, Comfy CLI, Comfy Cloud API (на платных планах 5–40 «builds» и 2–20 «deployments» по плану).
- Воспроизводимость (4 из 5): схема лежит текстом под git; сид, версии узлов и хэши весов нужно фиксировать самому. Двоичных проектных файлов нет, но результат на другой видеокарте может отличаться.

## Платформа и оборудование

Windows, Linux, macOS; NVIDIA, AMD, Intel, Apple Silicon, Ascend. По README большие модели идут от 4 ГБ видеопамяти и 8 ГБ оперативной за счёт потоковой подгрузки весов. Для видеомоделей Wan, LTX, HunyuanVideo нужно столько, сколько требует модель (8–80 ГБ). Есть Windows portable и desktop-версия. Comfy Cloud работает на Blackwell RTX 6000 Pro с 96 ГБ видеопамяти, предустановлено более 900 моделей.

## Экспорт

Что именно можно сохранить, зависит от узлов. В README: видео, изображения, 3D, аудио; результаты в PNG содержат схему. Конкретные форматы видео (mp4, webm, gif) и последовательности кадров задаются узлами сохранения, их список в источниках не читался.

## Стоимость

Проверено 2026-10-14 по [странице цен Comfy Cloud](https://www.comfy.org/cloud/pricing).

- Локально: бесплатно. Оценка стоимости 0.
- Comfy Cloud: 5 бесплатных запусков для новых пользователей. Standard $16 в месяц при годовой оплате ($20 помесячно), 50 400 кредитов в год. Creator $28 ($35), 88 800 кредитов, свои модели. Pro $80 ($100), 253 200 кредитов, до 1 часа на запуск. Team $630 ($700). Платится активное время GPU. Максимум одного запуска 30 минут (на Pro 1 час).
- Допкредиты не сгорают до года.

## Лицензия и права

- Код: GPL-3.0 (файл LICENSE в репозитории). Копилефт касается самой программы и её изменений, а не ваших схем и видео.
- Результат: определяется моделью. ComfyUI прав не заявляет. Для каждой модели читайте её условия (например [HunyuanVideo](hunyuanvideo.md) исключает ЕС, [LTX-Video](ltx-video.md) ставит порог выручки $10 млн, [Wan](wan.md) под Apache-2.0). Для Partner nodes действуют условия провайдера.
- Метки: ComfyUI не добавляет собственных. Раскрытие синтетических сцен для YouTube — на вас (см. [обзор класса](../classes/10-generative.md)).
- Ассеты в комплекте: шаблоны схем; условия отдельных шаблонов не проверялись.

## Когда брать и когда нет

- Брать: запускать открытые видеомодели и модели изображений в одной воспроизводимой схеме; связать кадры, переходы и апскейл; готовить повторяемые «рецепты» под git.
- Брать для агента: схема JSON и API проще, чем интерфейсы закрытых сервисов.
- Не брать: если нужно одно-два клипа и подписка на сервис проще. Не брать без видеокарты (тогда облако).
- Не брать вслепую кастомные узлы без проверки.
