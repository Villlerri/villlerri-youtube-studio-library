# Jitter

Браузерный сервис motion design в духе Figma: слои, ключевые кадры, пресеты анимации, шаблоны, совместная работа. Сделан для интерфейсов, соцсетей и брендинга. Содержит ИИ-чат, который строит анимацию прямо на холсте.

## Ссылки

- Официальный сайт: <https://jitter.video/>
- GitHub: открытого кода нет.
- Документация и справка: <https://help.jitter.video/>
- Журнал изменений: <https://jitter.video/changelog/>
- Примеры, проверенные 2026-10-14 (ссылки открываются через oEmbed; содержание описано по названию и описанию ролика, ролики целиком не смотрелись):
  - [Jitter Beta – A simple animation tool on the web](https://www.youtube.com/watch?v=h5QFqYZ3ses) — канал Jitter. Ролик на 28 секунд, «Figma для motion design»: анимации для видео, сайтов и приложений в браузере.
  - [Jitter Basics: Adding and Animating Videos](https://www.youtube.com/watch?v=N5Mj2GtvAGQ) — канал Jitter. Загрузка видео, анимация поверх него и самого видео (движение, поворот, масштаб, скругление углов), анимированный текст, маски.

## Что реально получается

Опора: страницы продукта, тарифов, справки и журнал изменений.

- Пресеты анимации, больше 300 шаблонов (страница шаблонов и страница тарифов), главная страница называет 400+. Шаблоны бесплатны, сказано «можно использовать в коммерческих целях».
- Инструмент «перо» с морфингом, градиенты, размытие, режимы наложения, эффекты (искажение, 3D-переворот, дизеринг). Журнал изменений 2026: смещающие шейдеры, независимые радиусы углов, составные формы пером.
- Анимированные компоненты и переопределения компонентов (2026-08-18).
- Импорт из Figma, плагин для Figma Draw, импорт видео и аудио в анимацию, преобразование картинки в видео.
- Типографика: пользовательские эффекты текста (2026), больше 1500 шрифтов (главная страница).
- Пакетное создание сцен из CSV (Bulk Create, 2026-07) и пакетный экспорт (Max). Подходит для серии однотипных карточек.
- ИИ: чат создаёт анимацию на холсте, переключается между режимами Balanced и Smart (2026-10-14).
- Камера и непрерывная сцена: в проверенных источниках не названы. Сервис ориентирован на короткие ролики и интерфейсные анимации, а не на длинную объясняющую сцену.
- Рисование линий и схемы: «перо» и пути есть, но готового «draw-on» в источниках не нашёл.
- Синхронизация с голосом: импорт аудио есть, привязки к тексту сценария нет.

## Слабые стороны

- Бесплатный тариф: 720p при 30 к/с и водяной знак Jitter. Без водяного знака и в 1080p/60 нужен Pro.
- Прозрачный фон (альфа), покадровый экспорт и 4K нужны тарифы Max или Ultra.
- Нет локальной работы и экспорта проекта в открытом формате: всё живёт в облаке аккаунта.
- Бесплатный тариф ограничен тремя файлами в рабочем пространстве.
- ИИ-кредиты ограничены по тарифу.
- Цены тарифов не видны на странице без выполнения JavaScript, условия использования (Terms) на прямой запрос пустые. См. «Неизвестно».
- Для длинных объясняющих роликов не рассчитан.

## Сложность

- Для человека (2 из 5): интерфейс простой, освоить можно за день-два. Оценка автора карточки.
- Для агента (4 из 5): публичного API и командной строки в проверенных источниках нет. Агенту доступен только интерфейс сервиса. ИИ-чат самого Jitter строит анимацию по описанию, проверять результат нужно человеку. Подготовка текстов и таблиц CSV для Bulk Create возможна кодом.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): Bulk Create из CSV, пакетный экспорт (Max), шаблоны и компоненты. Публичного API не нашёл.
- Воспроизводимость (2 из 5): проект живёт в облаке, воспроизводить его нужно через аккаунт. Результат зависит от версии сервиса и ИИ.

## Платформа и оборудование

- Браузер. Никакой установки. Нужен аккаунт.
- Максимальные размеры экспорта: от 16x16 до 2160x4320 / 4320x2160 / 2800x2800 / 5760x1080 пикселей (справка).

## Экспорт

- Бесплатный тариф: видео MP4 (H.264), GIF, Lottie, 720p при 30 к/с, с водяным знаком.
- Pro: без водяного знака, 1080p при 60 к/с, WebM, MOV (ProRes 4444).
- Max и Ultra: прозрачный экспорт (WebM, MOV, GIF), покадровый экспорт, 4K при 120 к/с, пакетный экспорт.
- PNG-последовательности и PNG как формат: в справке не упомянуты.

## Стоимость

Проверено 2026-10-14 по [странице тарифов](https://jitter.video/pricing/) и [справке](https://help.jitter.video/en/articles/14809073-compare-jitter-s-subscription-plans).

- Free, Pro, Max, Ultra и Enterprise (по запросу). Pro, Max и Ultra: цена за редактора в месяц при оплате за год. Страница тарифов показывает «--» вместо сумм (цены подгружаются скриптом).
- Скидка при оплате за год: страница тарифов называет 15%, справка «больше 20%». Разовой оплаты нет, только подписка.
- Сторонний обзор называет около US$19 за Pro в месяц при годовой оплате. Не подтверждено Jitter. Оценка стоимости 1 условная.
- Бесплатный тариф даёт все базовые функции анимации, но с водяным знаком и 720p.

## Лицензия и права

- Код или программа: проприетарный сервис.
- Результат: по странице шаблонов шаблоны можно использовать в коммерческих целях. Условия использования (Terms) не прочитаны (страница не отдаёт текст без JavaScript), права на экспорт и ИИ-результат не подтверждены. Водяной знак есть на бесплатном тарифе и снимается на платном (справка).
- Ассеты в комплекте: шаблоны, шрифты, стоковые картинки и видео из Pixabay и Pexels в ИИ-чате (журнал изменений). Условия шрифтов и ассетов не читал.

## Активность и зрелость

Зрелость: stable. Журнал изменений показывает частые выпуски до 2026-10-14. Версия 1.0 вышла раньше (ролик «Introducing Jitter 1.0»). Развивает команда Jitter. Чаще всего меняется ИИ-часть, поэтому интерфейс и цены могут меняться.

## Когда брать и когда нет

- Брать: короткие заставки, титры, карточки, интерфейсные анимации, серия однотипных клипов из CSV.
- Брать: когда нужен быстрый результат без установки.
- Не брать: если нужна длинная непрерывная сцена с камерой, схемами и рисованием. Тогда [After Effects](after-effects.md) или [Cavalry](cavalry.md).
- Не брать: если нужен контроль над правами и данными на своих серверах. Сервис закрытый.
- Не брать: если сцены должен собирать агент без интерфейса.
