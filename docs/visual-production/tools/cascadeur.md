# Cascadeur

3D-программа для анимации персонажей от компании Nekki (Кипр). Опирается на физику: персонаж «знает» центр масс, опору и инерцию, поэтому позу и движение можно править меньшим числом точек. ИИ-инструменты помогают, но работают под управлением человека: AutoPosing (позы по нескольким точкам), Inbetweening (промежуточные кадры между ключами), генерация движения. Выводит анимацию в Blender, Unreal, Unity и другие, свой финальный рендер ролика не является главным назначением.

## Что реально получается

- Выразительная анимация персонажа: прыжки, падения, бой, паркур, жестикуляция. Физика (AutoPhysics) добавляет вес и инерцию, Ragdoll даёт реакцию на удары, AutoPosing позволяет ставить позы, двигая мало точек, Inbetweening строит промежутки между ключами, инструмент генерации движения создаёт бег, прыжки, бой и другое (в 2026.2 переименован из Root Motion).
- Очистка захвата движения (mocap): убирает скольжение стоп, провалы коленей и проникновение в геометрию, затем правится позами.
- Готовые риги: автоматическая расстановка суставов для гуманоидов и четвероногих, перенос анимации между персонажами (retargeting, в платных тарифах начиная с Pro).
- Передача в другие программы: форматы FBX, DAE, USD, GLB/GLTF, прямой поток в Unreal Engine (Live Link). Рендер готового ролика нужно делать в [blender](blender.md) или [unreal-engine](unreal-engine.md) (на странице документации в списке экспорта есть Blender, Unreal, Unity, Daz, Roblox). Собственный движок Filament (с 2026.1) показывает вид в окне программы, экспорта видео из него не нашёл.
- Для объясняющего ролика: нужна там, где автор хочет персонажа с телом (ведущий, ассистент, маскот), который показывает, сидит, толкает предмет и правдоподобно реагирует. Для объяснения полей, формул и схем не годится: см. [manim-ce](manim-ce.md), [blender-geometry-nodes](blender-geometry-nodes.md).
- Непрерывность и камера: камера есть, сцену можно вести как один длинный план, слои анимации (2026.2, альфа) разделяют движение на независимые части и складываются. Морфинга форм и рисования линий нет.
- Синхронизации с озвучкой в виде меток нет, есть окно аудио для привязки на таймлайне (раздел справки Audio), готовых меток по голосу нет.

## Слабые стороны

- Это инструмент для анимации персонажей, а не для научной графики.
- Рендера ролика в самой программе, по документации, нет: нужен ещё один пакет (Blender или Unreal).
- Работа только вручную в интерфейсе: позы, ключи, настройки физики. Агент мало поможет.
- Часть возможностей урезана в бесплатном тарифе: экспорт только в собственный формат `.casc`, FBX и DAE закрыты, коммерческое использование запрещено.
- Слои анимации в альфа-версии (2026.2).
- Требует учётную запись и вход в программе (EULA: регистрация на сайте перед использованием).

## Сложность

- Для человека (3 из 5): есть уроки, ИИ-помощники ускоряют входы, но анимация персонажа остаётся ремеслом. Хватает недель на базовый результат, мастерство требует практики.
- Для агента (4 из 5): программа с окном. В ней есть Python API и меню скриптов, и свежие версии добавляют заглушки для подсказок (Python stub files в 2026.2), но запуск без интерфейса и командную строку я не нашёл. Позы, ключи и оценку движения агенту делать трудно.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): Python-скрипты внутри Cascadeur (меню Scripts, PySide/QML для интерфейса), импорт и экспорт FBX, DAE, USD, GLTF, BVH-импорт (с 2026.2). Командной строки для пакетной работы не нашёл.
- Воспроизводимость (3 из 5): проект в двоичном формате `.casc`, результат воспроизводится в той же версии. Нейросетевые инструменты дают разный результат от версии к версии: в 2026.2 Inbetweening и Motion Generation переобучены на больших данных.

## Платформа и оборудование

Windows 10 (версия 1809 и новее) и 11, Ubuntu 20.04–22.04.1, macOS 13.3 и новее (процессоры серии M). Минимум: 4 ГБ памяти, видеокарта уровня NVIDIA GTX 550 Ti и OpenGL 4.1. Рекомендуется: 8 ГБ памяти, GTX 650 и лучше. Установщик около 500 МБ. Текущая версия на странице загрузки: 2026.2.3 от 2026-10-01. Есть мобильное приложение для iOS (платные функции в нём входят в подписку).

## Когда брать и когда нет

- Брать: канал с персонажем, где нужен правдоподобный вес и движение; очистка mocap; быстрый аниматик характера для передачи в Blender или Unreal.
- Не брать: научные схемы, формулы и поля ([manim-ce](manim-ce.md), [remotion](remotion.md)); если нет денег на Indie при монетизации; если нужен рендер ролика в самой программе; если вся работа должна идти из кода и командной строки.
