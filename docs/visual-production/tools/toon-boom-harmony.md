# Toon Boom Harmony

Отраслевой стандарт 2D-анимации для студий: рисованная покадровая анимация, кукольные риги из вырезанных частей, мультиплан-камера, узловой композитинг. Три редакции: Essentials, Advanced, Premium.

## Что реально получается

- Две техники в одном проекте: рисованная анимация кадр за кадром (векторные и в Advanced растровые кисти, калька, ink and paint) и кукольные риги из частей с костями и деформаторами.
- Камера: мультиплан-камера с осью Z входит в сравнительную таблицу магазина в базовой группе функций. Движение камеры по глубине даёт параллакс между слоями фона.
- Композитинг: узловой вид (Node View), частицы, OpenFX, 3D-модели и вращение по осям X/Y в Premium. Это ближе к After Effects, чем к рисовалке.
- Позирование: в версии 27 (2026-06-16) добавлен Attribute Controller. Он добавляет смещения поверх существующей анимации и позволяет смешивать позы в сетке или по слайдеру.
- Дёрганые переходы: покадровые техники и «смазывание» (smear) рисуют вручную, автоматического смаза в просмотренных страницах нет.
- Морфинг формы и линия, которая «вычерчивается» сама: в просмотренной документации и таблице магазина не проверял.
- Звук и голос: звук на шкале; липсинк-инструменты в просмотренных страницах не открывал.
- Скрипт-экспорт видео: узел записи «Scripted Movie» запускает внешний процесс после рендера, например ffmpeg.

## Слабые стороны

- Самый высокий порог входа в классе, Premium стоит дорого. Нужен обученный аниматор.
- Linux в системных требованиях не указан. Требования высокие: рекомендуется 32 ГБ памяти и видеокарта уровня GTX 1060 или M1 Pro.
- Ключевые функции разнесены по редакциям: узловой вид, деформаторы кривых и сеток и Master Controller только в Premium.
- Нативно экспортирует `.mov`, а не MP4. H.264 в `.mov`, ProRes на macOS; на Windows для QuickTime-кодеков нужен установленный QuickTime.
- Ручная работа аниматора на каждую секунду: покадровая рисованная сцена в разы дороже кода.

## Сложность

- Для человека (5 из 5): профессиональный инструмент с узловым видом, риггингом и своей терминологией. Месяцы до уверенной работы, без навыков анимации сразу не получится.
- Для агента (4 из 5): интерфейс графический. Есть скрипты и запуск без окна, но сцену рисуют и ставят руками. Агент годится для пакетных операций над готовой сценой, но не для создания анимации.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): скрипты JavaScript (QtScript) работают в режиме без интерфейса: `Harmony<Edition> Scene.xstage -batch -compile Script.js` ([документация 24](https://docs.toonboom.com/help/harmony-24/scripting/script/index.html)). В версии 27 скриптом задают цветовое пространство ProRes. В таблице магазина есть строка «Integrated batch rendering» (в какой редакции, не определял).
- Воспроизводимость (3 из 5): сцена — папка с файлом `.xstage` и файлами рисунков, рендер воспроизводится. Формат `.xstage` и пригодность для git не проверял.

## Платформа и оборудование

Windows 10 и 11 (64 бита), macOS от Monterey 12.7.3 до Sequoia 15.3 ([страница продукта](https://www.toonboom.com/products/harmony)). Рекомендуется 32 ГБ памяти, минимум 8 ГБ, видеокарта GTX 960 или M1 7-core минимум. Планшет Wacom в рекомендациях. Для 3D нужна поддержка Vulkan 1.1. Браузерной версии на страницах не видно.

## Экспорт

- Видео: `.mov` (QuickTime, кодек на выбор), H.264/MPEG-4 в `.mov` (до 4096×2304, без настроек), на Windows `.wmv`. На macOS через AVFoundation доступны ProRes 422 и 4444. Для прозрачности выбирают кодек с альфой ([документация 27](https://docs.toonboom.com/help/harmony-27/essentials/export/export-movie.html)).
- Последовательности изображений и другие форматы: на просмотренных страницах не названы, не проверял.
- Разрешение камеры: Essentials 2K, Advanced 4K, Premium выше 8K.

## Когда брать и когда нет

- Брать: персонажный ролик с актёрской игрой, когда нужен самый высокий потолок качества и есть аниматор. Подходит студии, которой ролики с персонажами нужны серией.
