# Апплеты Falstad

Набор интерактивных симуляций Пола Фалстада по математике, физике и электронике. Раньше были Java-апплетами, сегодня большей частью работают на JavaScript в браузере. Для магнетизма есть «3-D Magnetostatic Fields» и несколько апплетов поля и индукции.

## Ссылки

- Официальный сайт: <https://www.falstad.com/mathphysics.html>
- GitHub: единого репозитория нет. Открыты исходники части апплетов: [circuitjs1](https://github.com/pfalstad/circuitjs1), [emstatic-ts](https://github.com/pfalstad/emstatic-ts), [ripplegl-ts](https://github.com/pfalstad/ripplegl-ts). У апплета 3-D магнитостатики репозитория не нашли.
- Условия: <https://www.falstad.com/licensing.html>
- Примеры, проверенные 2026-10-14:
  - [3-D Magnetostatic Fields (полноэкранная версия)](https://www.falstad.com/vector3dm/vector3dm.html) — поля тока и магнитов с режимами показа: частицы в поле, векторы, линии поля, потенциал; ползунки плотности линий и числа частиц.
  - [Directions для 3-D Magnetostatic](https://www.falstad.com/vector3dm/directions.html) — список полей: токовая петля (эквивалент диска-магнита), пара петель, противоположные петли (два встречных магнита), концентрические петли (кольцевой магнит), соленоид, тороид, подковообразный электромагнит, намагниченная сфера.
  - [2-D Electrodynamics (TM)](https://www.falstad.com/emwave2/) — электромагнитное излучение, индукция и магнитостатика.
  - [Ripple Tank (2-D Waves)](https://www.falstad.com/ripple/) — пример стиля апплетов Falstad, не магнитный.
  - Роликов на YouTube с разбором 3-D магнитостатики Falstad не нашли. Найдены только ролики по ripple tank и симулятору цепей.

## Что реально получается

Сквозной пример (магнит на холодильнике). В «3-D Magnetostatic Fields» поле магнита задаётся эквивалентным током. Пара «loop pair opposing» (два круговых тока в противоположных направлениях) соответствует двум встречным дисковым магнитам, это ближайший вид к двум соседним полосам полосатого магнита. Полосатая пластина и стальная дверь не входят в набор полей. Линии поля показываются режимом «Field Lines», движение частиц по линиям — режимом частиц.

Что даёт для видео:

- Мгновенно понятный образ поля: живой поток частиц вдоль линий, вращение сцены мышью, переключение источников.
- Запись экрана. Встроенного видеоэкспорта нет.
- Рисования линий нет, морфинга нет, синхронизация с голосом — только живое управление. Камеру вращают мышью.
- Подходит как референс или черновик идеи. Для готовых кадров с рабочим видом лучше пересоздать сцену кодом.

## Слабые стороны

- Права на запись видео для монетизированного ролика не ясны (см. «Лицензия и права»).
- Жёстко заданный набор полей, нельзя ввести собственную геометрию полосатого магнита.
- Внешний вид «апплетный», шрифты и цвета фиксированы.
- Нет экспорта и API. Воспроизводить сцену приходится руками.

## Сложность

- Для человека (1 из 5): открыть страницу, выбрать поле и режим.
- Для агента (4 из 5): интерфейс на холсте с ползунками. Агент может управлять браузером и записывать экран, но точно воспроизвести кадры трудно.

## Автоматизация и воспроизводимость

- Автоматизация (1 из 5): нет API и командной строки.
- Воспроизводимость (1 из 5): результат зависит от ручных действий, точный кадр воспроизвести нельзя.

## Платформа и оборудование

Любой современный браузер с WebGL. Установка не нужна. Для части апплетов есть приложения для iPhone, iPad и Android (главная страница сайта).

## Когда брать и когда нет

- Брать: быстрое наглядное объяснение магнитного поля тока и магнита в качестве референса или записи экрана для некоммерческого видео, после получения согласия на другое использование.
- Не брать: монетизированный ролик без письменного разрешения. Для готовой графики лучше построить сцену в [magpylib](magpylib.md) и [pyvista](pyvista.md).
