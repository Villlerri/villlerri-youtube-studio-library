# Glaxnimate

Простой редактор векторной анимации и motion design от проекта KDE. Основной формат: Lottie, вторичные: анимированный SVG, GIF, WebP. Есть консоль Python и модуль для запуска без интерфейса.

## Ссылки

- Официальный сайт: <https://glaxnimate.org/>
- GitHub: <https://github.com/KDE/glaxnimate> (зеркало, основной репозиторий <https://invent.kde.org/graphics/glaxnimate>)
- Документация: <https://docs.glaxnimate.org/en/> (руководство для версии 0.5.4, устарело), скрипты: <https://glaxnimate.org/contributing/scripting>
- Примеры, проверенные 2026-10-14 (ссылки открываются через oEmbed; содержание описано по названию и описанию ролика, ролики целиком не смотрелись; оба ролика сторонние):
  - [Easy Character Animation in Glaxnimate](https://www.youtube.com/watch?v=REU8Z5j7qlw) — канал Photolearningism. Простой 2D-персонаж из импортированных картинок, шаги от настройки проекта до анимации слоя.
  - [Glaxnimate Explain: How to animate Maps in Glaxnimate](https://www.youtube.com/watch?v=SuZidetfKDs) — канал Eses infor Learning. Анимация карты: движение точек по траектории (follow path). Подходит для схем движения.

## Что реально получается

Опора: сайт, руководство 0.5.4, CHANGELOG из репозитория KDE, примеры выше.

- Простые векторные сцены: фигуры, пути, градиенты, ключевые кадры с кривыми лёгкости, маски, повтор (Repeater), скругление углов. В разработке (0.7.0): режимы наложения, маска по яркости, привязка к сетке.
- Движение по траектории: из CHANGELOG (автоповорот по траектории, группа вдоль пути). Подходит для схем «объект идёт по линии».
- Импорт растровых картинок и трассировка в вектор (Trace Bitmap).
- Импорт файлов After Effects (AEP) добавлен в 0.5.4. Покрытие возможностей не проверено.
- Lottie открывается и сохраняется, с оговоркой «реализованы не все возможности». Просмотр прямо из программы в веб-плеере Lottie.
- Рисование линий, морфинг контуров, камера: в руководстве не найдено. Морфинг как анимация точек пути возможен в принципе, подтверждения нет.
- Типографика: не описана в проверенных источниках.
- Непрерывная сцена: композиции и предкомпозиции есть (0.7.0: «предкомпозиции без границ»), но готовых примеров сложной сцены нет.
- Синхронизация с голосом: ключевые кадры вручную. Привязки к звуку не найдено.

## Слабые стороны

- Руководство описывает версию 0.5.4. Новые функции 0.6 и 0.7 видны только в CHANGELOG репозитория.
- Версии 1.0 нет. В 0.6.0 принята схема чётных и нечётных номеров версий (CHANGELOG, смысл схемы там не поясняется).
- Видеоэкспорт в проверенных источниках упомянут только вскользь. Список видеоформатов и кодеков не проверен.
- Формат Lottie сам ограничивает возможности: часть эффектов не переносится, и в программе «реализованы не все возможности» формата.
- Для научно-популярного канала мало: нет 3D, камеры, сложной типографики, физики.
- Официальной командной строки для рендера в источниках нет.

## Сложность

- Для человека (2 из 5): простой интерфейс, свободное освоение за дни. Подходит для первой работы с векторной анимацией. Оценка автора карточки.
- Для агента (3 из 5): есть консоль Python и модуль `glaxnimate` из PyPI, который работает без интерфейса: создаёт документ, слои, фигуры, анимирует и сохраняет Lottie JSON. Агент может собрать анимацию кодом. Рендер кадра для проверки идёт через сам Glaxnimate или плеер Lottie, готового способа в источниках нет.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): Python в консоли и как модуль без интерфейса (по странице скриптов). В 0.7.0 улучшены привязки объектов, свойств и ключевых кадров. Командная строка не описана.
- Воспроизводимость (3 из 5): скрипт Python воспроизводит документ. Собственный формат проекта не проверен. Lottie JSON хранится как текст и годится для git.

## Платформа и оборудование

- GNU/Linux (Flatpak на Flathub, ночные сборки), Windows (установщик `.exe`, Microsoft Store), macOS (отдельные DMG для ARM и Intel). Страница загрузки версии 0.6.0.
- Требований к железу не нашёл.

## Экспорт

- Lottie (JSON), Telegram-стикеры TGS, SVG (в том числе анимация SMIL), растровые кадры, GIF и WebP анимированные (руководство 0.5.4).
- Экспорт последовательности изображений поддерживает SVG (CHANGELOG 0.6.0). Кадры в PDF и PostScript (CHANGELOG 0.7.0).
- Альфа-канал: растровые форматы GIF и WebP с прозрачностью, подробности не проверены.

## Когда брать и когда нет

- Брать: бесплатные простые анимации для Lottie, стикеры, иконки, схемы с движением по траектории.
- Брать: если агент собирает документ скриптом на Python.
- Не брать: если нужна выразительная сцена уровня Kurzgesagt. Тогда [After Effects](after-effects.md) или [Cavalry](cavalry.md).
- Не брать: если нужен рендер в видео по команде. Тогда [Friction](friction.md) или код ([Manim CE](manim-ce.md)).
