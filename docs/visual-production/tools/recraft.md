# Recraft (векторная генерация)

Сервис генерации изображений, который умеет выдавать настоящий SVG с контурами, а не растр. Модели Recraft V4.1 (май 2026), V4.1 Flash (сентябрь 2026), V4 Styles (август 2026). Для объясняющих роликов интересен как источник редактируемых иллюстраций, значков, схем и логотипов, которые можно анимировать кодом.

## Ссылки

- Официальный сайт: <https://www.recraft.ai>
- GitHub: открытого кода моделей нет.
- Документация: <https://www.recraft.ai/docs> (API, модели, цены)
- Примеры, проверенные 2026-10-14:
  - [Recraft V4.1 Flash](https://www.youtube.com/watch?v=VRmnSYgedjE) — официальный канал Recraft. Ссылка открывается через oEmbed, содержание по названию.
  - [Recraft V4 Styles](https://www.youtube.com/watch?v=1nevzOnWTGE) — тот же канал, как держать один стиль в серии. Содержание по названию.
  - [Модели в документации](https://www.recraft.ai/docs/api-reference/models/overview) — таблица моделей, цены и история релизов. Прочитана.

## Что реально получается

Опора: документация API, страница цен, условия. Генераций я не запускал.

- Векторные модели: названия с `_vector` возвращают SVG. `recraftv4_1_vector` по $0.08, `recraftv4_1_pro_vector` $0.30, V4 vector $0.08, V2 vector $0.044. Документация описывает SVG как «редактируемый» и «для логотипов, типографики и иллюстраций». Ссылка на файл живёт около 24 часов.
- Растровые модели: V4.1 (по умолчанию, от $0.035), V4.1 Flash (около 1,3 секунды, $0.007), V4 Styles (стиль по 1–10 картинкам-образцам, без обучения, от $0.035), V3 (текст и правка: закраска, расширение, фон).
- Инструменты: преобразование растра в SVG (Vectorize, $0.01 за запрос), удаление фона для PNG, JPG, WEBP и SVG, апскейл, ремикс, смена фона, улучшение подсказки.
- Постоянный стиль: V4 Styles и стили в Studio позволяют держать единый вид иллюстраций в серии. Это отвечает на повтор одного и того же стиля в ролике.
- Видео: в Studio на плане Pro доступны сторонние видеомодели (Kling, Grok Imagine Video, Veo, Seedance) с «полным набором управления». Собственных видеомоделей Recraft в документации нет.
- Связь с анимацией: SVG можно оживлять кодом ([GSAP](gsap.md), [Vivus](vivus.md), [Lottie](lottie.md)): рисование линий, движение частей. Это моя рекомендация по формату, не функция Recraft.
- Вывод автора: лучший в классе источник векторных иллюстраций для схем и значков. Сложные схемы с точными подписями и связями всё равно проще строить кодом.

## Слабые стороны

- SVG от модели не гарантирует правильную структуру: группы, слои и имена объектов придётся проверять руками. Это вывод, а не измерение.
- Научная точность не гарантирована: модель рисует «похоже», а не по спецификации.
- Free-план: картинки публичны, принадлежат Recraft, коммерческое использование запрещено.
- Автоматическая метка происхождения: по условиям Recraft может встраивать метаданные и водяные знаки, удалять их нельзя.

## Сложность

- Для человека (1 из 5): веб-редактор, готовые стили, правка на холсте. Осваивается за день.
- Для агента (2 из 5): REST API с одним запросом (`prompt`, `model`), ответ со ссылкой на SVG; есть Claude Code skill и MCP-сервер Recraft. Агент проверяет результат, открыв SVG; человек заводит ключ и оплату.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): REST API (генерация, правка, векторизация, фон, апскейл, пакетные задачи, асинхронная обработка), совместимость с OpenAI-клиентами по настроенному base URL, MCP.
- Воспроизводимость (2 из 5): модели обновляются, версии в имени (V4.1, V4.1 Flash); SVG надо скачать за 24 часа и положить в git. После этого файл фиксирован, но повторная генерация даст иной результат.

## Платформа и оборудование

Браузер (Recraft Studio), API. Локального запуска нет, GPU не нужна.

## Экспорт

SVG (векторные модели), WebP (без потерь) и PNG (растровые). Для векторного вывода формат всегда SVG. Размеры: 1K и 2K для V4.1; на Pro-вариантах 2K. Видео из сторонних моделей на плане Pro.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://www.recraft.ai/pricing) и [документации API](https://www.recraft.ai/docs/api-reference/models/overview).

- Free: $0, ограниченные бесплатные кредиты, 3 генерации на стиль в день, все изображения публичные, коммерческого использования нет, только модели Recraft.
- Basic: $10 в месяц при годовой оплате ($120 в год), 1000 кредитов в месяц, коммерческие права, приватные генерации, модели Nano Banana, Seedream, GPT Image, Flux.
- Pro: $16 в месяц при годовой оплате ($192 в год), 2000 кредитов (выбор до 16 000), видеогенерация, 10 параллельных.
- Teams: $18 за место в месяц при годовой оплате, общий воркспейс. Скидка при годовой оплате 20%; помесячную цену не считывал. Цены без НДС.
- API, за картинку: V4.1 Flash $0.007; V4.1 растр $0.035, вектор $0.08, Pro-вектор $0.30; V4 растр от $0.04; V2 вектор $0.044; Vectorize $0.01.
- Пример расчёта: 100 векторных иллюстраций V4.1 через API = $8, с ориентиром 3–5 попыток на удачную $24–40. Оценка стоимости 1.

## Лицензия и права

- Код или программа: проприетарный сервис.
- Результат (Free): по [условиям](https://www.recraft.ai/terms) п. 7.1 Free Tier Assets принадлежат Recraft, коммерческое использование запрещено, нельзя обучать ИИ на них; в странице цен ещё и публичность в галерее.
- Результат (платный план): п. 7.2 — «You own all Assets you create with the Services», Recraft передаёт вам авторские права. Ограничение: нельзя использовать результат для обучения моделей ИИ, иначе права возвращаются Recraft. Права остаются и после отмены подписки.
- API и MCP: действуют отдельные [Developer Terms](https://www.recraft.ai/legal/developer-terms). По умолчанию Recraft не хранит изображения API сверх необходимого срока; сторонние модели обрабатываются по условиям их провайдеров.
- Метки: п. 8.2 условий — Recraft может встраивать машиночитаемые метаданные, водяные знаки и сведения о происхождении, снимать их нельзя; вы отвечаете за раскрытие ИИ там, где это требует закон. Для YouTube реалистичные синтетические сцены нужно раскрывать в Studio (см. [обзор класса](../classes/10-generative.md)).
- Ассеты в комплекте: стили и шаблоны Studio; их условия отдельно не читал.

## Активность и зрелость

Зрелость (stable): история моделей V2 (февраль 2024), V3 (октябрь 2024), V4 (февраль 2026), V4.1 (май 2026), V4 Styles (август 2026), V4.1 Flash (сентябрь 2026); ежемесячные обзоры обновлений Studio на канале. Развивает компания Recraft.

## Когда брать и когда нет

- Брать: векторные значки, иллюстрации и элементы схем, единый стиль на серию роликов, оживление SVG кодом.
- Брать для фонов и иконок, которые должны остаться в проекте файлом (SVG под git).
- Не брать: научные схемы, где важна точность связей и подписей: строить в [D3.js](d3.md) или кодом.
- Не брать на Free-плане для публикуемого ролика (нет коммерческих прав).
