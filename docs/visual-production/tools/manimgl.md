# ManimGL (3Blue1Brown)

Исходная версия Manim, личный инструмент Гранта Сандерсона для роликов 3Blue1Brown. Рендер через OpenGL, окно с интерактивным предпросмотром, оболочка IPython прямо внутри сцены. Задаёт эталон стиля для математических объяснений.

## Что реально получается

- Тот самый вид 3Blue1Brown: тёмный фон, плавные перестройки формул, объекты, которые передвигаются, а не сменяются. Рекордный по узнаваемости результат класса.
- Морфинг формул: `TransformMatchingTex` с `key_map` и `transform_mismatches=True` (перетекание одинаковых частей, несовпавшие уходят или превращаются). `TransformMatchingShapes` сопоставляет формы без разметки. Видно в `TexTransformExample`.
- Рисование линий: `ShowCreation` вместо `Create` из CE, плюс `Write`. Для контуров есть `lag_ratio` и `run_time`.
- Камера: `self.frame.animate` с `increment_phi`, `increment_theta`, `reorient`. В `SurfaceExample` камера поворачивается во время превращений поверхности. Есть `ThreeDScene`, поверхности и оси.
- Апдейтеры: `always_redraw`, `f_always`. Подписи и скобки следят за объектами каждый кадр.
- Непрерывность: вся сцена в одном `construct()`. Мобджекты остаются в кадре между `play()`. Между роликами стыковка монтажом.
- Интерактив: `self.embed()` открывает оболочку внутри сцены; команды из неё сразу видны в окне. Ускоряет подбор композиции для человека.

Отличия от [Manim CE](manim-ce.md):

- Кто ведёт: ManimGL — личный проект автора роликов. CE выделен в 2020 году группой разработчиков с целью «стабильнее, лучше протестировано» (README обоих).
- Пакеты разные: `pip install manimgl` с импортом `from manimlib import *`; для CE — `pip install manim` с `from manim import *`. README предупреждает: инструкции смешивать нельзя.
- Рендер: ManimGL — OpenGL с окном. CE по умолчанию — Cairo на процессоре, OpenGL там необязателен.
- Имена и API: `ShowCreation` и `OldTex` против `Create` и `MathTex`; камера `self.frame` против `self.camera.frame` в `MovingCameraScene`. Код между версиями не переносится без правок.
- LaTeX: в обеих версиях через LaTeX. В CE с 0.21.0 есть альтернатива Typst; в README ManimGL про Typst ничего нет.
- Документация: у ManimGL короткая, у CE справочник по классам.
- Какой использует канал: 3Blue1Brown использует ManimGL, не CE (README репозитория роликов).

## Слабые стороны

- Опубликованная версия устарела: README репозитория роликов требует ставить `manimgl` из исходников. Релиз 1.7.2 вышел 2024-12-13, коммиты идут до сентября 2026.
- API меняется без уведомлений. README роликов: код старых выпусков может не запускаться на новой версии.
- Нужен OpenGL и окно. Работу без экрана (сервер, CI) документация не описывает.
- Документация короткая: примеры и исходники важнее справочника. Агенту и новичку труднее, чем с CE.
- Код роликов 3Blue1Brown лицензирован CC BY-NC-SA 4.0 (некоммерческая, с указанием автора и той же лицензией). Брать этот код в коммерческие ролики без отдельного разрешения нельзя.

## Сложность

- Для человека (4 из 5): установка из исходников, OpenGL, короткие документы, привычка к собственным идиомам. Взамен очень быстрый цикл «правка, окно, оболочка».
- Для агента (2 из 5): сцена пишется кодом, рендер из командной строки (`manimgl file.py Scene -w`). Сложности: нужен контекст OpenGL, нестабильный API и редкие примеры в документации, у агента выше шанс ошибиться в именах.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): флаги `-w`, `-s`, `-n`, `--hd`, `--uhd`, `--fps`, `-t` (прозрачный фон) и `custom_config.yml`. Пакетный запуск сценариями. Минус — привязка к окну OpenGL.
- Воспроизводимость (4 из 5): текст на Python под git. Версии плавают: ставить из исходников значит фиксировать коммит самому.

## Платформа и оборудование

Linux, macOS, Windows. Python 3.10 или новее, FFmpeg, OpenGL, заголовки Pango на Linux, LaTeX необязателен. Нужна видеокарта или программный OpenGL. Установка: `pip install manimgl` или `pip install -e .` из клона репозитория.

## Экспорт

- `-w` пишет сцену в видеофайл (MP4), `-o` ещё и открывает, `-s` пропускает к последнему кадру, `-so` сохраняет последний кадр как изображение.
- Размер: `-l`, `-m`, `--hd` (1080p), `--uhd` (4K), `-r` задаёт «WxH»; `--fps` частота кадров.
- `-t` рендерит с прозрачным фоном.

## Когда брать и когда нет

- Брать: если нужен именно стиль 3Blue1Brown, интерактивная раскадровка сцены в окне и человек сам ведёт сцену. Хорошо для формул, графиков, полей и 3D-поверхностей.
- Не брать: если сцены пишет агент без экрана, если нужна стабильность API на годы или нужен ручной таймлайн. Для этих задач [manim-ce](manim-ce.md) или [motion-canvas](motion-canvas.md).
