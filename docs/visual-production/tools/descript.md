# Descript

Облачный редактор видео и звука с монтажом по тексту: запись расшифровывается, правка текста правит видео. Есть ИИ-помощник Underlord и ИИ-голоса. Синтезированную речь студия получает только через ElevenLabs, поэтому голосовые ИИ-функции Descript (AI Speakers, клонирование, Regenerate Speech) не используются. Монтаж по тексту годится и для записи живого голоса.

## Что реально получается

Опора: главная страница, цены, справка.

- Монтаж по тексту: «удаление слова удаляет момент видео, перенос предложения переносит кадры». Паузы и слова-паразиты убираются кликом, для тонкой правки есть таймлайн.
- Underlord: ИИ-помощник, из черновой записи собирает монтаж, ставит субтитры, чистит паузы, делает подборки. Через API запускается так же.
- Для видео: Eye Contact, Green Screen, Automatic Multicam, Studio Sound (очистка звука), титры, перевод, клипы, шаблоны.
- Для объясняющих роликов: черновая нарезка записи диктора или лекции, субтитры, перевод.
- Непрерывная сцена, морфинг, рисование, камера в 3D: нет.
- Синхронизация с голосом: правка идёт по тексту расшифровки, а не по анимации. API умеет экспортировать расшифровки (страница API). Формат таймкодов слов не проверен.
- Голосовые функции (AI Speakers, клонирование, Regenerate Speech): есть, студия их не использует.

## Слабые стороны

- Облако. Проекты живут в облачном диске (Drive) Descript, воспроизвести их из кода нельзя.
- Скачать готовое видео через API без публикации нельзя: файл отдаётся по подписанной ссылке после публикации (страница API).
- Из экспорта таймлайна теряются видеоэффекты, переходы, анимация, титры, формы и изображения, скорость клипа, ключевые кадры (справка). Дальше править придётся с нуля.
- Free: 720p и водяной знак.
- Условия разрешают Descript и его поставщикам использовать ваши данные для обучения моделей, если не отказаться.
- Linux на странице загрузки не указан.
- YouTube-ссылки как источник импорта через API не принимаются.

## Сложность

- Для человека (1 из 5): править текст проще, чем таймлайн. Оценка автора карточки.
- Для агента (3 из 5): есть HTTP API и MCP. Агент может импортировать медиа, запускать правки Underlord, публиковать, искать проекты. Скачать готовый файл можно только через публикацию. Токен привязан к одному диску. Минуты и кредиты расходуются. Проверка запуском не проводилась.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): HTTP API (токен на диск; 402 при исчерпании минут или кредитов; записи заданий доступны 30 дней) и MCP через OAuth. Бета-статус API страница не называет; в результатах поиска справка называлась «Descript API (beta)».
- Воспроизводимость (1 из 5): правки Underlord и ИИ-функции недетерминированы, проект облачный.

## Платформа и оборудование

- Десктоп: macOS 14 (Sonoma) или Windows 11 и новее (страница загрузки). Linux не указан.
- Веб-приложение: есть вход через сайт, требования страница не называет.

## Экспорт

- Локальный экспорт: MP4 и GIF. Разрешения 480p, 720p, 1080p, 4K. Free ограничен 720p.
- Водяной знак Descript в правом нижнем углу на экспорте с Free. Hobbyist, Creator, Business его убирают, старые видео нужно переэкспортировать.
- Экспорт таймлайна: Premiere Pro (XML), DaVinci Resolve (XML), Final Cut Pro (FCPXML), Reaper (EDL), Audition (SESX), Pro Tools/Logic (AAF). Только тарифы Creator, Business, Enterprise. Субтитры: SRT и VTT (индекс справки).
- Частота кадров не проверена.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://www.descript.com/pricing). Цены на человека в месяц, USD, при оплате за год и помесячно.

- Free: $0. 1 час медиа в месяц, 100 разовых кредитов ИИ, 720p с водяным знаком, 5 ГБ.
- Hobbyist: $16 за год ($24 помесячно). 10 часов медиа, 400 кредитов, 1080p без водяного знака, Underlord, Studio Sound, 100 ГБ.
- Creator: $24 ($35). До 3 мест, 30 часов, 800 кредитов, 4K, 1 ТБ, ИИ-генерация видео, стоковая библиотека.
- Business: $50 ($65). До 5 мест, 40 часов, 1500 кредитов, перевод и дубляж на 30+ языков.
- Enterprise: по запросу.
- Оценка стоимости 1 по тарифу Hobbyist при оплате за год. Для экспорта таймлайна нужен Creator.

## Активность и зрелость

Зрелость: stable. Продукт коммерческий, функции Underlord и API обновляются часто (в справке Underlord назван Beta). Развивает компания Descript.

## Когда брать и когда нет

- Брать: запись диктора или скринкаста нужно быстро расшифровать, почистить и отдать редактору. Для текстового монтажа черновика.
- Брать Creator: если нужен экспорт таймлайна в Premiere, Resolve или Final Cut.
- Не брать: для анимированной графики, непрерывных сцен и ИИ-голоса (синтез речи только в ElevenLabs).
- Не брать, если контент нельзя отдавать облаку или нужен воспроизводимый пайплайн из кода ([FFmpeg](ffmpeg.md), [auto-editor](auto-editor.md)).
