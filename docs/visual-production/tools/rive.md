# Rive

Векторный редактор анимации с машинами состояний и открытыми рантаймами. Создан для интерфейсов, игр и интерактивных сцен. У него есть текстовый формат сцены (RML), командная строка и встроенный ИИ-агент. Видео получают отдельно, через облачный рендер редактора.

## Что реально получается

- Векторные сцены: фигуры, пути, кости, IK, сетки для растровых картинок, обрезка пути (Trim Path), текст с модификаторами, звук и события звука. Всё это в списке документации.
- Рисование линий: Trim Path анимирует длину обводки. Это даёт «вычерчивание» линии без ручных кадров.
- Непрерывность сцены: один артборд и одна временная шкала на сцену, машины состояний переключают анимации. Машины состояний переключают анимации; для линейного видео хватает одной анимации на шкале.
- Морфинг и камера: страницу про морфинг фигур и объект камеры в индексе документации не нашёл. Движение «камеры» делают анимацией родительской группы.
- Покадровая рисованная анимация (флипбук, калька) в документации не описана: инструмент векторный и ключевой, не как Harmony или TVPaint.
- Видео: облачный рендер редактора выдаёт H.264, GIF, последовательность PNG или SVG, WebM; настройки частоты кадров, длительности, битрейта и размера. Звук в видеофайле не проверен.
- Командная строка рендерит один кадр в PNG (`--screenshot`, `--advance` двигает время). Видео из неё собирают сами, например через [ffmpeg](ffmpeg.md).
- Синхронизация с голосом: есть аудиоассеты и аудиособытия. Готового редактора меток по озвучке и липсинка в индексе документации нет.

## Слабые стороны

- Видео можно только на платном тарифе, рендер идёт в облаке Rive через интерфейс редактора, не из командной строки.
- Инструмент ориентирован на интерактив. Для объясняющего видео половина его возможностей (состояния, привязка данных, скрипты) не нужна.
- ИИ-агент редактора и MCP работают только на платных тарифах и в десктопном редакторе (MCP: macOS и Windows). Точное правило разных страниц расходится, см. «Неизвестно».
- Дата выхода CLI, RML и агента не установлена; документация MCP прямо говорит, что список функций будет расти.

## Сложность

- Для человека (3 из 5): интерфейс похож на After Effects и Figma, но состояния, привязка данных и макеты — отдельное знание. Готовую линейную анимацию освоить можно за недели.
- Для агента (2 из 5): сцена пишется текстом RML, проект `rive create` приходит с `AGENTS.md` и `CLAUDE.md`, есть `--verify`, `inspect` и скриншот кадра. Агент сам собирает и проверяет сцену. Руки нужны для видео-рендера в облаке и для оценки вкуса.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): CLI на Linux x86_64, macOS (Apple Silicon) и Windows, сборка `.riv` без окна, тесты скриптов, синхронизация с файлом аккаунта (`push`, `pull`). Видео-рендер не автоматизирован.
- Воспроизводимость (4 из 5): проект CLI — папка с текстом и ассетами, которая видна git. Редакторский `.rev` двоичный. Побитовую одинаковость кадров на разных видеокартах не проверял.

## Платформа и оборудование

Редактор в браузере (editor.rive.app) и десктопный для macOS и Windows. CLI для macOS на Apple Silicon, Linux x86_64 и Windows. Требования к видеокарте в просмотренной документации не названы.

## Экспорт

- Для рантайма: `.riv` (с заставкой на бесплатном тарифе).
- Видео и картинки: H.264 (MP4), GIF, PNG и SVG последовательности, WebM, одиночные PNG и SVG. Доступно на платных тарифах.
- Альфа-канал в видео, максимальное разрешение и частоту кадров документация не называет.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://rive.app/pricing). Цена указана за место в месяц. В тексте страницы нет разницы между годовой и месячной оплатой, переключатель есть.

- Free, $0: редактор и CLI, экспорт `.riv` с заставкой Rive, 3 совместных файла, агент с лимитами.
- Cadet, $9: без заставки, неограниченные файлы, до 3 мест. Видео и изображения доступны на платных тарифах по [документации](https://rive.app/docs/editor/exporting/exporting-for-video-and-static-design), значит с Cadet.
- Voyager, $32: библиотеки, хостинг встраивания, агент с расширенными моделями, $20 в месяц кредитов ИИ на место, до 25 мест.
- Enterprise, $120: пометка «$10M+ годового дохода», $40 кредитов на место, SSO.

## Когда брать и когда нет

- Брать: аккуратные векторные схемы, подписи, анимированные иконки и персонажи на костях, когда нужны и ролик, и интерактивная версия того же ассета; когда агент должен собирать сцену текстом.
- Не брать: рисованные кадры «от руки» и смазывание (smear) — смотри [toon-boom-harmony](toon-boom-harmony.md), [tvpaint](tvpaint.md); математическую анимацию и формулы — [manim-ce](manim-ce.md); если видео надо рендерить в пакетном режиме без интерфейса.

## Неизвестно

- Входит ли звук в видео из облачного рендера, и какое максимальное разрешение и частота кадров.
- Какой тариф даёт видео: документация пишет «платные тарифы», страница цен список экспорта не называет. Cadet вывел по формулировке.
- Агент: страница цен даёт «Agent with limits» на Free, документация агента пишет про Cadet, Voyager и Enterprise.
- Лицензия CLI и условия бинарных сборок редактора.
- Умеет ли Rive морфинг между фигурами с разным числом точек и есть ли готовый липсинк.
- Содержание роликов-примеров оценено по названию и описанию.
