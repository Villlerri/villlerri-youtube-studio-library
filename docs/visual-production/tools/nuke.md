# Nuke (Foundry)

Отраслевой узловой композитор для кино и VFX. Семейство: Nuke, NukeX, Nuke Studio, Nuke Indie, Nuke Non-commercial. Версия 17.1 (август 2026).

## Что реально получается

Опора: страница семейства Nuke, пресс-релиз Nuke 17.0, обзор Nuke 17.1 (CG Channel).

- Nuke: больше 200 узлов, глубокий композитинг (deep), 3D-проекции окружения. NukeX добавляет трекинг 3D-камеры, очистку кадра, узлы машинного обучения (CopyCat, Inference). Nuke Studio — NukeX плюс Hiero: таймлайн, управление планами, экспорт в сценарии Nuke.
- Nuke 17.0 (26 февраля 2026): 3D-система на USD вышла из беты, нативные гауссовы сплаты (импорт, просмотр, рендер, экспорт), узлы Field для 3D-данных, BigCat для обучения на многих планах, ACES 2.0.
- Nuke 17.1 (август 2026): анимированные сплаты, переосвещение сплатов, Hydra 2.0 в 3D-просмотре, обновления аннотаций в Nuke Studio.
- Для ролика: сложная сборка живой съёмки и CG, чистка кадра, продвинутый кеинг и трекинг. Для объясняющих роликов избыточен.
- Непрерывная сцена: 3D-система с камерами и проекциями ведёт кадр без склеек. Это возможность инструмента, готовых примеров для объясняющих роликов не нашёл.
- Морфинг, рисование линий, синхронизация с голосом: в описании семейства таких функций нет.

## Слабые стороны

- Цена. Коммерческие версии от €3,139 в год.
- Non-commercial: вывод ограничен 1920x1080, MPEG4 и H.264 выключены, внешние плагины не принимаются, шифруются сценарии `.nk`, Python видит не больше 10 узлов на скрипт, командная строка принимает только зашифрованные `.nknc`.
- Non-commercial: только для личного, учебного и некоммерческого использования. Версия работает 180 дней после выхода.
- Linux: платформа указана как Rocky Linux 9.0 (CG Channel, вторичный источник).
- Для Indie проект открывается только в Indie и Non-commercial.

## Сложность

- Для человека (5 из 5): профессиональный узловой инструмент, месяцы. Оценка автора карточки.
- Для агента (3 из 5): в коммерческих версиях есть Python-интерфейс и командный рендер (по ограничениям Non-commercial, которые их упоминают). Проверка запуском не проводилась. Non-commercial и Indie режут Python (10 узлов и 10 команд), поэтому для агента нужна коммерческая лицензия.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): Python API, командный рендер, Nuke Render для ферм (€416 в год), Graph Scope Variables с Python-колбэками в 17.0.
- Воспроизводимость (3 из 5): сценарии `.nk` в документации названы скриптами (в Non-commercial шифруются). Текстовый ли это формат в коммерческой версии, не проверено.

## Платформа и оборудование

- Windows 11, Rocky Linux 9.0, macOS 15.0 и новее (CG Channel про 17.1).
- Требования к видеокарте и памяти не найдены.

## Экспорт

- Non-commercial: до 1920x1080, MPEG4 и H.264 выключены. Нет экспорта EDL, OTIO, XML.
- Nuke Indie: до 4K.
- Список форматов коммерческой версии не читал.

## Стоимость

Проверено 2026-10-14 по [странице Nuke](https://www.foundry.com/products/nuke-family/nuke) и [Nuke Indie](https://www.foundry.com/products/nuke-family/nuke-indie). Страница показывает евро, налоги отдельно.

- Nuke: €3,139 в год, €366 в месяц (не везде), €1,719 в квартал.
- NukeX: €4,759 в год. Nuke Studio: €5,799 в год. Nuke Render: €416 в год.
- Nuke Indie: €449 в год. Условия: доход меньше $100 000 в год, одна лицензия на пользователя, нельзя использовать в конвейере с коммерческими лицензиями Nuke.
- Для справки: [CG Channel](https://www.cgchannel.com/2026/08/foundry-releases-nuke-17-1/) называет $3,839 (Nuke), $5,219 (NukeX), $6,379 (Nuke Studio), $499 (Indie). Вторичный источник.
- Non-commercial: бесплатно. Foundry называет его «бесплатными версиями без водяных знаков».

## Активность и зрелость

Зрелость: standard. Nuke 17.0 вышел 26 февраля 2026, Nuke 17.1 в августе 2026. Foundry выпускает основные и промежуточные версии (в том же месяце 16.1 и 17.0 вышли параллельно).

## Когда брать и когда нет

- Брать: студия уже работает в VFX-конвейере, нужен глубокий композитинг и сплаты.
