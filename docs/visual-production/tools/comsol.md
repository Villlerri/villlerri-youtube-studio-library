# COMSOL Multiphysics

Коммерческая платформа мультифизического конечно-элементного моделирования. Магнитные задачи решает модуль AC/DC (надстройка к платформе). Сильна готовой постановкой задачи, постпроцессором и экспортом анимаций.

- Документация: <https://doc.comsol.com/6.4/docserver/>

  - [Permanent Magnet Simulation in COMSOL Software – Complete Tutorial](https://www.youtube.com/watch?v=gk90QXYAjjc) — урок канала Learn with BK: 2D-модель постоянного магнита от геометрии до карты поля, около 15 минут. Не ролик COMSOL.

## Что реально получается

Сквозной пример (магнит на холодильнике). Модуль AC/DC в магнитостатике поддерживает мягкие материалы с кривой B-H, постоянные магниты, анизотропные материалы, гистерезис (страница модуля). Значит, стальная дверь с насыщением (кривая B-H) считается честно. Полосатый магнит — набор доменов с разной остаточной индукцией. Готового примера гибкого многополюсного магнита на странице модуля и в найденном примере Permanent Magnet нет; пример с постоянным магнитом и железным стержнем есть.

Что получается на выходе:

- Карты модуля поля, линии тока (streamline), стрелки, срезы, изоповерхности. Постпроцессор встроен.
- Анимации: узел Animation в Export. Куда: GIF (по умолчанию), AVI, WebM или последовательность PNG, BMP, JPG. Частота по умолчанию 10 кадров в секунду, можно менять. PNG может быть 16 бит на канал. Есть режим плеера прямо в окне.
- Кадры анимации берутся по шагам времени или собственным значениям (описание узла Animation). Перебор параметра, например зазора между магнитом и дверью, в проверенных страницах не описан.
- Движение, морфинг, камера: анимация идёт по шагам времени; управление камерой в проверенных страницах не описано. Непрерывность между сценами — на стороне монтажа.
- Рисование линий: линии поля есть как готовый график, не растут сами.
- Голос: нет.

Вид картинок по умолчанию инженерный. Для ролика кадры обычно выгружают как PNG-последовательность и обрабатывают в монтажной программе или рисуют заново по экспортированным данным в [paraview](paraview.md) или [matplotlib](matplotlib.md).

## Слабые стороны

- Цена не публичная. Ожидаемо это самый дорогой инструмент класса (оценка, не факт). Магнитный модуль AC/DC — надстройка (add-on) к базовой платформе.
- Модель хранится в двоичном `.mph`. Править в git сложно.
- Скрипты: LiveLink for MATLAB (отдельный продукт) и методы на Java в Application Builder. Полный пакетный режим из командной строки в проверенных страницах не подтверждён.
- Нужна действующая лицензия: без неё агент не запустит расчёт.
- Правила использования академической лицензии для ролика на монетизируемом канале на проверенных страницах не найдены.

## Сложность

- Для человека (4 из 5): программа профессиональная, но интерфейс единообразный и сильно ведёт за руку. Освоение магнитных моделей занимает недели.
- Для агента (4 из 5): основной путь — мышь и дерево модели. Автоматизация идёт через Java или MATLAB, а это отдельная работа и отдельная лицензия. Агент не может сам проверить рендер без лицензии.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): LiveLink for MATLAB позволяет управлять геометрией, сеткой, физикой, расчётом и постобработкой из скрипта. Java-методы в приложениях. Командная строка и пакетный режим не проверены.
- Воспроизводимость (3 из 5): файл `.mph` воспроизводит результат, но он двоичный. Версии программы совместимы не всегда.

## Платформа и оборудование

Версия 6.4, обновление 3 (6.4.0.429). Windows 10 и 11, macOS (Apple silicon, M1 и новее), Linux (включая ARM64). Минимум 4 ГБ оперативной памяти по системным требованиям, для 3D-задач с магнитами нужно значительно больше. GPU-ускорение есть для части решателей.

## Когда брать и когда нет

- Брать: уже есть лицензия, нужны достоверные расчёты со сталью, нелинейностью и связанной физикой (нагрев катушки, силы), или нужен быстрый результат через параметрическую развёртку.
- Не брать: нужен воспроизводимый открытый конвейер для агента и бюджет ограничен. Тогда [elmer-fem](elmer-fem.md), [femm](femm.md) или [magpylib](magpylib.md).
