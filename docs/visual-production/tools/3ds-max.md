# Autodesk 3ds Max

Профессиональная 3D-программа Autodesk для моделирования, анимации и рендера. Сильна жёстким моделированием (hard surface) и работой с модификаторами, плагинами (tyFlow, thinkingParticles, Forest Pack), визуализацией архитектуры и предметов. В комплекте рендер Arnold. Работает только в Windows. Для канала с Blender это дорогая альтернатива, оправданная только если команда уже живёт в экосистеме Autodesk или нужен определённый плагин.

## Что реально получается

- Моделирование: булевы операции, ретопология, стек модификаторов с параметрическим возвратом к шагам. Предметы, механизмы и устройства получаются точно и аккуратно.
- Анимация: Biped и Character Animation Toolkit (CAT) для персонажей, ключи и кривые, процедурные модификаторы. Объекты можно связать, и они обновляются при движении других.
- Рендер: Arnold (встроен, CPU и GPU), Arnold RenderView в реальном времени, сторонние рендереры вроде V-Ray. Физическая камера (выдержка, диафрагма, глубина резкости), OpenColorIO.
- Обмен: OpenUSD (импорт и экспорт, слои, варианты), публикация в glTF. Версия 2027 (последний выпуск по Википедии 2027.1 от 2026-05-21).
- Для объясняющих сцен: «устройство предмета» (разрезы, сборки, механизмы), масштабные переходы камеры, красивый свет и материалы. Плавная камера по кривым, один длинный план — стандартные задачи программы.
- Невидимые поля, потоки: через плагины (tyFlow для частиц) и модификаторы, готового набора для силовых линий нет, в отличие от [blender-geometry-nodes](blender-geometry-nodes.md).
- Синхронизация с озвучкой и рисование линий «вживую»: готовых инструментов нет, всё вручную или скриптом.

## Слабые стороны

- Только Windows. На Linux и macOS программа не запускается.
- Дорогая подписка: $255 в месяц или $2010 в год. Дешёвого пути для коммерческого канала нет, кроме Indie с ограничениями.
- Интерфейс и рабочий процесс тяжёлые, учиться месяцами.
- Проект в двоичном формате `.max`, под git плохо.
- Требует вход в учётную запись Autodesk. Установка на три компьютера, но использовать может только один пользователь на одном компьютере одновременно.
- Агентская автоматизация слабее, чем у [blender](blender.md): запуск без окна возможен, но программа лицензируется и тяжёлая.

## Сложность

- Для человека (4 из 5): профессиональный пакет. На базовые кадры уходят недели, до уверенного результата месяцы. Много обучающих материалов, включая официальный канал Autodesk.
- Для агента (3 из 5): есть скриптинг (страница возможностей 2027 называет поддержку Python 3; MAXScript известен по Википедии), значит сцену можно собрать кодом. Но программа тяжёлая, лицензия привязана к пользователю, визуальный контроль и вкус остаются за человеком.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): Python 3 и скрипты (страница возможностей 2027: «Get tighter pipeline integration and scripting with support for Python 3»), полностью программируемая запечка текстур, плагины и SDK. MAXScript известен по Википедии, на странице Autodesk его не нашёл. Командный рендер без окна есть в документации Autodesk, но справка строится скриптом, и я её не читал.
- Воспроизводимость (3 из 5): проект двоичный, результат воспроизводится при той же версии и плагинах. Скрипты сцены дают воспроизводимый вход, но лицензия и плагины усложняют CI.

## Платформа и оборудование

Windows 11 (и Windows 10 по странице обзора). Для версии 2027 в системных требованиях: 64-разрядный процессор Intel или AMD с SSE4.2, минимум 4 ГБ памяти (рекомендуется 8 ГБ и больше), 9 ГБ на диске, трёхкнопочная мышь, видеокарта из списка сертифицированных.

## Экспорт

- Рендер Arnold: последовательности кадров (PNG, EXR — стандартные форматы изображений); форматы видео из рендера не проверял.
- Обмен: OpenUSD, glTF (публикация для веба). Остальные форматы обмена не проверял.
- Разрешение и частота кадров определяет сцена. Альфа-канал в этих форматах возможен, настройки в программе не проверял.

## Стоимость

Проверено 2026-10-14 по [странице 3ds Max](https://www.autodesk.com/products/3ds-max/overview) (снимок web.archive.org от 2026-10-10).

- Месяц: $255. Год: $2010 (скидка 33% к помесячной цене, «starting at $168 / month» на странице считается от годовой). Три года: $6025.
- Бесплатный пробный период 30 дней.
- Flex: токены, оплата по дням использования (цены не проверял).
- Студенты и преподаватели: бесплатный доступ на год через Autodesk Education Community. Только для обучения.
- 3ds Max Indie: те же возможности по более низкой цене, только годовая подписка, нет пробного периода, только в списке стран, годовой доход от творческой работы ниже $100 000, проекты стоимостью до $100 000, одна лицензия на пользователя или организацию. Работа по найму для организации с оборотом больше $100 000 запрещена. Цену на странице не нашёл (подставляется скриптом).

## Лицензия и права

- Код или программа: проприетарная, подписка с лицензионным соглашением Autodesk (установка до трёх компьютеров, вход один пользователь).
- Результат: Indie прямо разрешает коммерческое использование в рамках условий (доход ниже $100 000). Студенческая лицензия только для обучения. Для полной подписки условий на результаты на страницах не нашёл, ограничений на ролики и монетизацию YouTube в описании нет.
- Ассеты в комплекте: Arnold, материалы и библиотеки в комплекте, их условия отдельно не проверял. Плагины третьих сторон (tyFlow, Forest Pack) платные отдельно.

## Активность и зрелость

Репозитория нет, цифры GitHub не собираются.

Зрелость: `standard`. Продукт с 1990 года (3D Studio для DOS, по Википедии), актуальная версия 3ds Max 2027, последний выпуск 2027.1 от 2026-05-21 (Википедия, вторичный источник). Развивает Autodesk, ежегодный цикл выпусков. На странице есть Autodesk Assistant (Tech Preview): ИИ-помощник по документации прямо в программе, не управляет сценой.

## Когда брать и когда нет

- Брать: команда уже работает на 3ds Max и Windows; нужны плагины (tyFlow, Forest Pack, thinkingParticles) или стандарт Autodesk; сложная сцена с точными устройствами.
- Не брать: новый канал с ограниченным бюджетом ([blender](blender.md) бесплатен и лучше для агента); работа на Linux или macOS; сцены с формулами, схемами и полями ([manim-ce](manim-ce.md), [blender-geometry-nodes](blender-geometry-nodes.md)). Если нужна анимация персонажей и вы на Autodesk, смотрите также [maya](maya.md).
