# LTX-Video (LTX-2.5)

Открытые видеомодели Lightricks. Развитие перенесено из репозитория LTX-Video в LTX-2: текущая версия LTX-2.5 (веса на Hugging Face обновлялись 2026-10-11) делает видео со звуком, поддерживает несколько ключевых кадров и работает локально.

## Что реально получается

Опора: README LTX-2, документация docs.ltx.io, лицензия. Генераций я не запускал.

- LTX-2.5: текст, картинка или звук в видео; синхронный звук в одном проходе. Модель 22B (distilled transformer), текстовый кодировщик Gemma. Размер загрузки по README около 66 ГБ.
- Ключевые кадры: `KeyframeInterpolationPipeline` (интерполяция между ключевыми картинками), в API `last_frame_uri` для картинки в видео и звука в видео. Это инструмент бесшовных переходов между нарисованными кадрами.
- Нативный мультикадр: одно обращение создаёт несколько связанных планов, герой, сцена, свет, стиль и голос держатся через склейки (заявление документации API).
- Конвейеры в репозитории: DistilledPipeline (быстрый), DFR (качество «production»: ключевые кадры плюс прорисовка, до 2× и 4× по частоте кадров), IC-LoRA (управление по референсу), A2Vid (звук в видео), Dub-It, продление и правка.
- Разрешение: по умолчанию 1024×1536, 24 кадра в секунду; UHD 3840×2176. Количество кадров формата 8k+1 (121 кадр = около 5 секунд). API: ltx-2-5-fast 6–20 секунд на 720p и 1080p при 24–25 кадрах, 6–10 секунд при 48–50; ltx-2-5-pro 6–10 секунд до 4K.
- HDR и EXR: стандартные конвейеры принимают EXR-кадры, пишут половинчатые EXR и мастер BT.2020 HLG.
- Камера: параметр `camera_motion` в API, в локальной версии управление текстом.
- Вывод автора: из открытых моделей у LTX самый богатый набор для управляемых переходов (ключевые кадры, IC-LoRA, EXR). Тот же класс рисков: физика, надписи.

## Слабые стороны

- Видеопамять: минимум 32 ГБ и больше (рекомендуется A100 80 ГБ или H100), 32 ГБ оперативной памяти, 100 ГБ диска, CUDA 12.7+, Python 3.12+ (страница System Requirements). Квантование `fp8-cast` и вынос на CPU или диск ослабляют требование, ценой скорости.
- Лицензия с порогом выручки (см. ниже). На крупную студию он может распространиться.
- Лицензия обязывает сохранять встроенные метки и раскрывать использование ИИ там, где это требуют законы.
- Продление и правка (`retake`, `extend`) у LTX-2.3 есть в API, у LTX-2.5 в таблице документации стоят прочерки.
- Старая версия LTXV 0.9.x даёт меньшее качество; на неё не ссылаться.
- Установка не выполнялась (по правилам библиотеки), совместимость зависимостей не проверена.

## Сложность

- Для человека (4 из 5): Python, CUDA, большие веса, конвейеры с флагами или ComfyUI.
- Для агента (2 из 5): `uv run python -m ltx_pipelines.distilled ...` из командной строки; агент подбирает параметры, смотрит кадры. Нужна машина с мощной видеокартой, веса скачиваются вручную после принятия условий.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): командная строка, пакеты `ltx-pipelines` и `ltx-trainer`, ComfyUI-узлы (встроены в ядро ComfyUI), API с асинхронными задачами, настольное приложение LTX-Desktop.
- Воспроизводимость (3 из 5): `--seed` и фиксированные веса. Детерминизм между видеокартами не проверялся; лицензия разрешает владельцу обновлять модель по сети («использовать последнюю версию»).

## Платформа и оборудование

Linux с CUDA для лучшей скорости (backend `natten`); Windows и macOS поддержаны с запасным декодированием. Рекомендуется NVIDIA 32 ГБ и выше. Облако: API Lightricks (console.ltx.video).

## Экспорт

- MP4 (`--output-path output.mp4`). EXR-кадры (половинчатые) с мастером HLG. До 4K, 24–50 кадров в секунду.
- Альфа-канала в источниках нет.

## Стоимость

Проверено 2026-10-14 по [ценам API](https://docs.ltx.io/pricing.md).

- Локально: бесплатно, оплачивается железо. Оценка стоимости 0 (при выручке до $10 млн).
- API, секунда видео, текст или картинка в видео: ltx-2-5-fast 720p $0.09, 1080p $0.13, 1440p $0.19, 4K $0.30; ltx-2-5-pro $0.12, $0.17, $0.25, $0.39. Старая ltx-2-3-fast от $0.03.
- Пример расчёта: 60 секунд вставок в 1080p, 5 попыток на клип, ltx-2-5-fast через API = 300 секунд × $0.13 = $39.

## Когда брать и когда нет

- Брать: локальная генерация вставок со звуком, переходы по нескольким ключевым кадрам, EXR для композитинга, обучение LoRA под свой стиль.
- Брать, если выручка студии заведомо меньше $10 млн и нужна свобода от поминутной оплаты.
- Не брать: научные сцены с точной физикой и надписями; слабая видеокарта.
- Не брать без юридической проверки, если выручка организации может превысить порог.
