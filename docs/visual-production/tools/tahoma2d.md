# Tahoma2D

Ответвление (форк) [OpenToonz](opentoonz.md) с упрощённым интерфейсом, захватом для покадровой съёмки и ежемесячными выпусками. Те же корни: рисованная и кукольная анимация, эффекты. Проще в освоении.

## Ссылки

- Официальный сайт: https://tahoma2d.org
- GitHub: https://github.com/tahoma2d/tahoma2d
- Сравнение с OpenToonz: https://tahoma2d.org (раздел «Tahoma2D vs. OpenToonz» на главной)
- Примеры, проверенные 2026-10-14 (ролики открывались через oEmbed, содержание описано по названию, не смотрел; все сторонние):

  - [Tahoma2D Keyframing Basics](https://www.youtube.com/watch?v=k4NP2WmZRnE) — канал David Hurwich, ключевые кадры и промежуточные кадры.

## Что реально получается

- Всё, что у OpenToonz: уровни, калька, ключевые кадры, вырезная анимация, эффекты и частицы. Плюс отличия, которые перечисляет сайт: упрощённое рабочее пространство, управление наборами стилей, кисти с наклоном, неявное удержание кадров (рисунок держится до следующего), перспективная сетка, инструмент симметрии, заливка с учётом других слоёв, живые маски обрезки.
- Автоматический липсинк через Rhubarb Lip Sync и покадровая съёмка со всеми поддержанными камерами (DSLR на Windows, macOS, Linux) — указаны на главной странице.
- Экспорт в MP4 и GIF без установки дополнительных библиотек.
- Для объясняющего видео: рисованный персонаж, говорящий под озвучку (с липсинком), и «живые» руки, рисующие объекты. Морфинг форм, камеры с глубиной и рисование линий автоматически в просмотренных страницах не описаны.
- Плавность переходов — вручную: ключевые кадры, кривые, ровное удержание.

## Слабые стороны

- Малое сообщество, документация скромнее, чем у платных пакетов. Раздел «Learn» на сайте не открывал; найденные уроки на YouTube — от энтузиастов.
- Проект не принимает код, написанный ИИ (файл AI_POLICY.md в репозитории). На использование в роликах это не влияет.
- Платформы на сайте перечислены неполно: в системных требованиях только Windows и macOS, в релизах есть сборки для Linux.

## Сложность

- Для человека (3 из 5): интерфейс проще, чем у OpenToonz, но рисованная анимация требует навыков. Базовый мультфильм по урокам собирают за недели.
- Для агента (4 из 5): интерфейс графический, как у OpenToonz. Агент не создаёт анимацию, но готовит ассеты (звук, меток липсинка) и пакетно рендерит готовое.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): код унаследован от OpenToonz, куда входят ToonzScript и очередь рендера. Работа скриптов именно в Tahoma2D не проверялась.
- Воспроизводимость (2 из 5): сцена — папка с проектом, формат как у OpenToonz. Для git не приспособлен.

## Платформа и оборудование

Сайт: Windows 8.1/10/11 (64 бита), macOS 15 (Sequoia) и новее, процессор Intel Core i-серии или лучше, 4 ГБ памяти, 500 МБ диска, монитор от 1280×1024. Релиз 1.6.3 содержит установщик и портативную сборку для Windows, портативные сборки для macOS (Intel и Apple Silicon) и пакеты для Linux (`.deb`, `.tar.gz`). Программа портативная: старые версии можно держать рядом.

## Экспорт

## Когда брать и когда нет

- Брать: бесплатная студия рисованной анимации и вырезных кукол для канала, где персонаж говорит под озвучку; быстрее старт, чем у [opentoonz](opentoonz.md).
- Не брать: для сложного риггинга и композитинга ([toon-boom-harmony](toon-boom-harmony.md)), для векторных костей с твинингом ([synfig](synfig.md)), для схем и графиков.
