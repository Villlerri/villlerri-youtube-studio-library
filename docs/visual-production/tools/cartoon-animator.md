## Что реально получается

- Кукольные персонажи из картинок: из изображений, PSD и векторных рисунков (SVG в обе стороны) собирают куклу с костями. Персонажи G3 строятся на костях, умеют поворот головы на 360 градусов.
- Живое управление: Motion Pilot (перетаскивание мышью), движение по траектории, пружинная динамика, деформация свободной формы (FFD), эластичные эффекты, лицо и тело по веб-камере или iPhone, захват движения (Rokoko, Perception Neuron) — по таблице сравнения версий.
- Липсинк: «Audio Lip-sync» для спрайтовых и морфовых персонажей — готовый вариант синхронизации с голосом.
- Эффекты и сцена: 2D-эффекты, 3D-параллакс, импорт 3D-движений в 2D, импорт видео, звука и SWF-векторов.
- Библиотека: 1700+ встроенных ассетов, магазин контента Reallusion.
- Объект камеры и морфинг фигур в таблице версий не названы.
- Для объясняющего видео: ведущий-персонаж или комментатор, который говорит по озвучке; быстрые кукольные сцены без рисования. Результат легко узнаётся как кукольный.

## Слабые стороны

- Страница загрузки называет только Windows 64 бита. В таблице экспорта есть строка «MOV ProRes 4444 — Mac only», поэтому версия для Mac, возможно, существует, но страница её не показывает.
- Видеоэкспорт (WMV, AVI, MP4, popVideo3) помечен как «PC only».
- В таблице версий нет скриптов и пакетной работы. Для связки с After Effects есть скрипт «After Effects Script for CTA».
- Для интернет-активации требуется соединение; в подписочной версии связь нужна постоянно.
- Готовые персонажи и движения узнаваемы, ролики похожи друг на друга.

## Сложность

- Для человека (2 из 5): интерфейс рассчитан на новичков, первый говорящий персонаж за день. Свой стиль потребует подготовки слоёв в Photoshop или векторе.
- Для агента (4 из 5): графический интерфейс. Агент может готовить слои персонажа и озвучку, куклу и сцену собирает человек.

## Автоматизация и воспроизводимость

- Автоматизация (1 из 5): API и командной строки в просмотренных страницах нет. Есть захват с веб-камеры и экспорт в After Effects скриптом.
- Воспроизводимость (2 из 5): проект в собственном формате; рендер воспроизводится при той же версии. Проект с контентом Reallusion при передаче клиенту может показывать DRM-водяной знак, см. «Права».

## Платформа и оборудование

Windows 7 SP1, 8, 10, 11, только 64 бита. Рекомендуется Intel Core i5 7-го поколения, 8 ГБ памяти, GeForce GTX 650 или Radeon HD 4890, 2 ГБ видеопамяти, SSD, 10 ГБ диска, монитор 1920×1080; минимум Core i5 2-го поколения, 2 ГБ памяти. Нужен интернет для установки и активации ([страница загрузки](https://www.reallusion.com/cartoon-animator/download.html)).

## Экспорт
