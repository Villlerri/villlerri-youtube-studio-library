# Runway

Облачная студия и API генеративного видео. Свои модели Gen-4.5 (видео из текста и картинки) и Aleph 2.0 (правка готового клипа) плюс десятки чужих моделей в одном аккаунте: Kling 3.0, Veo 3.1, Seedance 2.5, Wan 3.0, Gemini Omni Flash, MiniMax H3.

## Ссылки

- Официальный сайт: <https://runway.com>
- GitHub: открытого кода нет.
- Документация API: <https://docs.dev.runwayml.com> (список моделей, цены, справочник параметров)

  - [Creating an AI Short Film (Full Workflow) | Runway](https://www.youtube.com/watch?v=TM8hd2lnrEk) — официальный канал Runway, разбор сборки короткометражки. Ссылка открывается через oEmbed, содержание по названию.
  - [Consistent AI Characters, Voices and Scenes (Advanced Workflow)](https://www.youtube.com/watch?v=swx780Vy_OQ) — тот же канал, про постоянство героев между сценами. Содержание по названию.

## Что реально получается

Опора: справочник API и страница Gen-4.5. Роликов целиком я не просматривал, оценки идут по документации.

- Gen-4.5: текст в видео и картинка в видео, 2–10 секунд, один клип за запрос. Разрешение 1280×720 и 720×1280; для картинки в видео ещё 1104×832, 960×960, 832×1104, 1584×672. Параметр `seed` есть, но документация обещает лишь «похожий» результат при том же значении.
- Картинка в видео у Gen-4.5 задаёт только первый кадр (`position: first`). Последнего кадра в схеме запроса нет. Для бесшовного перехода между сценами это слабое место.
- Первый и последний кадр есть у Veo 3.1 внутри Runway (в документации API: первый кадр и необязательно последний, 4, 6 или 8 секунд, звук включается флагом).
- Aleph 2.0: правка готового клипа до 30 секунд, до 5 ключевых изображений на заданных секундах, расширение кадра под другой формат. Подходит, чтобы поправить объект или фон, не пересоздавая сцену. Прозрачности нет: альфа-канал в ProRes 4444 присутствует, но непрозрачный.
- Согласованность объектов: производитель сам называет «Object permanence» слабым местом Gen-4.5 (предмет может исчезнуть после перекрытия). Стабильный герой между клипами держится на картинке-первом-кадре и на моделях с опорой на ссылки. Например, у Kling 3.0 в собственном API Kling можно задать до 3 «элементов», а в Runway модель принимает мультикадровые подсказки.
- Камера: отдельных параметров движения камеры в схеме Gen-4.5 нет, управление идёт текстом подсказки (до 1000 символов). Вывод по схеме API, веб-интерфейс не открывался.
- Синхронизация с голосом: в схеме запроса Gen-4.5 нет параметра звука. Звук есть у Veo 3.1, Kling 3.0, Seedance. Привязки клипа к дикторской дорожке нет, длину подгоняют вручную.
- Вывод автора: подходит для атмосферных вставок (космос, лес, лаборатория). Для схем, формул, подписей и точной физики не подходит, см. слабые стороны.

## Слабые стороны

- Производитель перечисляет ограничения Gen-4.5: следствие раньше причины (дверь открывается до нажатия ручки), пропадающие и появляющиеся предметы, «успех любого действия» (неточный удар всё равно забивает гол). Для научпопа это значит неверные причинно-следственные цепочки.
- Клип до 10 секунд (Kling 3.0 внутри Runway до 15, Seedance 2.5 до 30). Длинная сцена собирается из кусков, на стыках скачет цвет и положение предметов. Это вывод по документации, не проверено на практике.
- Стоимость идёт в секундах результата, а не удачных попыток. Тариф Standard даёт 52 секунды Gen-4.5 в месяц.
- По условиям Runway вправе использовать ваши входные данные и результаты для обучения своих моделей.
- Ссылки на результаты API временные: файл нужно скачать сразу.

## Сложность

- Для человека (2 из 5): веб-интерфейс, достаточно уметь писать подсказки. Контроль над результатом слабый, нужны повторы.
- Для агента (2 из 5): REST API с асинхронными задачами (запрос, опрос статуса, скачивание). Агент пишет запросы и проверяет кадры сам. Руки нужны для оплаты и ключа. Платные вызовы агенту нужно явно разрешать.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): REST API и SDK, список из 26 видеомоделей по единому интерфейсу, форматы выдачи mp4, ProRes, PNG-последовательность, HDR-варианты и EXR (для Gen-4.5). Пакетный запуск задач возможен, лимиты зависят от уровня организации (страница уровней в документации не читалась).
- Воспроизводимость (2 из 5): `seed` задаётся, но результат не гарантируется тем же. Версии моделей меняются со временем, а закрытая модель не лежит у вас в git.

## Платформа и оборудование

Браузер, приложения для iOS и Android, API. Локального запуска нет. GPU не нужна.

## Экспорт

- Gen-4.5 через API: `mp4` (H.264, по умолчанию), `prores` (MOV, профили 422 и 4444), `png_sequence` (ZIP с кадрами), HDR-форматы (`hdr10`, `hlg`, 10-битный Rec.709, ProRes HDR, EXR-последовательности).
- За ProRes и PNG-последовательность в API прибавляется 5 кредитов в секунду, за 10-битный и HDR 20 (40 при размере больше 4 мегапикселей).
- Аудио в PNG-варианте отдаётся отдельным `.wav`.
- Максимум 10 секунд на клип, около 720p у Gen-4.5; на тарифах указан апскейл до 4K («4K upscaling»).

## Стоимость

Проверено 2026-10-14 по [странице цен](https://runway.com/pricing) и [ценам API](https://docs.dev.runwayml.com/guides/pricing/).

- Free: 125 кредитов однократно, хранилище 5 ГБ, часть моделей.
- Standard: $12 в месяц при годовой оплате ($15 помесячно), 625 кредитов в месяц = 52 секунды Gen-4.5 или 104 секунды Gen-4 Turbo. Нет водяных знаков. 5 параллельных генераций.
- Pro: $28 ($35), 2250 кредитов = 187 секунд Gen-4.5. Безлимитный апскейл до 4K, 15 параллельных.
- Max: $76 ($95), 9500 кредитов = 791 секунда Gen-4.5, перенос остатка на месяц, ProRes и последовательности кадров.
- Допкредиты: от 1000 штук, купленные не сгорают.
- API: $0.01 за кредит. Gen-4.5 12 кредитов в секунду ($0.12), Gen-4 Turbo 5 ($0.05), Aleph 2.0 28 ($0.28, минимум 56 кредитов за запрос). Veo 3.1 от $0.20 в секунду, Veo 3.1 Fast $0.10, Kling 3.0 Pro от $0.12, Seedance 2.5 от $0.20.
- Пример расчёта: 60 секунд готовых вставок, по 5 попыток на клип, Gen-4.5 через API = 300 секунд × $0.12 = $36. Оценка стоимости 2: для рабочего объёма нужен Pro.

## Активность и зрелость

Зрелость (stable): Gen-4.5 вышла 2025-12-01, в API 26 видеомоделей, постоянные релизы моделей и партнёрств (Adobe, DaVinci Resolve по заголовкам роликов канала). Открытых релизов и GitHub нет, поэтому цифры репозитория не приведены.

## Когда брать и когда нет

- Брать: атмосферные вставки без точной физики, оживление статичной иллюстрации на 2–10 секунд, правка готового клипа через Aleph 2.0, быстрый выбор между разными видеомоделями в одном аккаунте.
- Брать для проверки идеи: серия коротких проб до запуска дорогой работы.
- Не брать: схемы, формулы, подписи, любые сцены, где важна точность механики или физики.
- Не брать как основу цепочки, если нужен тот же результат при повторе или независимость от поставщика.
