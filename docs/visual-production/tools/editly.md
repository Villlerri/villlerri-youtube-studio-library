# Editly

Декларативный монтаж на Node.js и ffmpeg: ролик описывается JSON или JSON5 (клипы, слои, переходы, звук), на выходе MP4, MKV или GIF. Работает потоково, не складывает промежуточные файлы на диск. Для библиотеки графики полезен как простая сборка итогового ролика из готовых рендеров: титры, переходы gl-transitions, музыка с автоматическим приглушением.

## Что реально получается

- Сборка ролика из клипов, картинок и заголовков: каждый клип содержит слои (видео, картинка, наложение с прозрачностью, заголовок, субтитры, градиенты, заливка, пользовательский слой на Canvas, Fabric.js или GLSL-шейдере). Слои накладываются в порядке списка.
- Переходы между клипами: любые из gl-transitions (шейдерные), а также `directional-left/right/up/down`, `random`. Переход задаётся на конце клипа и по умолчанию длится 0,5 секунды. Звук при переходе плавно перетекает (кривые `tri` и другие).
- Звук: слияние нескольких дорожек, автоматическое приглушение музыки под речь, нормализация громкости.
- Скорость: клип подгоняется под нужную длину ускорением или замедлением (звук в пределах от 0,5× до 100×).
- Движение внутри клипа: параметры Ken Burns для картинки, положение слоёв, слой «slide-in-text». Пользовательские слои Canvas, Fabric.js и GLSL позволяют рисовать любую анимацию по кадрам кодом.
- Размер и кадры: любой размер и соотношение сторон, масштаб с полями, частота кадров приводится к заданной.
- Для объясняющего ролика: быстро склеить готовые сцены из [manim-ce](manim-ce.md) или [remotion](remotion.md), добавить титры, переходы и музыку под голос. Для самих сцен это не инструмент.

Что не получается: Editly не ведёт сквозную сцену. Каждый клип — отдельный набор слоёв, объекты не живут между клипами, камеры, морфинга и рисования линий нет (кроме того, что нарисует свой слой на Canvas или шейдере). Склеивать надо уже готовые куски, а плавность между ними даёт шейдерный переход.

## Слабые стороны

- Разработка почти остановилась: последний коммит 2025-02-20, последняя стабильная версия в npm 0.14.2 от 2022-12-23, предрелиз 0.15.0-rc.1 от 2025-01-19. Автор в README: проект ведёт один человек.
- Версия 0.x, API менялся, пакет только ESM.
- Нужны Node.js и ffmpeg в PATH, на Linux ещё системные зависимости для headless-gl (OpenGL без окна, обычно через Xvfb). Установка может требовать сборки из исходников.
- Нет редактора и предпросмотра. Режим `--fast` делает черновик в малом размере.
- Нет ключевых кадров и кривых, переходы — готовые шейдеры, подгонять вкус нужно подбором.
- Размер по умолчанию 640 пикселей по ширине и размер первого видео: для YouTube надо задать 1920×1080 явно.

## Сложность

- Для человека (2 из 5): JSON или JSON5 и команда `editly spec.json5`. Нужно уметь установить Node.js и ffmpeg. Для своих слоёв нужен JavaScript.
- Для агента (1 из 5): спецификация — обычный текст, CLI без вопросов. Агент пишет JSON, запускает, смотрит кадры. Руки не нужны, кроме оценки вкуса и подготовки системных зависимостей на Linux.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): CLI и JavaScript API (`editly(editSpec)`), пакетный запуск, Docker (в репозитории есть `docker-compose`).
- Воспроизводимость (4 из 5): проект — текстовая спецификация под git, ffmpeg детерминирован при одной версии. Шейдеры и Canvas зависят от драйвера OpenGL и версии библиотеки, поэтому не 5.

## Платформа и оборудование

Windows, macOS, Linux. Node.js (рекомендуется последний LTS), ffmpeg и ffprobe в `PATH`. Для слоёв на GL и переходов нужен OpenGL: на Linux без монитора через виртуальный экран. Видеокарта желательна, не обязательна.

## Экспорт

MP4 и MKV (кодек h264 по умолчанию, свои параметры через `customOutputArgs`), GIF. Прозрачные картинки и видео с альфой принимаются как слои. Размер и частота кадров задаются параметрами, режим `--fast` даёт малое разрешение для черновика.

## Когда брать и когда нет

- Брать: быстрая сборка итогового ролика из готовых сцен и озвучки по JSON, шаблонные серии, склейка с шейдерными переходами и приглушением музыки; когда агенту проще написать JSON, чем команду ffmpeg.
- Не брать: сквозные сцены, морфинг, камера ([manim-ce](manim-ce.md), [motion-canvas](motion-canvas.md), [remotion](remotion.md)); сложные вещи со временем и ключами ([davinci-resolve](davinci-resolve.md)); долгосрочный проект, которому нужен живой инструмент.
- Для Python-сборки смотрите [moviepy](moviepy.md), для чистой командной склейки [ffmpeg](ffmpeg.md).
