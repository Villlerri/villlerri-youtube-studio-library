# Clip Studio Paint

Программа для рисования, комиксов и покадровой 2D-анимации от компании Celsys (Япония). Ценится за кисти и вид линии. Анимация построена на ячейках (cels) и таймлайне, есть векторные слои, камера по кривой, звук. Для «рисования вживую» полезна как место, где художник рисует, а потом экспортирует кадры или видео.

## Что реально получается

- Покадровая анимация «от руки»: ячейки, световой стол, onion skin, таймлайн, экспозиционный лист. Линия остаётся живой: векторные слои позволяют менять толщину и форму после рисования.
- Камера: перемещение, масштаб, поворот по кривой, ключевые кадры. Это даёт плавное движение «камеры» над рисунком, но не трёхмерную сцену.
- Звук: импорт WAV, MP3, Ogg, экспорт анимации со звуком. Можно рисовать под готовую озвучку и смотреть тайминг на таймлайне (Audio Scrubbing с версии 3.0).
- Трёхмерные модели (FBX, GLTF, VRM и другие) как опорные и фоновые элементы, преобразование 3D в линии и тона.
- Запись процесса рисования (Timelapse) есть в списке функций. Подробности и ограничения не проверял.
- Для объясняющего ролика: нарисовать иллюстрации, подвижные схемы покадрово, «оживающие» рисунки. Хорошо, когда нужно художественное качество и ручной штрих. Плавное превращение объекта в другой автоматически не делается: между ключевыми рисунками художник рисует промежутки сам.
- Передача: PNG-последовательность и другие кадры, видео MP4, GIF, AVI, сцены OpenToonz (в EX). Рендер сложной сцены с камерой делается вне программы, например в [davinci-resolve](davinci-resolve.md) или [after-effects](after-effects.md).

## Слабые стороны

- Ограничение числа кадров по редакциям. PRO и DEBUT: анимация до 24 кадров (3 секунды при 8 кадрах в секунду). EX: полноценная анимация без этого предела («Full-length animation tools»). Для ролика длиннее трёх секунд нужен EX.
- Покадровая работа дорога по трудозатратам. Автоматических in-between и морфинга нет.
- Нет интерфейса командной строки и скриптов для агента. Есть Auto Actions (записанные цепочки команд), но не программный API.
- Нужна учётная запись и интернет для проверки лицензии. Некоторые функции (Remove tones, Colorize, Pose Scanner) отправляют данные на серверы Celsys (EULA, п. 10.1).
- Проект в двоичном формате, под git только как файл.
- Нет Linux. Платформы: Windows, macOS, iPad, iPhone, Galaxy, Android, Chromebook.

## Сложность

- Для человека (3 из 5): интерфейс освоить можно за неделю-две, но анимация требует навыка рисования и терпения. Есть уроки Celsys и сообщество.
- Для агента (5 из 5): только ручная работа в интерфейсе. Агент может лишь готовить сценарий и раскадровку, проверять итоговые кадры и собирать экспорт в другой программе.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): Auto Actions, шаблоны слоёв и анимации, экспорт в нескольких форматах. Командной строки и API нет.
- Воспроизводимость (2 из 5): результат зависит от ручных действий, проект двоичный (.clip). Повторяемость обеспечивает файл, а не скрипт.

## Платформа и оборудование

Windows 10 и 11 (также Arm как приложение x64), macOS, iPad, iPhone, Galaxy, Android, Chromebook. Процессор с SSE2 (Intel, AMD), видеокарта с OpenGL 3.3, не меньше 2 ГБ памяти (рекомендовано 8 ГБ), 3 ГБ на диске. Нужен планшет с чувствительным к нажиму пером (Wacom, XPPen, HUION проверены). Нужен доступ в интернет для проверки лицензии.

## Экспорт

- Кадры: BMP, JPEG, TGA, PNG, TIFF, PSD, WebP. Анимация: PNG-последовательность и другие, анимированный GIF, видео MP4 и AVI, анимированные стикеры APNG, звук WAV и Ogg. EX: PDF, EPUB, сцены OpenToonz, экспозиционные листы XDTS, CSV.
- Прозрачность: в PNG-последовательности есть альфа (стандарт формата), для видео не проверял.
- Импорт видео AVI, MOV, MP4 и звука WAV, MP3, Ogg.
- Разрешение и частота кадров задаются в параметрах экспорта.

## Когда брать и когда нет

- Брать: канал с рисованными иллюстрациями и покадровыми «оживающими» схемами, где важен ручной штрих; нужен хороший инструмент рисования; художник уже работает в Clip Studio Paint.
- Не брать: если нужна автоматизация агентом или код ([manim-ce](manim-ce.md), [remotion](remotion.md)); если нужна скелетная анимация и камера в 3D ([spine](spine.md), [blender](blender.md)); если нужна бесплатная замена ([krita](krita.md), [opentoonz](opentoonz.md), [pencil2d](pencil2d.md)); если нужно Linux.
