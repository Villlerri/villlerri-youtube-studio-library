# Hunyuan3D

Открытые модели Tencent для 3D: форма и PBR-текстуры по картинке. Последняя полностью открытая версия — Hunyuan3D-2.1 (июнь 2025, код и веса для обучения). Работает локально. Лицензия Tencent не действует в ЕС, Великобритании и Южной Корее.

## Что реально получается

Опора: README Hunyuan3D-2.1 и Hunyuan3D-2, тексты лицензий. Генераций я не запускал.

- Hunyuan3D-2.1: форма (Hunyuan3D-DiT, 3 млрд параметров) и PBR-текстуры (Hunyuan3D-Paint, 2 млрд параметров) по одной картинке. Открыты веса, код и обучающий код.
- Выход: меш в `.glb` (в примере `mesh.export('demo.glb')`), затем текстурирование отдельным шагом.
- Hunyuan3D-2 (январь 2025) и мини-версии 2mini с турбо-вариантами для быстрой работы на слабых картах.
- Hunyuan3D 2.5 описан техническим отчётом от 2025-06-23; открытых весов 2.5 в README я не нашёл. Облачные узлы Hunyuan3D доступны платно в ComfyUI как Partner nodes (по README ComfyUI).
- Вокруг: Hunyuan3D-Part (работа с частями объекта, судя по названию; обновлён в декабре 2025), WorldClaw и HY-World 2.0 (3D-миры), обновлялись в августе 2026.
- Согласованность: меш фиксированный, камера и сцена строятся в [Blender](blender.md).
- Вывод автора: близкая к [TRELLIS](trellis.md) замена, но с юридически более тяжёлой лицензией.

## Слабые стороны

- Территория: лицензия не действует в ЕС, Великобритании и Южной Корее (определение «Territory»). П. 5(c) запрещает использовать, показывать и распространять результат за пределами территории. Для публикации на YouTube это риск. Не юридическая консультация.
- П. 5(b): результат нельзя использовать для улучшения других ИИ-моделей.
- Порог: больше 1 млн активных пользователей в месяц на дату выхода версии — нужна отдельная лицензия Tencent (в тексте 2.1 и 2.0).
- Видеопамять: 10 ГБ на форму, 21 ГБ на текстуру, 29 ГБ на форму и текстуру (README 2.1).
- Установка не выполнялась (по правилам библиотеки).
- Научные детали не гарантированы, как и в других генераторах.

## Сложность

- Для человека (4 из 5): Python, CUDA, веса, сборка расширений для текстурирования.
- Для агента (2 из 5): скрипты `demo.py`, получение `.glb`, проверка в Blender. Нужна видеокарта 29 ГБ для полного цикла.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): Python-API в стиле diffusers, скрипты, режим `--low_vram_mode`, интеграции ComfyUI и Unity (сообщество).
- Воспроизводимость (3 из 5): код и веса фиксируются, результат на разных видеокартах не проверялся.

## Платформа и оборудование

NVIDIA GPU от 10 ГБ для формы и около 29 ГБ для формы с текстурой. Облачные узлы Hunyuan3D доступны в ComfyUI как платные Partner nodes.

## Экспорт

GLB (PBR-текстуры). Другие форматы зависят от пост-обработки.
