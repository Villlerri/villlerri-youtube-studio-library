# Kdenlive

Свободный нелинейный видеоредактор KDE на движке MLT. Версия 26.08.2 вышла 13 октября 2026.

## Ссылки

- Официальный сайт: <https://kdenlive.org/>
- GitHub: <https://github.com/KDE/kdenlive> (зеркало; основная разработка на KDE Invent: <https://invent.kde.org/multimedia/kdenlive>).
- Документация: <https://docs.kdenlive.org/en/>
- Примеры, проверенные 2026-10-14 (ссылка открывается через oEmbed; содержание по названию):
  - [Keyframe Interpolation - Kdenlive Tutorial](https://www.youtube.com/watch?v=F1h6Kg-WLDE) — канал Nuxttux Creative Studio. Типы интерполяции ключевых кадров и кривые.
  - [How to Use Keyframes for Animation in Kdenlive 2025?](https://www.youtube.com/watch?v=8PJ24BntThU) — канал EditingBasics. Анимация позиции и масштаба ключевыми кадрами.

## Что реально получается

Опора: страница программы, документация, заметки «Что нового».

- Монтаж на дорожках, ключевые кадры у эффектов, прокси для слабых машин, титры и интеграция с Glaxnimate для векторной анимации.
- Переходы: в документации «композиции» (compositions) называют переходами. Страница описывает Dissolve (плавное перекрытие). Полный список переходов в документации не нашёл.
- С версии 26.04: анимированный предпросмотр переходов и композиций, автоматические ключевые кадры для части эффектов (26.08).
- Конвейер 10-бит с 25.12: эффекты, композиции и рендер.
- Сегментация объектов появилась в 25.04. Преобразование текста речи в субтитры есть (в 24.05 добавлен перевод через SeamlessM4T).
- Анимация Lottie и Glaxnimate с 22.08: можно вставлять анимацию, сделанную в другом инструменте.
- Непрерывная сцена, морфинг объектов, рисование линий: встроенных инструментов нет. Kdenlive собирает сцены из готовых клипов и слоёв.
- Синхронизация с голосом: ручная по дорожкам. Опорой служат расшифровка и субтитры.

## Слабые стороны

- Нет 3D, частиц и узлового композитинга. Сложная графика делается в других инструментах: [Natron](natron.md), [Blender](blender.md), [DaVinci Resolve](davinci-resolve.md).
- Нет скриптового API. Автоматизация через файл проекта MLT и `melt`. По обсуждениям на форуме, `melt` на `.kdenlive` только проигрывает проект, для рендера нужен консьюмер `avformat`, а параметры рендера Kdenlive надо повторять руками.
- Daily-сборки могут «испортить существующие проекты» (предупреждение на странице загрузки).
- Совместимость проектов между версиями не гарантирована. Для старых проектов есть архив версий.

## Сложность

- Для человека (2 из 5): типичный редактор, базовые операции за дни. Оценка автора карточки.
- Для агента (4 из 5): API нет. Агент может писать MLT XML и рендерить через `melt`, но результат нужно проверять отдельно. Параметры кодирования из диалога Kdenlive в `melt` переносятся вручную.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): `melt` и привязки MLT (Python, Lua и др.). Kdenlive не вызывается из кода. Рендер по документации через диалог (Ctrl+Return). В оглавлении документации есть раздел «Rendering in Batch Mode», содержание не открывал.
- Воспроизводимость (3 из 5): проект на XML (MLT), по форуму читается `melt`. Но в формат попадают служебные свойства Kdenlive, версии между собой не всегда совместимы.

## Платформа и оборудование

- Linux: AppImage и Flatpak (Flathub). Windows 10 и новее: установщик и portable. macOS 13 Ventura и новее: Intel и Apple Silicon (страница загрузки). BSD упомянут на главной.
- Требования к памяти и видеокарте не найдены.

## Экспорт

- Диалог рендера (Ctrl+Return), по умолчанию MP4 H.264/AAC («работает почти везде», документация), свои профили и пресеты.
- Клипы с альфа-каналом принимаются на вход. Экспорт альфа-канала и пресеты YouTube в документации не нашёл.
- Импорт и экспорт OpenTimelineIO с 25.04.

## Когда брать и когда нет

- Брать: бесплатный редактор на Linux, сборка ролика из готовых клипов, ключевые кадры у масштаба и позиции, импорт Lottie.
- Не брать: нужен вывод через код (взять [FFmpeg](ffmpeg.md) или [MoviePy](moviepy.md)), нужна сложная анимация и морфинг (взять Fusion в [DaVinci Resolve](davinci-resolve.md)).
