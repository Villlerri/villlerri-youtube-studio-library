# Synfig Studio

Свободная программа векторной 2D-анимации. Главное: векторный твининг (одна форма плавно превращается в другую), система костей и слоёв, связь параметров через выражения. Проект — XML-файл, рендер из командной строки.

## Ссылки

- Официальный сайт: https://www.synfig.org
- GitHub: https://github.com/synfig/synfig
- Документация: https://synfig.readthedocs.io/en/latest/ (руководство для версии 1.5.1)

  - [Exporting Synfig animation for web - Demo 1](https://www.youtube.com/watch?v=Wjw2nO8kYlc) — канал Synfig, экспорт в Lottie; ссылка из руководства.

## Что реально получается

- Векторный твининг: сайт заявляет «Transform any vector shape into another»; задаёте ключевые позиции, промежуточные кадры считаются. Это ближайшее в классе к морфингу рисунка.
- Кости: система костей для вырезной анимации и управления векторной графикой; слой Skeleton Distortion деформирует растровые картинки. В 1.5.0 появился инструмент Skeleton для быстрого построения и перестановки костей.
- Слои: 50+ слоёв (геометрия, градиенты, фильтры, искажения, фракталы). Параметры связываются напрямую или математическими выражениями, из этого собирают «пружинящие» куклы.
- Непрерывная сцена: один холст, много слоёв и вложенных холстов. Камеры как объекта в просмотренных страницах нет.
- Звук: панель звука показывает форму волны, в 1.5.0 улучшен выбор звуковых слоёв. Автоматического липсинка в просмотренных страницах нет.
- Рисование линий: готового эффекта «линия вычерчивается» в просмотренных страницах нет; его собирают вручную через параметры обводки.
- Для объясняющих видео подходит для векторных персонажей и схем с плавным морфингом форм. Вид «по умолчанию» — гладкий векторный клипарт; живой рукотворности добавить трудно.

- Анимация персонажа всё равно ручная работа аниматора.

## Сложность

- Для человека (3 из 5): понятия слоёв, холстов и конвертеров непривычны, но видеокурс и руководство есть. Рабочий результат за недели.
- Для агента (3 из 5): файл проекта `.sif` — XML (пример `backdrop.sif` из репозитория), его пишут и правят текстом. Команда `synfig` рендерит без окна. Дизайн сцены и ключевые позы агенту трудно задать вслепую, обычно нужен человек в интерфейсе.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): консольный рендер `synfig файл.sif -t <цель> -o <файл>`, ключи `--time` (один кадр), `--begin-time`, `--end-time`, `--fps`, `-w`/`-h`, `-T` (потоки), `--targets` (список целей), `--layers`, `--list-canvases` ([man-страница Debian](https://manpages.debian.org/testing/synfig/synfig.1.en.html) для 1.5.5). Плагины на Python для импорта и экспорта (с 1.5.0).
- Воспроизводимость (4 из 5): проект — XML под git, `.sifz` — сжатая версия. Тот же файл даёт тот же кадр на той же версии; побитово между платформами не проверял.

## Платформа и оборудование

Windows 7 и новее, macOS 10.8 и новее, Linux начиная с 2012 года; двухъядерный процессор 2 ГГц, 2 ГБ памяти (сайт; цифры устарели). Сборки: AppImage для Linux.

## Когда брать и когда нет

- Брать: векторные куклы и морфинг форм без бюджета; сборка анимации текстом и рендер на сервере; экспорт в Lottie для сайта.
- Не брать: сложная композиция с камерой и эффектами ([after-effects](after-effects.md), [toon-boom-harmony](toon-boom-harmony.md)); рисованная «живая» анимация ([tahoma2d](tahoma2d.md), [tvpaint](tvpaint.md)); если нужна свежая версия без риска ветки разработки.
