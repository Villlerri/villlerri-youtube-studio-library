# aeneas

Библиотека и набор команд на Python и C для привязки фрагментов текста к дорожке озвучки. Синтезирует эталонную речь движком eSpeak и выравнивает с настоящей записью алгоритмом динамической деформации времени (DTW). Проект заброшен: последний релиз 2017 года.

## Что реально получается

- Карта синхронизации. Входной файл: аудио и текст, разбитый на фрагменты (абзац, предложение, подпредложение, слово). Выход: время начала и конца каждого фрагмента. Так получается «строка сценария → интервал» для сцены или субтитра.
- Слова. Для пословной разметки в командной строке есть пресет `--presets-word` (маска MFCC для пауз). Точность слов в документации не приведена.
- Форматы: JSON, CSV, TSV, SSV, TXT, XML, SRT, VTT, TTML, SBV, SMIL для EPUB 3, а также Audacity, ELAN, TextGrid.
- Русский. Код `rus` в списке языков, эталонную речь для выравнивания даёт eSpeak. Это внутренний инструмент выравнивания, не озвучка ролика. Другие синтезаторы речи библиотека не рассматривает по правилу студии; озвучка идёт только через [ElevenLabs](elevenlabs.md).
- Пакетная работа. Команда `execute_job` обрабатывает набор задач из архива с конфигурацией.
- Непрерывность сцены, морфинг и камера — не его задача.

## Слабые стороны

- Брошенный проект. Последний релиз 1.7.3 вышел 2017-03-15, последний коммит — 2020-05-13. Есть 37 открытых вопросов.
- Поддерживаемые версии — Python 2.7 и 3.5. Разработка и тесты велись на Debian 64 бит; другие системы «подтверждены как работающие», но не поддерживаются.
- Метод грубее современных: сравнивает с синтезом eSpeak, а не с фонетической моделью. На современных моделях ([WhisperX](whisperx.md), [Montreal Forced Aligner](montreal-forced-aligner.md)) границы слов точнее, но это сравнение не проверялось.
- Требует ffmpeg, eSpeak, numpy, lxml, BeautifulSoup4 и компиляции расширений на C.
- Длина записи по умолчанию ограничена 7 200 секундами (параметр `task_max_audio_length`).

## Сложность

- Для человека (3 из 5): установка на современной системе может потребовать подгонки версий Python и сборки расширений. Дальше всё одной командой с конфигурационной строкой.
- Для агента (3 из 5): запуск и разбор результатов просты. Часть работы руками: поднять окружение со старой версией, проверить пословные метки на слух.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): команды `execute_task` и `execute_job`, Python API, форматы для машин.
- Воспроизводимость (4 из 5): алгоритм DTW детерминирован. Результат зависит от версии eSpeak и параметров MFCC, поэтому окружение фиксируют.

## Платформа и оборудование

Рекомендуется машина с 4 ГБ памяти и 64-битным процессором 2 ГГц. Основная платформа — Debian с Python 2.7 или 3.5. Подтверждены Linux, macOS и Windows (по README). Видеокарта не нужна. Установка через `pip install numpy`, затем `pip install aeneas`. Установщики для macOS и Windows, скрипт для Debian и Ubuntu, образ Vagrant.

## Экспорт

JSON, CSV, TSV, SSV, TXT, XML, SRT, VTT, TTML, SBV, SMIL, Audacity (AUD), ELAN (EAF), TextGrid. Метки по фрагментам с точностью до миллисекунд.

## Когда брать и когда нет

- Брать: только если нужен готовый инструмент для длинного текста с фрагментами (предложениями) и вы согласны на старое окружение. Хорошо подходит для карт синхронизации аудиокниг и для привязки субтитров по предложениям.
- Не брать: для основного конвейера студии. Для слов и фонем лучше [Montreal Forced Aligner](montreal-forced-aligner.md), [WhisperX](whisperx.md) или Forced Alignment API в [ElevenLabs](elevenlabs.md).
