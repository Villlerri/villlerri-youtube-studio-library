# Doodly

Настольный конструктор whiteboard-роликов компании Voomly: персонажи, реквизит и текст кладутся на сцену, «рука» дорисовывает их. Продаётся по подписке вместе с набором приложений Voomly Cloud.

## Что реально получается

Опора: страница цен и FAQ Voomly, сайт Doodly.

- Сцены из готовых персонажей, реквизита, фонов, текста. В Standard 1 164 картинки персонажей и 1 620 реквизита, 84 шаблона сцен, 20 шаблонов видео, 35 шрифтов. В Enterprise 3 959 персонажей, 3 341 реквизита, 40 шаблонов видео, 70 шрифтов.
- Рука рисует картинки по очереди. Для загруженных PNG и JPEG каждой картинке автоматически назначается «заранее заданный путь рисования», его можно подправить (FAQ).
- Режим классной доски (blackboard): переключение белой доски в чёрную в пару кликов.
- Музыка (150–250 дорожек без лицензионных платежей), запись или загрузка озвучки (MP3), свои шрифты, свои картинки.
- Морфинга, камеры, непрерывной сцены, рисования линий по смыслу нет. Сцена остаётся набором слайдов.
- Синхронизация с голосом: на странице продукта нет. Руками на таймлайне.

### Почему выглядит дёшево

Оценка автора карточки, не источник.

- Рука «закрашивает» клипарт по автоматическому пути. Объяснение не строится, а подменяется эффектом.
- Тот же набор персонажей, что у всех покупателей. Узнаваемый жанр рекламных роликов.
- Сцены не связаны друг с другом: каждая начинается с чистого фона. Длинный ролик превращается в слайд-шоу.
- Лучше: свои иллюстрации в едином стиле, запись настоящего пера или анимация собственных линий (см. [Excalidraw](excalidraw.md), [OBS Studio](obs-studio.md)) вместо клипарта.

## Слабые стороны

- Подписка дорогая для того, что получается: US$49 в месяц, US$490 в год.
- Нужен интернет: программа подтягивает картинки из сети, проекты хранятся в облаке (FAQ).
- Экспорт только MP4, до 1080p, 24–60 к/с.
- Только интерфейс.
- Главная страница показывает акцию «Normally $468/year, Today ONLY $67» и купон на 10%, а страница цен другие суммы. Сравнивать нужно по странице цен.

## Сложность

- Для человека (1 из 5): «перетащи и отпусти», ролик за час. Оценка автора карточки.
- Для агента (5 из 5): только интерфейс настольного приложения, API нет. Агент может подготовить сценарий и список картинок.

## Автоматизация и воспроизводимость

- Автоматизация (1 из 5): нет API, скриптов, командной строки.
- Воспроизводимость (2 из 5): проект хранится в облаке аккаунта, обновления приходят автоматически («hybrid Web + Desktop app»). Результат может меняться с версиями.

## Платформа и оборудование

- Windows 7 и новее, Mac OS X 10.10 и новее (FAQ страницы цен, данные старые). Установка настольного приложения, нужен постоянный интернет.

## Экспорт

- MP4 (FAQ). Разрешение от 360p до 1080p, частота кадров 24–60 к/с, качество от 62% до 100%.
- GIF, альфа-канал, PNG-последовательность: не найдены.

- Оценка стоимости 2: US$49 в месяц.

## Когда брать и когда нет

- Брать: быстрые рекламные «doodle»-ролики для бизнеса, если нужен готовый набор персонажей.
- Не брать: научно-популярный канал. Нет непрерывной сцены, морфинга, камеры, вывода формул.
- Не брать: если студия сама рисует иллюстрации. Тогда [Excalidraw](excalidraw.md), [tldraw](tldraw.md), запись пера ([OBS Studio](obs-studio.md)).
- Не брать: если ролик собирается автоматически.
