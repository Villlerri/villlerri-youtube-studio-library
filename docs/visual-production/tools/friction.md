# Friction (бывший enve)

Свободная программа для 2D motion graphics: векторная и растровая анимация, ключевые кадры, выражения на JavaScript, экспорт в видео и в анимированный SVG. Ответвление проекта enve (автор Maurycy Liebner). Работает на Linux, Windows и macOS.

## Ссылки

- Официальный сайт: <https://friction.graphics/>
- GitHub: <https://github.com/friction2d/friction> (трекер ошибок есть и на Codeberg: <https://codeberg.org/friction/friction/issues>)
- Документация: <https://friction.graphics/documentation/>
- Примеры, проверенные 2026-10-14 (ссылки открываются через oEmbed; содержание описано по названию и описанию ролика, ролики целиком не смотрелись; оба ролика сторонние, на официальном канале проекта примеров не искал):
  - [Shape Morphing and Match Cut - Friction Graphics Tutorial](https://www.youtube.com/watch?v=758rfoR_l1I) — канал Nuxttux Creative Studio. Морфинг формы и склейка по совпадению (match cut), монтаж в Kdenlive. Ролик 16 минут.
  - [3 Friction Graphics Effects - Friction Tutorial](https://www.youtube.com/watch?v=8qMD9YDiOAs) — тот же канал. По главам: Follow Path, Flipbook, Clipping Mask, отслеживание объекта (Object Tracking).

## Что реально получается

Опора: сайт проекта, документация (экспорт, выражения, использование), список новостей.

- Векторные фигуры, кривые Безье, рисованные кривые, растровые изображения (подключаются как ссылка на файл), импорт SVG с редактированием фигур.
- Ключевые кадры на любом параметре, график скорости (Graph) с кривыми Безье.
- Эффекты контуров: Displace, Dash, Duplicate, Sub-Path, Solidify, Sum, Lines, ZigZag, Subdivide. Заметки проекта описывают «постепенное появление контура» (аналог Trim Path) и «альфа-маскирование между слоями» (аналог трек-маски). Это даёт рисование линий и вывод схемы по шагам.
- Морфинг формы: есть учебный ролик (выше). В документации «использование» морфинг не назван.
- Выражения: ECMAScript в каждом параметре, привязки к свойствам сцены, примеры (Clamp, Wiggle, Loop, Orbit). Ограничение: выражение не читает значения из другого кадра.
- Типографика: эффекты текста и контуров в списке возможностей. Подробностей в документации «использование» нет.
- Непрерывная сцена и камера: несколько сцен и таймлайнов в одном проекте. Камеры в документации не описаны.
- Синхронизация с голосом: ключевые кадры вручную. Импорт звука в документации «использование» не найден (в экспорте есть звуковые форматы).
- Шейдерные эффекты: экспериментальные, ограниченный набор.

## Слабые стороны

- Стабильной версии 1.0 нет. Последний выпуск 1.0.0-rc.3 вышел 2025-12-31. Сопровождающий писал, что это последний шаг перед версией 1.0 «в начале января» (страница релизов). К 2026-10-14 новых выпусков в ленте нет, хотя коммиты идут (последний 2026-10-09).
- Проект двоичный (`.friction`). Текстовый формат только запланирован.
- GIF не поддерживается (документация советует собрать из MP4 или PNG снаружи).
- ProRes с альфой не читают декодеры Apple Silicon (известная проблема в документации).
- Анимированный SVG: в браузере результат может отличаться от того, что видно в окне просмотра, поддерживается только подмножество возможностей.
- Командная строка и скрипты не описаны.
- Мало материалов и примеров по сравнению с After Effects.

## Сложность

- Для человека (3 из 5): интерфейс близок к After Effects (таймлайн, график, слои, выражения), но программа сырая и требует привыкания. Оценка автора карточки.
- Для агента (4 из 5): интерфейс графический, проект двоичный, командной строки в проверенных источниках нет. Агент может написать выражения и подготовить SVG, остальную анимацию делает человек руками. Проверка кадра через экспорт.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): выражения ECMAScript в параметрах, пресеты выражений `.fexpr`. Командной строки и API внешних скриптов в документации нет.
- Воспроизводимость (2 из 5): двоичный `.friction`, всё, кроме подключённых ресурсов, внутри файла. Версия программы влияет на результат: проект pre-1.0.

## Платформа и оборудование

- Windows (установщик и портативная сборка), Linux (AppImage), macOS (DMG). Сборка из исходников для трёх платформ описана в документации.
- Основа: C++, Qt, Skia, FFmpeg, OpenGL. Конкретных требований к видеокарте и памяти не нашёл.

## Экспорт

- Видео через FFmpeg: MP4 (H.264), ProRes (MOV), MPEG-4, AVI, WebM. Звук: MP3, FLAC, WAV, OGG.
- Последовательности изображений: PNG, TIFF, JPEG.
- Анимированный SVG (SMIL) для веба.
- GIF нет. Lottie в документации не найден.
- Альфа-канал: ProRes с альфой есть, но с проблемой на Apple Silicon. Для других форматов не проверено.

## Когда брать и когда нет

- Брать: бесплатная замена After Effects для простых 2D-сцен, схем, титров, рисования контуров, на Linux.
- Брать: если нужен анимированный SVG для сайта.
- Не брать: если нужна стабильность и подписанный релиз. Версия 1.0 не вышла.
- Не брать: если нужен Lottie. Тогда [Glaxnimate](glaxnimate.md) или [Cavalry](cavalry.md).
- Не брать: если сцены собирает агент без участия человека. Тогда код: [Manim CE](manim-ce.md), [Motion Canvas](motion-canvas.md).
