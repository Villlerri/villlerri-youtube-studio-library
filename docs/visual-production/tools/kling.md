## Что реально получается

Опора: справочник API image-to-video, страница истории выпусков, страница планов. Генераций я не запускал.

- Kling 3.0 через API: 3–15 секунд, разрешения 720p, 1080p и 4K, родное аудио включается флагом (`audio: native`).
- Первый и последний кадр (`first_frame`, `last_frame`): поддерживается генерация по первому кадру и по паре «первый и последний». Только последний кадр не поддерживается. Это инструмент бесшовных переходов: два нарисованных кадра, движение между ними генерирует модель. Размер картинки от 300 пикселей, пропорции от 1:2.5 до 2.5:1, до 50 МБ.
- Мультикадр: подсказка вида «shot n, m, words» задаёт до 6 планов в одном клипе, каждый не короче 1 секунды, сумма равна длительности клипа, подсказка плана до 512 символов. Герой, стиль и звук держатся через склейки (заявление производителя).
- Элементы (`element`): до 3 сохранённых героев или предметов на запрос, упоминаются как `@имя`. Так закрепляется внешний вид объекта между клипами.
- Подсказка до 3072 символов (рекомендуется до 2500).
- Motion Control (с марта 2026): перенос движения с эталонного видео на героя, привязка лица по нескольким картинкам.
- Kling 4.0: на главной странице «All-New Kling 4.0», запись в истории выпусков от 2026-09-28. Технические параметры 4.0 я не проверил.
- Согласованность и физика: сайт Kling называет согласованность сильной стороной 3.0, независимых проверок в источниках нет.
- Вывод автора: из сервисов класса у Kling самый удобный набор для связки «опорные кадры, мультикадр, элементы». Для научных сцен действует тот же риск физики.

## Слабые стороны

- Права и метки: условия использования требуют помечать результат брендом Kling, пока нет письменного разрешения, и запрещают коммерческое использование результата без письменного разрешения. При этом страница тарифов обещает коммерческое использование и снятие бренд-знака на платных планах. Противоречие нужно снять письменно (см. «Лицензия и права»).
- Кредиты на сайте считаются по разным ставкам для моделей и разрешений, длина и звук меняют цену. Простой прогноз по месячному пакету невозможен.
- Договор подчиняется праву Сингапура. Kling получает широкую лицензию на ваши входные данные и результаты (для продвижения и разработки).
- На плане Basic бренд-знак не снимается (в таблице планов стоит прочерк).

## Сложность

- Для человека (2 из 5): веб-интерфейс и приложения, подсказки на английском и китайском лучше. Мультикадровый синтаксис надо выучить.
- Для агента (2 из 5): REST API, задачи создаются и опрашиваются, `external_task_id` и `callback_url` для автоматизации. Платные вызовы агенту нужно явно разрешать; создание «элементов» и покупка пакета делаются человеком.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): API с коллбэками, кредитные пакеты на 180 дней с 20 параллельными задачами; параметр `watermark_info.enabled` управляет водяным знаком в выдаче.
- Воспроизводимость (2 из 5): параметра `seed` в прочитанной части справочника нет. Модели обновляются (3.0, 3.0 Turbo, 4.0).

## Платформа и оборудование

Веб, приложения для iOS и Android, настольное приложение (Intel и Apple Silicon на странице загрузки). Локального запуска нет.

- Альфа-канала нет.

## Стоимость

Проверено 2026-10-14 по [странице планов](https://kling.ai/app/membership/membership-plan) и [ценам API](https://kling.ai/dev/pricing).

- Basic: бесплатно. Платные планы: Standard 660 кредитов в месяц, Pro 3000, Premier 8000, Ultra 26000. Прейскурант: $10, $37, $92, $180. При помесячной оплате страница показывает скидку 12% ($8.8, $32.56, $80.96, $159.99) и первый месяц дешевле ($6.99, $25.99, $64.99, $127.99). Цена за 100 кредитов: $1.06, $0.87, $0.81, $0.49. Годовая цена не считывалась.
- Платным планам приписаны: очередь без лимита, 1080p и 4K, снятие бренд-знака, коммерческое использование контента. В колонке Basic напротив двух последних пунктов прочерк.
- API: 1 единица = $0.14. Kling 3.0 за секунду без аудио: 720p $0.084, 1080p $0.112, 4K $0.42. С родным аудио без управления голосом: $0.126, $0.168, $0.42. Kling 3.0 Turbo с аудио: $0.112 (720p), $0.14 (1080p). Пакеты на 180 дней от $700 (5000 единиц), без переноса остатка.
- Пример расчёта: 60 секунд готовых вставок, 5 попыток на клип, Kling 3.0 с аудио в 1080p по API = 300 секунд × $0.168 = $50.4. Оценка стоимости 2.

Но п. 4.5 требует помечать результат брендом Kling («Kling AI») без письменного разрешения, а п. 4.6 запрещает без письменного разрешения использовать и распространять результат в коммерческих целях. Страница планов отдельно обещает коммерческое использование и снятие бренд-знака платным планам. Для студии значит: брать только платный план и письменно подтвердить права у Kling. П. 4.7: Kling получает неисключительную лицензию на ваши входные данные и результаты, в том числе для продвижения и R&D.
- Метки происхождения: C2PA и SynthID в прочитанных страницах не упомянуты. Для YouTube реалистичные синтетические сцены нужно раскрывать в Studio (см. [обзор класса](../classes/10-generative.md)).

## Активность и зрелость

Зрелость (stable): лента выпусков — Kling 3.0 (2026-01-31), 3.0 Motion Control (2026-03-04), нативный 4K (2026-04-23), 3.0 Turbo (2026-06-17), 4.0 (2026-09-28). Развивает Kuaishou. GitHub нет.

## Когда брать и когда нет

- Брать: переходы между двумя заранее нарисованными кадрами, мультикадровые вставки с постоянным героем, атмосферные сцены в 1080p и 4K.
- Брать через Runway или Luma, если уже платите им: Kling 3.0 доступна внутри их аккаунтов.
- Не брать: научные сцены с точной механикой или физикой, любые надписи и формулы в кадре.
- Не брать без письменного подтверждения прав: условия и страница планов противоречат друг другу.
