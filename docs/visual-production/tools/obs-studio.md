# OBS Studio

Бесплатная программа для записи экрана и камеры и для прямых трансляций. В схеме «рисование вживую» она записывает окно графической программы, в которой человек рисует пером на планшете, вместе с голосом и камерой. Сама рисовать и анимировать не умеет.

  - [OBS - How to Scribble on Screen with your iPad or Graphics tablet](https://www.youtube.com/watch?v=DW61u2lTzr4) — канал Gael LEVEL. Как показать рисование с планшета поверх кадра OBS. В описании: приложение VDO.Ninja для трансляции экрана планшета и плагин obs-shaderfilter. Сторонний ролик.

## Что реально получается

Опора: главная страница OBS, база знаний, ролики выше.

- Сцены: «неограниченное число сцен и переходов между ними». Источники: захват окна, изображения, текст, окно браузера, веб-камера, карты захвата. Из них собирается кадр: рабочая область рисования плюс камера лектора.
- Рисование вживую: планшет рисует в программе (Krita, Xournal++, Excalidraw, Concepts и подобные), OBS записывает окно, голос с микрофона и, при желании, камеру в углу. Процесс виден зрителю, ничего не превращается в клипарт.
- Chroma Key и накладки: фильтры источников, показаны в обучающих роликах сторонних авторов. Документация OBS по этому разделу не открывалась. Для [Lightboard](lightboard.md) OBS может заменить аппаратный видеомикшер: принять камеру и слайды, записать смесь (идея; на lightboard.info микшер аппаратный).
- Запись: MKV рекомендован (защита от повреждения при сбое), потом его пересохраняют в MP4 (руководство OBS по записи).
- Виртуальная камера: ключ запуска `--startvirtualcam`. Для публикации ролика не нужна.
- Синхронизация с голосом: естественная, голос и картинка пишутся вместе. Записанный голос остаётся человеческим. Для синтезированной озвучки (ElevenLabs) подходит монтаж постфактум.
- Морфинг, камера, непрерывная сцена: OBS их не создаёт. Переходы между сценами есть (страница OBS), но это переключение кадров, а не развитие одной сцены.

## Слабые стороны

- Не рисует и не анимирует: качество определяется художником и программой для рисования.
- Запись всегда в реальном времени. Ошибки в рисовании остаются или требуют повторной записи.
- Рисунок «вживую» обычно идёт медленнее, чем терпит зритель (оценка автора карточки). Скорость правят при монтаже.
- Для чистого рисунка нужны хорошие планшет и приложение. Планшет с экраном и пером, например iPad, отправляет картинку в OBS через стороннее приложение (ролик Gael LEVEL).
- Ограничения macOS: страницы OBS называют разные минимальные версии (см. «Неизвестно»).

## Сложность

- Для человека (2 из 5): настройка сцены занимает час, дальше запись. Оценка автора карточки.
- Для агента (3 из 5): агент настраивает запуск через ключи командной строки и управляет записью через WebSocket. Сцены надо создавать в интерфейсе, как автоматизировать это целиком, в источниках не проверено. Рисует человек или отдельная программа.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): встроенный WebSocket (с OBS 28, пароль генерируется при первом запуске, переопределяется ключами `--websocket_port`, `--websocket_password`), ключи запуска `--startrecording`, `--startstreaming`, `--startvirtualcam`, `--profile`, `--collection`, `--scene`, скрипты Lua и Python, API плагинов на C.
- Воспроизводимость (3 из 5): профили и коллекции сцен сохраняются. Сама запись «вживую» не воспроизводится: человек рисует заново.

## Платформа и оборудование

- Windows 10 и 11, macOS (Intel и Apple Silicon), Linux (X11 и Wayland). Видеокарта: DirectX 10.1 на Windows, OpenGL 3.3 на macOS и Linux (база знаний). Нагрузка зависит от кодека, разрешения, частоты кадров и сложности сцены.

## Экспорт

- Запись: MKV (рекомендуется), потом пересохранение в MP4. Другие контейнеры, ProRes, прозрачность: в руководстве по записи не описаны.
- Трансляции на платформы стриминга.

## Когда брать и когда нет

- Брать: запись живого объяснения пером на планшете, лекции в стиле Lightboard, запись экрана программ и веб-страниц (excalidraw-animate, браузерные сцены).
- Брать: когда нужен предсказуемый бесплатный инструмент на любой ОС.
- Не брать: если нужно создавать графику. OBS только снимает то, что уже нарисовано.
- Не брать: если нужен безошибочный дубль без монтажа. Тогда скрипт сцены в коде ([Manim CE](manim-ce.md), [Motion Canvas](motion-canvas.md)).
