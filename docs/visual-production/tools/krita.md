# Krita (анимация)

Свободный редактор цифровой живописи с покадровой растровой анимацией. Для объясняющих роликов подходит как рисовалка для рукописных кадров и «рисуемых вживую» сцен. Анимационные инструменты скромные: нет векторных костей, камеры и твининга форм.

## Ссылки

- Официальный сайт: https://krita.org
- GitHub: https://github.com/KDE/krita — зеркало. Основной код лежит на KDE: https://invent.kde.org/graphics/krita (в README зеркала сказано: «If you are reading this on GitHub, be aware that this is just a mirror»).

  - [Render Animation](https://docs.krita.org/en/reference_manual/render_animation.html) — официальная страница о выводе в последовательность PNG и видео.
  - [KRITA ANIMATION TUTORIAL [Frame-by-frame and Tweening]](https://www.youtube.com/watch?v=8qCTjlepcSo) — канал 2nutty4kimy, сторонний урок (ролик открывался через oEmbed, содержание описано по названию, не смотрел).

## Что реально получается

- Покадровая растровая анимация: «Krita has frame-by-frame raster animation» (руководство). Дорожка (Animation Timeline), калька (Onion Skin), кривые анимации для небольшого твининга, раскадровка (Storyboard).
- Рукописные сцены: доска или схема рисуется вручную кадр за кадром. Это дёшево по деньгам, но дорого по времени художника.
- Запись процесса: Recorder docker снимает кадр после каждого штриха и собирает ускоренное видео (нужен FFmpeg). Так получают ролик «как рисовали», без покадровой анимации.
- Преобразования: маски трансформации можно анимировать (раздел руководства «Animating with transform masks»), это даёт простое движение и поворот кусков рисунка.
- Звук: дорожки звука для анимации («Audio for Animation»). Автоматического липсинка в просмотренных страницах нет.
- Морфинг, кости, камера, непрерывная сцена в одном холсте: инструмент для этого не предназначен. Переходы между сценами делают в монтаже.
- Для коротких рисованных вставок в объясняющем видео это приемлемо, для основной сцены — нет.

## Слабые стороны

- Только растровые кадры: нельзя масштабировать без потерь и нет векторного твининга.
- Все кадры лежат в памяти: «animation files will eat up all of your computer's working memory» (руководство). Анимацию длиннее 3 секунд советуют планировать по раскадровке.
- Для видео нужен внешний FFmpeg, его пути задают вручную. На Android FFmpeg не используется.
- Без камеры, мультиплана и узлового композитинга.

## Сложность

- Для человека (2 из 5): интерфейс рисовалки, основы покадровой анимации осваивают за дни. Сложность — в самом рисовании.
- Для агента (4 из 5): каждый кадр рисуют руками. Агент может готовить подложки и запускать экспорт скриптом.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): Python-API для плагинов и скриптов, см. «Python Scripting» в руководстве; страница «Linux Command Line» есть. Покадровый вывод вызывают из меню. Вывод анимации из командной строки не проверял.
- Воспроизводимость (2 из 5): файл `.kra` двоичный (архив), результат зависит от ручной работы. Версии 5.3 и 6.0 выпускаются параллельно.

## Платформа и оборудование

Windows, macOS, Linux, Android. Для iOS и iPadOS версии нет (FAQ). Руководство на 5.3.0. Требований к видеокарте не искал; анимация ограничена объёмом памяти. В версии 5.3.4 и 6.0.4 (2026-09-15) экспорт видео добавлен на Android.

## Экспорт

- Последовательность PNG всегда; затем кодирование видео внешним FFmpeg: GIF, MP4, MKV и другие форматы, которые умеет FFmpeg ([Render Animation](https://docs.krita.org/en/reference_manual/render_animation.html)). Можно экспортировать только уникальные кадры.
- Альфа-канал: PNG-кадры с прозрачностью; поведение видео с альфой не проверял.

## Когда брать и когда нет

- Брать: бесплатная рисовалка для рукописных вставок, записи процесса рисования (Recorder) и коротких покадровых сцен у художника, который уже работает в Krita.
- Не брать: персонаж с костями ([synfig](synfig.md), [moho](moho.md), [spine](spine.md)), длинные покадровые сцены ([tahoma2d](tahoma2d.md), [tvpaint](tvpaint.md)), «рисование линий» с авто-вычерчиванием ([vivus](vivus.md)). Для кадра в 3D-сцене: [blender-grease-pencil](blender-grease-pencil.md).
