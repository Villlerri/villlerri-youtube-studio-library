# Moho

Векторная 2D-анимация с упором на кости: быстрый риг персонажа, умные кости (Smart Bones), покадровые кисти и скрипты на Lua. Бывшая Anime Studio. С 2020 года принадлежит Lost Marble LLC, компании автора программы. Две редакции: Debut и Pro.

- Скрипты (справочник сообщества): https://mohoscripting.com

## Что реально получается

- Кукольная анимация: кости с прямой и обратной кинематикой, булавочные кости (pin bones), ограничения, автоматическое сжатие и растяжение, перенос анимации между персонажами (пресс-релиз Moho 14, [AWN](https://www.awn.com/news/major-moho-14-update-now-available)).
- Умные кости (Smart Bones): суставы изгибаются без искажений и управляют мимикой, поворотом и движением тела. В версии 14.4 добавлены умные кости с поворотом на 360 градусов (по названию ролика разработчика).
- Векторное рисование, оптимизированное для анимации: формы остаются стабильными при движении. «Liquid Shapes» для мягких форм: огонь, дым, вода.
- Покадровые инструменты: Freehand, Blob Brush, Eraser на новом графическом движке; «умная линия-дрожь» (smart boil) в 14.2. Это даёт рисованную «бурлящую» линию без полной покадровой работы.
- Звук и голос: встроенный липсинк (улучшен в 14.2 для низких частот кадров). Подробности по инструменту не проверял.
- Скрипты на Lua; с 14.2 можно запускать Lua-скрипты при старте из командной строки.
- Экспорт в игровые движки и 3D-пакеты (Unreal, Unity, Godot, Blender, Maya) — в бесплатном обновлении 14.4 «SIDE QUEST»; название и описание из [блога Moho](https://moho.lostmarble.com/blogs/news/moho-announces-free-side-quest-update-for-moho-14-owners-export-to-video-game-engines-and-blender), прочитано в пересказе поисковой выдачи.
- Морфинг формы и камера: в просмотренных страницах отдельно не проверял. Прозрачное видео ProRes с альфой улучшено в 14.2.
- Для объясняющего видео: персонаж-проводник с мимикой и быстрые куклы в серии; векторная чёткость при любом размере.

## Слабые стороны

- Платформы только Windows и macOS.
- Две редакции: Debut упрощена, функции Pro в Debut недоступны. Что именно отличает, страница не читалась.
- Работа в Moho сводится к ручному риггингу: полной автоматизации нет.
- Официальный сайт при проверке отвечал HTTP 429 на все запросы; справка и цены напрямую не читались.

## Сложность

- Для человека (3 из 5): кости и умные кости надо изучать, остальное привычно для векторного редактора. Первый персонаж за недели.
- Для агента (4 из 5): интерфейс графический. Есть Lua и запуск скриптов с командной строки (14.2), но сцену собирает человек.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): скрипты на Lua, запуск Lua при старте из командной строки (заметки 14.2). Отдельный консольный рендер в просмотренных страницах не проверял.
- Воспроизводимость (3 из 5): проект в файле `.moho` (формат не проверял), рендер воспроизводится при той же версии.

## Активность и зрелость

Репозитория нет.

Зрелость: `stable`. Moho 14 вышел 2023-09-12 (Википедия), с тех пор бесплатные обновления 14.1, 14.2, 14.3 и 14.4 «SIDE QUEST» (по Википедии 14.4 от 2025-11-11). Развивает Lost Marble.

## Когда брать и когда нет

- Брать: векторный персонаж с костями за разовую плату в несколько сотен долларов; когда нужны умные кости для мимики; вместо Harmony при меньшем бюджете.
- Не брать: если нужен Linux; если нужен самый высокий уровень композитинга ([toon-boom-harmony](toon-boom-harmony.md)); если нужна бесплатная альтернатива ([synfig](synfig.md), [tahoma2d](tahoma2d.md)).
