# ElevenLabs (озвучка и метки времени)

Облачный сервис синтеза речи, распознавания речи (Scribe) и выравнивания текста по аудио. Для библиотеки важны два входа: синтез с посимвольными метками времени и Forced Alignment API для готового аудио. По правилу студии синтезированная озвучка делается только через ElevenLabs. Запись живого голоса, например автора канала, правило не ограничивает. API при подготовке карточки не вызывался: формат ответов взят из справочника.

  - [Forced Alignment, справочник API](https://elevenlabs.io/docs/api-reference/forced-alignment/create) — на вход аудио и текст, на выход времена по символам и словам.

## Что реально получается

- Синтез речи. Модели и русский язык по [странице моделей](https://elevenlabs.io/docs/overview/models): Eleven v4 (90+ языков, до 10 000 знаков за запрос), v3 (70+, 5 000), Multilingual v2 (29, 10 000), Flash v2.5 (32, 40 000). Русский подтверждён для всех четырёх. Качество голоса и ударения не слушал.
- Синтез с метками. Запрос `POST /v1/text-to-speech/{voice_id}/with-timestamps` возвращает аудио и три параллельных массива: символы, начало и конец каждого символа в секундах. Метки даны дважды: для исходного текста (`alignment`) и для нормализованного (`normalized_alignment`, числа раскрыты словами). Слов в ответе нет, их собирают по пробелам. Оба поля могут быть пустыми (`null`).
- Forced Alignment. Запрос `POST /v1/forced-alignment` принимает файл и текст. Ответ: символы и слова с `start`, `end`, у слов ещё `loss`, плюс общий `loss`. Подходит, когда голос записан не в сервисе (диктор, чужой файл) и когда надо проверить уже готовые метки. Язык: 29 языков моделей Multilingual v2, русский назван. Текст без разметки спикеров.
- Распознавание Scribe v2. Метки слов (`timestamps_granularity=word`) или символов, 90+ языков. Это путь, когда есть только аудио без сценария.
- Управление стыками. Поля `previous_text` и `next_text` и идентификаторы предыдущих запросов помогают держать интонацию между кусками. До трёх словарей произношения на запрос. Для русских терминов и ударений словарь стоит проверить на слух.
- Что сервис не делает: графики, морфинга, камеры нет. Его вклад — точные времена, на которые вешаются ключевые кадры в [manim-voiceover](manim-voiceover.md), [Remotion](remotion.md) и [Motion Canvas](motion-canvas.md).

## Слабые стороны

- Метки по символам, слов нет. Знаки препинания и пробелы тоже в массиве. Слова, паузы и ударные слова собирает свой код.
- При нормализации числа и сокращения становятся словами. Привязка `normalized_alignment` к строке сценария требует отдельной сверки.
- Результат не воспроизводится дословно: `seed` даёт «лучшее возможное» повторение, но не гарантирует его. Модели обновляются. Готовое аудио и метки хранят в проекте.
- Бесплатный тариф не даёт коммерческого права (раздел «Лицензия и права»). Генерировать «про запас» на Free для монетизируемого канала нельзя.
- MP3 192 кбит/с только с тарифа Creator, PCM и WAV 44,1 кГц только с Pro (справочник API).
- Облако: текст сценария уходит на серверы сервиса. Режим без хранения (`enable_logging=false`) только на Enterprise.
- Лимит длины запроса зависит от модели (5 000–40 000 знаков). Длинный сценарий режут по сценам.

## Сложность

- Для человека (2 из 5): веб-интерфейс осваивается за час. Метки требуют небольшого скрипта: разбор JSON и склейка символов в слова.
- Для агента (1 из 5): REST и SDK, ответ JSON. Агент сам проверяет, что времена возрастают и покрывают все символы. Руки и слух нужны для оценки произношения, ударений и интонации.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): REST API и SDK, региональные хосты (США, ЕС, Индия, Сингапур), оплата за использование.
- Воспроизводимость (2 из 5): тот же текст и тот же `seed` дают похожую, но не обязательно такую же запись. Модели меняются и выводятся. Кэш аудио и меток в репозитории проекта обязателен.

## Платформа и оборудование

Облачный сервис: веб-интерфейс и API, свой компьютер и видеокарта не нужны. Для API нужен ключ и интернет.

## Экспорт

- Аудио: MP3 (22,05 и 24 кГц, 44,1 кГц, 32–192 кбит/с), Opus 48 кГц, PCM и WAV 8–48 кГц, µ-law и A-law 8 кГц (справочник API).
- Метки: JSON в ответе API.
- Ограничения по тарифам: 192 кбит/с — Creator и выше, 44,1 кГц PCM и WAV — Pro и выше.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://elevenlabs.io/pricing) и [ценам API](https://elevenlabs.io/pricing/api).

- Free: $0, 10 000 кредитов в месяц, 3 проекта в Studio. Без коммерческой лицензии.
- Starter: $6 в месяц (первый месяц $1 по акции до 18 октября), 30 000 кредитов. Коммерческая лицензия, мгновенное клонирование голоса.
- Creator: $22 в месяц (первый месяц $11), 121 000 кредитов, профессиональное клонирование (1 слот), 192 кбит/с.
- Pro: $99 в месяц, 600 000 кредитов, PCM 44,1 кГц через API.
- Scale: $299 в месяц, 1,8 млн кредитов, 3 места, 3 профессиональных клона.
- Business: $990 в месяц, 6 млн кредитов, 10 мест, 10 профессиональных клонов. Enterprise: по договору.
- Годовая оплата: платишь за 10 месяцев из 12.
- Кредиты: 1 знак = 1 кредит на моделях V2 Multilingual. Скидочные модели Flash и Turbo через API — 0,5–1 кредита на знак. Распознавание Scribe — 330 кредитов за минуту. Неиспользованные кредиты на платных тарифах переносятся до двух месяцев.
- API без подписки (за 1000 знаков): v4 $0,08, v4 Turbo $0,04, v3 $0,08, v2 Multilingual $0,08, Flash и Turbo $0,04. Scribe v2: $0,22 за час.
- Forced Alignment тарифицируется как Speech to Text ([возможности](https://elevenlabs.io/docs/overview/capabilities/forced-alignment)), отдельной цены нет.
- Прикидка автора: русская речь около 1000 знаков в минуту, ролик на 10 минут — около 10 000 знаков, то есть около $0,8 через API. Тариф Starter на 30 000 кредитов покрывает три такие озвучки в месяц без повторов. Цифра 1000 знаков в минуту — оценка, не измерение.

## Лицензия и права

- Код или программа: проприетарный облачный сервис.
- Результат (из [условий использования](https://elevenlabs.io/terms-of-use) и [справки о публикации](https://elevenlabs.io/docs/help-center/legal/can-i-publish-the-content-i-generate-on-the-platform)):
  - Платные тарифы дают коммерческую лицензию, кроме Beta-сервисов. Условия: соблюдать Prohibited Use Policy. Права на результат остаются у пользователя; два пользователя могут получить одинаковый результат.
  - Бесплатный тариф: «не включает коммерческую лицензию и не может использоваться ни для каких коммерческих целей». Публиковать результат можно только некоммерчески и с указанием ElevenLabs: «elevenlabs.io» или «11.ai» в названии.
  - Контент, созданный вне платной подписки, нельзя использовать коммерчески. Контент, созданный в период платной подписки, можно использовать коммерчески и бессрочно.
  - Beta-сервисы: ни коммерчески, ни в рабочей среде.
  - Монетизация YouTube в условиях отдельно не названа. Вывод автора: ролик с рекламой — коммерческое использование, поэтому платный тариф нужен на момент генерации.
- Клоны голоса:
  - Мгновенный клон (IVC) с тарифа Starter, профессиональный (PVC) с Creator. Слотов PVC: 1 на Creator и Pro, 3 на Scale, 10 на Business ([страница цен](https://elevenlabs.io/pricing)).
  - PVC проходит проверку, что голос принадлежит владельцу аккаунта. Клонировать чужой голос нельзя даже с согласием владельца: владелец проходит проверку на своём аккаунте и делится клоном по ссылке ([документация](https://elevenlabs.io/docs/creative-platform/voices/voice-cloning)).
  - Нельзя клонировать живого человека без явного осознанного согласия. Нельзя использовать записи людей младше 18 лет. Нельзя удалять водяные знаки и сигналы происхождения. Раскрывать использование ИИ, где этого требует закон или где умолчание вводит в заблуждение ([политика использования](https://elevenlabs.io/use-policy)).
  - Клон нельзя скачать файлом, он живёт в аккаунте. При падении ниже Creator PVC остаётся, но не работает.
- Ассеты в комплекте: стандартные голоса и голоса Voice Library. Для Voice Library действует отдельное Addendum, его не читал. Бесплатным пользователям голоса из библиотеки через API недоступны ([страница Voice Library](https://elevenlabs.io/docs/creative-platform/voices/voice-library)).

Это сведения из условий использования, не юридическая консультация.

Зрелость: `stable`. Сервис коммерческий, Python SDK `elevenlabs` версии 2.72.0 вышел 2026-10-13 (PyPI). На сайте анонсирована модель Eleven v4, в справочнике указаны Scribe v2 и Eleven v3. ## Когда брать и когда нет

- Брать: единственный разрешённый студией источник озвучки. Нужны русская озвучка и точные метки, на которые вешается анимация. Метки без отдельного распознавания даёт `with-timestamps`, метки для чужой записи — Forced Alignment.
- Не брать: когда нужен офлайн, дословное повторение результата, бесплатная публикация ролика с рекламой.

## Неизвестно

- Поддерживают ли метки (`with-timestamps`) модели Eleven v3 и v4: страница моделей это не называет.
- Точность меток на русском, качество и ударения голоса: звук не слушал, API не вызывал.
- Лимит файла в Forced Alignment: справочник пишет «меньше 1 ГБ», страница возможностей — 3 ГБ, 10 часов и 675 000 знаков.
- Отдельная цена Forced Alignment: документация ссылается на тариф Speech to Text.
- Условия Voice Library Addendum и лицензии отдельных голосов.
- Доступ к API на бесплатном тарифе: страница цен «Creative» его не расписывает, на странице API бесплатный столбец указан с 10 000 знаков.
- Максимум кредитов в одном запросе: страница цен называет лимит, цифры нет.
- Знаков в минуту у русской речи: приведена оценка автора.
