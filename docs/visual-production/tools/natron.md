# Natron

Свободный узловой композитор, похожий по задачам на Nuke и After Effects. Последний стабильный выпуск 2.5.0 от 26 ноября 2022. Сегодня годится ограниченно.

  - [Compositing in Natron, part 1](https://www.youtube.com/watch?v=I0SunlioeRk) — канал Sean Kennedy. Серия по сборке кадра в Natron.

## Что реально получается

Опора: README проекта, страница сайта.

- Узловой граф с группами и сохранением своих блоков. Конвейер 32-бит с линейным цветом, управление цветом OpenColorIO.
- Ротоскопия с растушёвкой по вершинам, рисование по кадрам (rotopaint), 2D-трекинг, кеинг, кривые и таблица ключевых кадров (curve editor, dope sheet).
- Плагины OpenFX: в составе Natron OpenFX-IO, Misc, G'MIC, Arena. Сторонние коммерческие (Boris FX Sapphire и другие) запускаются, по README.
- Python: выражения параметров, пользовательские параметры, группы как скрипты, редактор скриптов. Установка сообществом PyPlugs (Gizmos) по drag-and-drop.
- Запуск без интерфейса для пакетного рендера и ферм.
- Для ролика: чистка кадра, ротоскопия объекта, маска, привязка плашки к движущемуся предмету, коррекция цвета.
- Непрерывная сцена: узловой граф ведёт один кадр по слоям, камеры в 3D и частиц в списке возможностей нет. Морфинг изображения в изображение готовым узлом не нашёл. Морфинг формы маски через ключевые кадры упомянут в названии урока (содержание не проверял).
- Рисование линий: rotopaint рисует мазки, анимируются ключевыми кадрами. Рисования «вживую» одним действием нет.
- Синхронизация с голосом: нет встроенной привязки к аудио.

## Слабые стороны

- Развитие почти остановилось. Стабильный 2.5.0 вышел в ноябре 2022. Пробные сборки: 2.6.0-alpha1 (8 декабря 2022), 2.5.1-pre1 (15 апреля 2023), 2.5.1-pre2 (13 сентября 2024). Последние коммиты ветки RB-2.6 датированы 24 июля 2026.
- Qt: Natron собирается на Qt 4 и Qt 5, Qt 6 не поддерживается, код C++98 (README). Это риск для будущих ОС.
- macOS: на сайте только Intel, на Apple Silicon идёт через Rosetta 2. Нативная сборка только в альфе.
- Разделы документации с пометкой «(empty)»: Expressions, Keying, Noise removal.
- В списке возможностей README нет 3D, частиц и трекинга камеры.

## Платформа и оборудование

- Windows 8.1, 10, 11 (64-бит), установщик и portable zip.
- GNU/Linux x86_64 с X11, glibc 2.17+, установщик, архив или Flatpak.
- macOS: Intel (на M-чипах через Rosetta 2), сборки для macOS 11+ и более старых.
- Требования к памяти и видеокарте не найдены.

## Экспорт

- Форматы: H.264, DNxHR, EXR, DPX, TIFF, JPG, PNG через OpenImageIO и FFmpeg (README).
- Доступен рендер в последовательности кадров. Ограничений по разрешению нет в описании.

## Когда брать и когда нет

- Брать: бесплатный композитинг по узлам на Linux для ротоскопии, чистки кадра и трекинга, пакетный рендер.
- Не брать как основу студии: риск остановки развития, Qt без 6-й версии. Для узловой работы лучше Fusion в [DaVinci Resolve](davinci-resolve.md) (бесплатная версия) или компоновщик [Blender](blender.md). Это вывод автора карточки.
