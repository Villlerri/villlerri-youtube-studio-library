# vvvv gamma

Визуальная среда программирования для Windows: узлы и провода плюс полноценный C# и .NET. Для графики использует движок Stride (3D) и Skia (2D). Делает интерактив, медиасерверы и генеративную графику; видео пишется отдельным способом.

## Ссылки

- Официальный сайт: https://vvvv.org (адрес visualprogramming.net перенаправляет сюда)
- GitHub: у среды открытого кода нет. Открыты только её библиотеки: https://github.com/vvvv/VL.StandardLibs
- Документация: https://thegraybook.vvvv.org/
- Примеры, проверенные 2026-10-14 (ролики проверены через oEmbed, видео не смотрел):
  - [Tutorial for Absolute Beginners of VL: 1. Navigating the Environment](https://www.youtube.com/watch?v=7m1EzfxUtzo) — The NODE Institute; интерфейс и первые узлы.
  - [vvvv gamma Graphics Tutorial: GPU Instancing](https://www.youtube.com/watch?v=fyG63KEVhoo) — Takuma Nakata; много объектов на GPU.
  - [Video Recording](https://thegraybook.vvvv.org/reference/best-practice/video-recording.html) — официальная страница о записи видео и последовательностей.

## Что реально получается

- Реал-тайм 3D (Stride) и 2D (Skia), интерфейсы (ImGui), видео, звук, датчики; на сайте называют медиасерверы, интерактивные инсталляции, лазеры, свет. Сцены `field`, `simulation`, `scale`.
- Непрерывность: программа — один живой граф; сцена не пересобирается между кадрами, камера и объекты живут постоянно.
- Анимация: узлы-генераторы (LFO, фильтры) и C#-код; готового таймлайна для видео нет.
- Морфинг, рисование линий, типографика: собираются вручную из узлов и библиотек. Готовых приёмов под объясняющее видео нет.
- Голос: привязки к озвучке нет; возможна ручная синхронизация сигналами.
- Потолок качества (4 из 5): картинка зависит от Stride и вашей работы, готовой «научно-популярной» эстетики нет.

## Слабые стороны

- Только Windows (x64 и Arm). Страница: «vvvv does not have a native version for macOS!»; для Mac на Apple Silicon предлагают Parallels со сборкой Windows Arm.
- Запись видео не встроена в виде одного узла. Страница о записи называет три пути: запись экрана в реальном времени (Xbox Game Bar, NVIDIA, AMD, OBS Studio, LiceCap для GIF), пакет `VL.ScreenRecorder` и офлайн-запись последовательности кадров (`TextureWriter` + `SceneTexture` в VL.Stride, `ImageWriter` с офлайн-рендерером в VL.Skia). Форматы видео контейнера и кодека страница не называет.
- Офлайн-запись не подходит для сцен, которые зависят от реальных параметров (анализ звука, датчики).
- Формат `.vl` — XML. Git его хранит, но слияния «могут повредить файлы»: документация советует делить проект на несколько файлов и не сливать правки.
- Ядро и редактор закрыты: на вопрос «так vvvv теперь открыт?» авторы отвечают «No».
- Нужна коммерческая лицензия разработчика, если ролики приносят деньги.

## Сложность

- Для человека (4 из 5): визуальное программирование с типами, «спредами» и итерацией. Видео-курс для новичков состоит из семи частей. Для результата нужны ещё C# и основы 3D.
- Для агента (3 из 5): C#-код и NuGet-пакеты можно писать текстом, `.vl`-файл — XML. Но сборка графа идёт в редакторе, а запуск и оценка кадра требуют Windows и запущенной среды. Агент пишет узлы на C#, человек собирает граф.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): есть расширение на C# и NuGet, экспорт отдельных исполняемых файлов (Windows), офлайн-запись кадров. Среда не имеет известной командной строки для безголового рендера (в проверенных страницах не нашёл).
- Воспроизводимость (3 из 5): проект — текст в XML, но слияния ненадёжны. Режим «Is Incremental» у узла `MainLoop` с заданным «Incremental FPS» ведёт часы по фиксированному шагу: зависящие от времени узлы (LFO, фильтры) идут правильно, как бы долго ни писалась картинка на диск. Это даёт повторяемые кадры при отсутствии реальных входов.

## Платформа и оборудование

Windows (x64 и Windows Arm). Видеокарта нужна для Stride. Версия 7.4 — последняя на странице. Подробные требования не искал.

## Экспорт

- Офлайн: последовательности изображений (`TextureWriter`, `ImageWriter`), одиночные кадры. GIF — через LiceCap.
- Запись в реальном времени: Xbox Game Bar, NVIDIA, AMD, OBS Studio; из приложения — `VL.ScreenRecorder`, `VL.LoopTool` («Captures video, image sequences and images»).
- Автономный `.exe` с неограниченным числом экспортов для держателя лицензии разработчика.
- Прозрачность и кодеки готового видео в документации не названы.

## Когда брать и когда нет

- Брать: если команда уже живёт на C#, на Windows и нужна интерактивная реал-тайм графика или инсталляция, а ролик выходит как побочный продукт.
