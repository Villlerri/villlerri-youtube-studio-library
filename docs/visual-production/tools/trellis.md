# TRELLIS (TRELLIS.2)

Открытая модель Microsoft: одна картинка превращается в 3D-объект с полными PBR-материалами (цвет, шероховатость, металличность, прозрачность). Текущая TRELLIS.2 (4 млрд параметров, декабрь 2025); первая TRELLIS (декабрь 2024) тоже открыта. Для видео — локальный источник заготовок предметов для сцены в [Blender](blender.md).

## Что реально получается

Опора: README TRELLIS.2 и TRELLIS, карточка весов. Генераций я не запускал, установка запрещена.

- Вход: одна картинка. Выход: 3D-объект с PBR-материалами (базовый цвет, шероховатость, металличность, непрозрачность). Текстовая версия есть в первой TRELLIS, но её авторы советуют сначала получить картинку и подавать её в image-модель.
- Представление O-Voxel: произвольная топология (открытые поверхности, листва, внутренние полости, не-многообразные сетки).
- Разрешение и скорость на H100: 512³ около 3 секунд, 1024³ около 17, 1536³ около 60 (по README).
- Экспорт в `.glb` (по умолчанию в режиме OPAQUE; прозрачность включается вручную в 3D-пакете). Пример кода выдаёт также видео-превью `sample.mp4`.
- PBR-текстурирование для готовой формы: отдельный скрипт `example_texturing.py`.
- Для сцен: предмет или деталь прибора по картинке. Движение камеры и сборку сцены делает Blender; согласованность между кадрами — свойство 3D-сцены.
- Вывод автора: лучший открытый вариант «картинка в 3D» для заготовок. Реальную точность формы, размеры и правильные детали модель не гарантирует.

## Слабые стороны

- Видеопамять: нужна NVIDIA GPU минимум 24 ГБ, проверено на A100 и H100. Linux — единственная проверенная система.
- Зависимости с некоммерческими лицензиями: `nvdiffrast` (рендеринг результата) и `nvdiffrec` (PBR) — NVIDIA Source Code License: использование «только некоммерческое… для исследования или оценки». Это касается цепочки запуска, а не весов. Нужна юридическая проверка перед коммерческим конвейером.
- Каждая картинка даёт один из вариантов, повтор даёт другой.
- Установка сложна: CUDA Toolkit 12.4, компиляция расширений (по README).

## Сложность

- Для человека (4 из 5): Linux, CUDA, сборка расширений, Python.
- Для агента (2 из 5): запуск Python-скрипта, получение `.glb`, проверка рендером в Blender. Нужна машина с видеокартой 24 ГБ.

## Платформа и оборудование

Linux, NVIDIA GPU от 24 ГБ (A100, H100), CUDA Toolkit 12.4, PyTorch 2.6 по умолчанию. Облачное демо на Hugging Face Spaces.

## Экспорт

GLB (PBR-текстуры, режим OPAQUE по умолчанию), видео-превью MP4. До 1536³ вокселей; упрощение сетки до 16 777 216 граней (лимит nvdiffrast).

## Когда брать и когда нет

- Брать: локально получать заготовки предметов из картинки (например из FLUX или Recraft-растра) и ставить их в сцену Blender.
- Брать, если облачные сервисы вроде [Meshy](meshy.md) не подходят по цене или данным.
- Не брать: коммерческий конвейер без проверки лицензий `nvdiffrast` и `nvdiffrec`; Windows и видеокарты меньше 24 ГБ.
- Не брать для точных научных моделей (молекулы, приборы): использовать [Molecular Nodes](molecular-nodes.md) или модель по чертежу.
