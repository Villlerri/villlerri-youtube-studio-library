# Storyboarder

Бесплатная программа для быстрой раскадровки и черновой анимации (аниматика) от студии Wonder Unit. Рисуют эскизы-кадры, вводят реплики, задают длительность, вставляют звук и выгружают видео. Развитие остановилось в 2022 году, лицензия не определена.

## Что реально получается

- Раскадровка. Кисти для набросков, направляющие (сетка, трети, углы), «луковая кожа». Слоёв нет, есть опорный слой (Reference Layer). Рисуют мышью или пером. Есть печать листов-шаблонов, рисунок от руки потом снимают на телефон и импортируют.
- Сценарий. Открывает сценарий в формате Fountain. Для каждого кадра вводятся реплики, действие, тип плана и «информация о времени» ([сайт](https://wonderunit.com/storyboarder/)).
- Аниматик. По описанию ролика John McCaffrey: длительность кадра выставляется автоматически по репликам, можно загрузить звук и подогнать тайминг, затем выгрузить видео. Для студии это проверка ритма ролика на эскизах до того, как начнётся анимация.
- Shot Generator. Трёхмерный генератор кадров: описывают план, получают референс, который кладётся на слой подложки и обводится.
- Экспорт. По сайту: Premiere, Final Cut, Avid, PDF, анимированный GIF. Экспорт для монтажных программ позволяет собрать аниматик там.
- Русский. Интерфейс с версии 3.0.0 локализован на русский.
- Роль в конвейере студии. Схема «сценарий → озвучка → аниматик»: голос от [ElevenLabs](elevenlabs.md) подкладывают под эскизные кадры. Смотрят, нет ли повтора одного кадра в разной крупности и развивается ли сцена. Метки слов для самих кадров здесь не нужны, достаточно длительности реплики.
- Непрерывность сцены, морфинг, камера, рисование линий в анимации — не его задача: кадры статичны, движение показывается сменой кадров.

## Слабые стороны

- Развитие остановлено. Последний релиз 3.0.0 — 2021-02-17, последний коммит в основной ветке — 2022-06-30. Внутри Electron 18.0.2 (`package.json`), ошибки на новых системах не исправляются.
- Лицензия не определена (раздел «Лицензия и права»). Для продакшена это риск.
- Анимации внутри кадра нет: движение камеры и объектов в аниматике не показать.
- Скачивание с сайта идёт через форму с адресом почты. Сборки есть и на странице релизов GitHub.
- Сайт устарел: на нём указана версия 1.0.0.
- Конвейер без интерфейса невозможен: проект собирается в окне.

## Сложность

- Для человека (1 из 5): освоить за день. Набросать кадры и положить звук умеет любой.
- Для агента (4 из 5): интерфейс, программного API и командной строки для сборки аниматика нет. Программа принимает путь к файлу проекта при запуске (`DEVELOPERS.md`). Агент может готовить сценарий Fountain и раскадровку-референсы, но собрать и подогнать аниматик делает человек.

## Автоматизация и воспроизводимость

- Автоматизация (1 из 5): скриптов и API нет. Известны запуск с путём к файлу и экспорт из меню.
- Воспроизводимость (3 из 5): проект хранится файлом `.storyboarder` (по `DEVELOPERS.md`). Состав проекта и формат не описаны, пригодность для git не проверял.

## Платформа и оборудование

macOS, Windows, Linux (сайт и скрипты сборки `package.json`: `dist:mac`, `dist:win`, `dist:linux`). Приложение на Electron, видеокарта для рисования не нужна.

## Экспорт

PDF, анимированный GIF, видео и проекты для Premiere, Final Cut, Avid (по сайту). Прозрачности и точных характеристик видео в документации не нашёл.

## Лицензия и права

- Код или программа: исходный код выложен на GitHub, но файла лицензии в репозитории нет. В `package.json` в поле `license` стоит путь к тексту EULA Wonder Unit (`build/license_en.txt`), в нём «Free version» и «Upgraded version». В заметке студии «Thoughts on Free and Open Source» (дата на странице не указана) сказано: программа будет под MIT с исключениями. Исключения: нельзя брать плату, при распространении нужна ссылка на Storyboarder и Wonder Unit, учебным заведениям отдельная версия. Какой из текстов действует, не установлено.
- Результат: в EULA и на сайте нет оговорок про права на готовые кадры и видео. Это не означает, что их нет.
- Ассеты в комплекте: модели Shot Generator, позы, шаблоны. Условия отдельно не нашёл.

Это сведения из публичных текстов, не юридическая консультация.

## Когда брать и когда нет

- Брать: быстрый черновик ритма ролика на эскизах под готовую озвучку, когда допустим риск неподдерживаемой программы.
- Не брать: как основу производства. Нет анимации внутри кадра, нет поддержки, неясная лицензия. Для аниматика с движением камеры смотри [Blender Grease Pencil](blender-grease-pencil.md) и [Motion Canvas](motion-canvas.md).
