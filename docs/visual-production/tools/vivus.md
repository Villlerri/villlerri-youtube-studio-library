# Vivus

Лёгкая JavaScript-библиотека без зависимостей: рисует контуры SVG так, будто их выводит перо. Работает через свойство `stroke-dashoffset`. Остановлена в развитии: последний выпуск 2021 года.

## Что реально получается

Опора: README и страница демо.

- Контуры SVG «выводятся» линиями: пути, окружности, прямоугольники и т. д. Встроенный «pathformer» превращает фигуры в пути.
- Режимы: `delayed` (все пути сразу, со слабой задержкой, по умолчанию), `sync` (все начинают и заканчивают вместе), `oneByOne` (по очереди, по демо «лучшее ощущение живого рисования»), `scenario` и `scenario-sync` (время задаётся атрибутами `data-*` в SVG).
- Управление: `play`, `stop`, `reset`, `finish`, `setFrameProgress(progress)`, `getStatus`. Функции плавности для каждого пути и для всей анимации.
- Подходит для линейных иллюстраций: схемы, контуры, подписи. Это ближайший по смыслу к «рисованию вживую» способ из карточек, не требующий пера и записи.
- Выводятся только штрихи, заливки нет (README). Заливку можно включить после вывода контура (приём из общей практики, не из README).
- Текст `<text>` не поддерживается: сначала нужно превратить его в контуры (README).
- Синхронизация с голосом: `setFrameProgress` позволяет задавать прогресс вручную по времени, значит голос можно привязать кодом. Привязки к тексту сценария нет.
- Морфинг и камера: нет.

## Слабые стороны

- Не развивается: последний выпуск 0.4.6 в апреле 2021, последний коммит июль 2022.
- Только контуры. Заливки и текст не рисуются. Скрытые пути создают разрывы в анимации.
- Для `vector-effect="non-scaling-stroke"` нужно вызывать `recalc()` при изменении размера.
- Вывод в видео не встроен: нужно снимать кадры браузера.
- Функции плавности вызываются каждый кадр, поэтому их нужно делать простыми.

## Сложность

- Для человека (2 из 5): нужны HTML, SVG и базовый JavaScript. Подготовка контуров (штрихи без заливки) в Illustrator, Inkscape или Figma. Оценка автора карточки.
- Для агента (2 из 5): агент пишет HTML со скриптом и SVG. Покадровый рендер, например, браузером под управлением Playwright или аналога ([CCapture.js](ccapture-js.md)), не проверялся.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): всё кодом. `setFrameProgress(progress)` ставит прогресс анимации на любое значение, этого достаточно, чтобы снимать детерминированные кадры без реального времени.
- Воспроизводимость (4 из 5): HTML, JS и SVG — текст под git. Результат зависит от версии браузера и подготовленного SVG.

## Платформа и оборудование

## Когда брать и когда нет

- Брать: когда нужен вывод линейных SVG-иллюстраций «пером» в веб-сцене, собираемой кодом.
- Брать: как простейшая замена «руке, рисующей картинку» из конструкторов, но по собственным контурам.
- Не брать: если нужна заливка или текст, или нужна поддерживаемая библиотека. Тогда анимация `stroke-dashoffset` на [GSAP](gsap.md) или код ([Motion Canvas](motion-canvas.md)).
- Не брать: если нужно рисовать вживую пером. Тогда запись ([OBS Studio](obs-studio.md)).
