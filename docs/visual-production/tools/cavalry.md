# Cavalry

2D-программа для motion design с процедурным подходом: дубликаторы, поведения, связи между свойствами, JavaScript. С 2026 года принадлежит Canva и бесплатна для частных лиц. Ближайший аналог After Effects для плоской вектор-графики, но 3D в проверенных разделах документации не упомянуто.

## Что реально получается

Опора: документация Cavalry (список узлов, Render Manager), примеры выше.

- Типографика. Узел Text Shape даёт дочерний элемент на каждую строку, слово и символ. Это основа для кинетического текста по буквам.
- Процедурная анимация. Дубликатор копирует форму по сетке или по пути, поведения (Stagger, Oscillator, Wave, Spring, Noise, Look At, Squash and Stretch) раздают движение копиям. Таблицы (Spreadsheet) подключаются как источник данных. Из них собираются инфографика и графики по таблице.
- Морфинг. В списке поведений есть Morph и Blend Shape. Как они работают на реальных формах, я не проверял.
- Камера. В утилитах есть Camera и Camera Guide. 3D в разделе форм не упомянуто, это плоская система.
- Рисование линий. Узлы Trails, Points to Path, Segment Path, Cel Animation Shape (покадровая анимация). Готового «рисования» Trim Path-аналога в проверенных списках я отдельно не нашёл. Это нужно проверить в приложении.
- Физика и частицы: узлы Forge Dynamics и Particle Shape.
- Непрерывная сцена. Среди форм есть Composition и Component (вложение сцен). Как работает Camera, не проверял. Готового примера длинной сцены на объяснении я не нашёл.
- Синхронизация со звуком: поведение Sound. Привязки к тексту сценария нет. Времена слов от ElevenLabs можно подавать через Spreadsheet или JavaScript (идея, не проверено).

## Слабые стороны

- Командная строка недоступна с версии 2.7 (в версии 2.8.0 тоже). Страница CLI помечена «Legacy». Пакетный рендер без интерфейса через нее больше не сделать. В старых версиях `render`, `list` и `--prompt` требовали лицензию Enterprise.
- Нужен аккаунт Canva: программа просит войти при запуске (CG Channel).
- ИИ-функции (AI Studio) требуют платный план Canva. Для видео в бесплатном режиме они не нужны.
- Lottie: не поддерживаются фильтры, шейдеры, часть градиентов, пунктир, маски на группе. Текст превращается в формы.
- Linux в требованиях не указан.
- Видео H.264/MP4 ограничено 9 437 184 пикселями (до 4096 x 2304 в формате 16:9).
- Формат проекта `.cv` не проверялся: двоичный или текстовый, неизвестно.

## Сложность

- Для человека (3 из 5): интерфейс проще After Effects, но процедурное мышление (дубликаторы, поведения, связи) непривычно. Первую сцену повторяют по официальному ролику на 11 минут, свободная работа с системой занимает недели. Оценка автора карточки.
- Для агента (3 из 5): агент пишет JavaScript-скрипты (`api`, `ctx`, `cavalry`, `def`) и может ставить их в папку Scripts. С версии 2.8 есть MCP-сервер: Claude управляет запущенным Cavalry (по документации: массовые правки слоёв, переименование, создание собственных инструментов). Приложение должно работать с лицензией Canva. Рендера без интерфейса нет. Проверка кадра: рендер через очередь вручную или через render scripts.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): JavaScript API (создание слоёв, атрибутов, соединений, ключевых кадров), JavaScript Layer, JavaScript Shape и Deformer, скрипты с интерфейсом, скрипты до и после рендера очереди (блокируют рендер, пока работают), MCP-сервер в 2.8. Командной строки нет в 2.7 и выше. Web Player (бета) проигрывает анимации в браузере.
- Воспроизводимость (3 из 5): проект воспроизводит результат на той же версии. Формат файла не проверен, считаю двоичным. Скрипты и процедурные сцены хорошо повторяют результат, но нужен запущенный Cavalry.

## Платформа и оборудование

- Windows 10 и новее (Intel, AMD; ARM через эмуляцию Prism, медленнее). macOS 12.0 и новее (Intel и Apple Silicon). Видеокарта с OpenGL 4.1 Core Profile; для Intel нужен Gen. 12 (Alder Lake) и новее.
- Документация называет минимум 512 МБ ОЗУ. Для HD-сцен реальной нагрузки это не отражает, оценки у меня нет.
- Linux не указан, мобильной версии нет.

## Экспорт

- Видео: MP4 (H.264), QuickTime (Motion JPEG, Uncompressed 422, ProRes; альфа только ProRes 4444 и 4444 XQ), WebM (VP8, VP9, AV1; альфа не поддерживается). Аудио: AAC, AIFF, WAV.
- Картинки: PNG (8 и 16 бит, с альфой), JPEG, WebP, APNG, GIF (с альфой), спрайт-листы.
- Векторы: SVG как последовательность файлов (не анимированный SVG) и Lottie (`.json`, с оговорками выше).
- EXR в Render Manager не найден.
- Ограничений бесплатной версии по разрешению теперь нет: до перехода к Canva бесплатная версия была ограничена HD (CG Channel).

## Стоимость

Проверено 2026-10-14 по [главной странице](https://cavalry.studio/en/) и [CG Channel](https://www.cgchannel.com/2026/04/canva-makes-motion-graphics-and-animation-app-cavalry-free/).

- Бесплатно для частных лиц, «без ограничений и платежей». Нужен бесплатный аккаунт Canva. Для коммерческих проектов отдельных ограничений в источниках нет (CG Channel: использование в коммерческих проектах разрешено).
- Версия с единым входом (SSO): через Canva Enterprise или Canva Districts, цена по запросу.
- Прежние платные лицензии Teams и Pro: функции Pro остаются в версиях 2.6.1 и старше, при возврате денег доступ к ним пропадает. До перехода Pro стоил £192 в год (CG Channel, вторичный источник).
- Оценка стоимости 0: для студии из частных лиц достаточно бесплатной версии. Если студия считается компанией, условия неясны (см. «Неизвестно»).

## Активность и зрелость

Зрелость: stable. Первый выпуск в 2020 году (по выдаче поиска к материалу uktech.news). Canva купила Cavalry в феврале 2026 (CG Channel, 80.lv), бесплатной сделала в апреле 2026 (версия 2.7). Версия 2.8.0 вышла 2026-09-30 (примечания к выпуску). Развивает команда Cavalry внутри Canva.

## Когда брать и когда нет

- Брать: кинетическая типографика, инфографика, сетки и повторы, плоская вектор-анимация без подписки на Adobe, генерация сцен скриптами.
- Брать: когда нужен Lottie без After Effects.
- Не брать: если нужен рендер без интерфейса на сервере. Командной строки с 2.7 нет.
- Не брать: если нужен 3D, композитинг по съёмке, трекинг. Для этого [DaVinci Resolve](davinci-resolve.md) (Fusion) или [After Effects](after-effects.md).
- Не брать: если студия Linux-ная. Версии нет.
