# Maya

Профессиональный 3D-пакет Autodesk для анимации персонажей, риггинга и эффектов (Bifrost), с рендером Arnold. Индустриальный стандарт кино и сериалов. Для объясняющих роликов дорог и избыточен, если не нужен тонкий риггинг персонажей.

## Ссылки

- Официальный сайт: https://www.autodesk.com/products/maya/overview (для скриптовых запросов отвечает 403, страницу читал через архив)
- GitHub: открытого кода нет.
- Документация: https://help.autodesk.com/view/MAYAUL/2027/ENU/
- Примеры, проверенные 2026-10-14:
  - [Generate animation with AI using Motion Maker in Maya 2026.1 (Maya Learning Channel)](https://www.youtube.com/watch?v=0IP8FXbPmeE) — превращение простых путей в анимацию персонажа; пример инструмента на ИИ внутри Maya.

## Что реально получается

- Персонажи и риггинг: сильнейшая сторона. Анимация и инструменты для сложных тел; на странице продукта показаны работы студий (Framestore и др.).
- Процедурные эффекты и симуляции: Bifrost (по странице «a procedural content creation tool in Maya for film, TV, and games», от взрывов до ткани).
- Рендер: встроен Arnold («Maya includes the Arnold renderer»).
- Непрерывность и камера: стандартные возможности 3D, непрерывная сцена без склеек.
- Для механизмов и схем: возможно, но удобнее [blender](blender.md) или [cinema-4d](cinema-4d.md).
- Рисование линий, формулы: не для этого.
- Голос: нет встроенной привязки к тексту озвучки.
- ИИ в Maya: на странице продукта значатся Autodesk Assistant (Tech Preview, естественный язык), генерация текстур через сторонние решения в LookdevX, MotionMaker (видео выше).

## Слабые стороны

- Дорого (см. «Стоимость»), подписка продлевается каждый год.
- Работа ведётся внутри программы с лицензией; открытых скриптов-проектов нет.
- Эффективность для научно-популярных сюжетов не подтверждена публичными примерами.
- Maya Indie требует соблюдения порогов дохода, иначе нужна полная лицензия.

## Сложность

- Для человека (5 из 5): профессиональный пакет, месяцы обучения.
- Для агента (3 из 5): страница продукта ссылается на MEL и Python как способ делать инструменты, то есть скриптовать сцену можно. Пакетный рендер и автоматический запуск без интерфейса по официальным страницам не проверял. Часть работы остаётся за человеком.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): MEL и Python (цитата SEGA на странице продукта: «ease of developing tools in MEL and Python»). Запуск без интерфейса не проверялся.
- Воспроизводимость (3 из 5): проектный файл воспроизводит результат. Формат файлов и работа с git не проверялись, оценка осторожная.

## Платформа и оборудование

Windows, macOS и Linux (страница продукта: «Maya can run on Microsoft Windows, Apple macOS, and Linux»). Подписка даёт доступ к установке трёх предыдущих версий. Системные требования см. справку Autodesk (не читал).

## Экспорт

Рендер Arnold в изображения и последовательности кадров; видео обычно собирают в монтажной программе. Подробный список форматов не проверялся.

## Стоимость

Проверено 2026-10-14 по [странице Maya](https://www.autodesk.com/products/maya/overview) (снимок web.archive.org от 2026-10-12; прямой запрос даёт 403).

- Годовая подписка $2010, помесячная $255, трёхлетняя $6025. В шапке страницы: «Starting at $168 / month».
- Maya Creative: только через жетоны Flex («pay-as-you-go option for daily use»), урезанный набор базовых инструментов.
- Студенты и преподаватели аккредитованных учебных заведений: бесплатный доступ на один год через Autodesk Education Community.
- Maya Indie ([страница](https://www.autodesk.com/campaigns/me-indie/maya-indie), снимок 2026-09-30): годовая выручка от творческой работы меньше $100 тыс. USD, стоимость проекта не выше $100 тыс.; «all of the same features … including the integrated Arnold renderer»; разрешено коммерческое использование («Maya Indie can be used for commercial, professional, or other for-profit purposes»); продление вручную. Если фрилансера наняла студия за время работы, нужна полная лицензия. Порог зависит от региона (в Европе, Индии и АСЕАН другие суммы). Цена Maya Indie на странице не указана; вторичный источник называет $305 в год (не проверено).

## Лицензия и права

- Код или программа: proprietary, условия Autodesk (EULA не читал).
- Результат: коммерческое использование разрешено платным подпискам и Indie в пределах порогов. Студенческая лицензия «can only be used for learning, training, or research».
- Ассеты в комплекте: условия не проверены.

## Активность и зрелость

Зрелость: `standard`. Текущая версия Maya 2027 (заголовок страницы продукта на 2026-10-12); выпуск 2026.1 с MotionMaker есть на канале Maya Learning. Развивает Autodesk.

## Когда брать и когда нет

- Брать: персонажный сюжет с сложным риггингом, студия, где Maya уже есть.
- Не брать: для научных схем и объяснений (дороже и сложнее, чем [blender](blender.md) и [godot](godot.md)); для проектов без бюджета.
