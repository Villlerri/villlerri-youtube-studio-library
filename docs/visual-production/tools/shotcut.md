# Shotcut

Свободный видеоредактор на движке MLT и Qt. Автор Dan Dennedy. Версия 26.9.27 от 27 сентября 2026.

## Что реально получается

Опора: страница возможностей, заметки о выпуске 26.9.27.

- Дорожки, фильтры (размытие, хромакей, цветокоррекция и другие), у параметров фильтров ключевые кадры с функциями плавности.
- Переходы: шторки (bar, barn door, box, clock, diagonal, iris, matrix, по своей градиентной картинке). Растворение делается перекрытием клипов на одной дорожке. Сложных переходов вроде морфинга нет.
- Adjustment Clip (26.9): пустой клип, чьи фильтры применяются к сумме всех нижних видеодорожек. Удобно для общего цвета или зерна на всю сцену.
- GPU-обработка в OpenGL с 16-битной плавающей точкой, аппаратное кодирование и декодирование.
- Чтение и запись видео с альфа-каналом, экспорт отдельных кадров.
- Whisper для субтитров: в заметках 26.9.27 есть исправление безопасности загрузки моделей Whisper, из чего следует наличие функции (прямого описания функции я не читал).
- Непрерывная сцена, морфинг, рисование линий, камера: встроенных инструментов нет. Увеличение и сдвиг делаются ключевыми кадрами фильтров. Вывод: так получается один кадр в разной крупности, которого канал хочет избежать.
- Синхронизация с голосом: ручная.

## Слабые стороны

- Нет композитинга со слоями-узлами, 3D и частиц.
- Автоматизации мало: нет скриптового API, ручной рендер через `melt` по XML проекта.
- Документация `melt` по отзывам форума слабая, ответы на форуме часто старые (2018–2021).
- В 26.9.27 исправлены ошибки безопасности в сетевых загрузках (повторный запрос по HTTP, игнорирование ошибок сертификата, непроверенные модели Whisper). Авторы советуют обновиться всем.

## Сложность

- Для человека (2 из 5): простой интерфейс с панелями. Оценка автора карточки.
- Для агента (4 из 5): API нет. Агент может писать MLT XML и рендерить `melt`, проверять сам.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): рендер через `melt`: `melt project.mlt -consumer avformat:export.mp4` (команда с форума Shotcut). Удобный путь с форума: экспортировать задачу из интерфейса, открыть её XML в панели Jobs, потом отдать `melt`. Чистого режима без X-сервера не подтверждено: форум пишет о «Xvfb».
- Воспроизводимость (3 из 5): проект в MLT XML (текст), но проекты Shotcut завязаны на версию и установленные плагины. В 26.9.27 внешние плагины отключены по умолчанию (флажок Allow External Plugins).

## Платформа и оборудование

- Windows, macOS, Linux. Qt 6.4 и новее для сборки.
- Системные требования к памяти и видеокарте на сайте не нашёл.

## Экспорт

- Сотни форматов через FFmpeg (в 26.9.27 FFmpeg 9.0), до 4K, смешивание разных форматов и частот кадров в одном проекте.
- Альфа-канал читается и пишется. Измерение PSNR и SSIM, график битрейта.
- Конкретные пресеты YouTube не проверены.

## Когда брать и когда нет

- Брать: простой бесплатный редактор, сборка из готовых клипов, цветокоррекция, аппаратное кодирование.
