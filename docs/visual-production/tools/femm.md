# FEMM (Finite Element Method Magnetics)

Бесплатный конечно-элементный решатель Дэвида Микера для плоских и осесимметричных задач магнитостатики, переменного поля, электростатики, теплопередачи и токов. Маленький, быстрый, с Lua-скриптами и интерфейсами Python, Octave, Matlab.

## Что реально получается

Сквозной пример (магнит на холодильнике). Полосатый магнит бесконечной длины — естественная плоская задача. Блоки с намагничиванием вверх и вниз задаются поочерёдно, для каждого блока свое направление (так устроен пример Permanent Magnet Example). Дверь холодильника — блок стали с кривой B-H: FEMM учитывает насыщение (FAQ, вопрос 4). Это главное преимущество перед аналитическим [magpylib](magpylib.md): стальная дверь рассчитывается честно, и видно, как поток замыкается в стали и сила притяжения растёт.

Что получается на выходе:

- Карта плотности потока (`mo_showdensityplot`), линии поля как изолинии векторного потенциала A (`mo_showcontourplot`), векторные стрелки (`mo_showvectorplot`).
- Числа: `mo_getpointvalues(x,y)` возвращает B, H, A в точке. Скрипт может обойти сетку и записать данные, из них потом строится красивая карта в [matplotlib](matplotlib.md) или [pyvista](pyvista.md). Это лучший путь для видео.
- Картинка из самой программы: `mo_savebitmap` — снимок окна (BMP), `mo_savemetafile` — EMF. Внешний вид фиксированный, это инженерное окно Windows.
- Движение: FEMM не анимирует. Движение магнита делается циклом: скрипт сдвигает геометрию, перерасчитывает, сохраняет кадр или данные. Шаг на шаге выходит ломаное движение, плавность зависит от числа шагов. Пример движения ротора с периодическим граничным условием: [Rotor Motion](https://www.femm.info/wiki/RotorMotion).
- Морфинг и непрерывная сцена: ничего встроенного. Склеивание переходов — на стороне рендера (Manim, After Effects) по выгруженным данным.
- Рисование линий: линии поля — готовые изолинии, не растут сами. Рост линий придётся рисовать в другом инструменте по данным.
- Синхронизация с голосом: нет.

## Слабые стороны

- Только 2D (плоская и осесимметричная). FAQ, вопрос 20: «3D-версии нет». Реальный магнит конечной длины и торцевые эффекты не показать.
- FEMM 4.2 — программа для Windows. На Linux работает через Wine (FAQ, вопрос 23), нативной версии нет. FEMM 5 на Qt кроссплатформенный, но бинарные сборки только для Windows и macOS, Linux собирается из исходников.
- Картинки из программы — снимок окна в растре. Для ролика нужна перерисовка по данным.
- Старый интерфейс. Скрипты на Lua 4 (в FEMM 5 есть и встроенный MicroPython).
- Генератор сетки Triangle может сбоить на очень острых углах и касательных дугах (FAQ, вопрос 22). Тонкие полосы магнита нужно рисовать аккуратно, иногда менять минимальный угол сетки.

## Сложность

- Для человека (2 из 5): учебник проходится за день-два, но нужно понимать физику материалов и граничных условий.
- Для агента (3 из 5): Lua-скрипт описывает задачу целиком и запускается из командной строки: `femm.exe -lua-script=file.lua -windowhide` (FAQ, вопрос 15). Это требует Windows или Wine. Агент может написать скрипт, проверить числа и построить картинку в Matplotlib. Руки нужны на установку и на первую настройку материалов.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): Lua, pyFEMM, OctaveFEMM, MathFEMM, управление из командной строки. Пакетный запуск цикла по положениям возможен. Минус: нужен установленный Windows-процесс FEMM.
- Воспроизводимость (4 из 5): модель — файл `.fem`, формат которого описан в документации ([Magnetics File Formats](https://www.femm.info/doku/lib/exe/fetch.php?media=femm-qt:docs:magnetics-file-formats.pdf) для FEMM 5), плюс скрипт. Результаты одинаковы на одной версии. Потеря балла из-за зависимости от Windows и версии сборки.

## Платформа и оборудование

FEMM 4.2: Windows (32 и 64 бита). FEMM 5: Windows (проверен на Windows 11 25H2), macOS 13.3 и новее (проверен на M1), Linux и FreeBSD сборкой из исходников. Запуск FEMM 4.2 под Wine на Linux описан в FAQ.

## Экспорт

BMP-снимок окна (`mo_savebitmap`), EMF (`mo_savemetafile`), копирование в буфер. Таблицы значений через Lua. Видео нет. Разрешение окна определяет размер BMP.

## Когда брать и когда нет

- Брать: плоская задача с сталью и насыщением, например магнитная лента на стальной двери. Быстрая серия расчётов циклом, данные для красивой перерисовки.
- Не брать: нужен 3D, нужна красивая картинка «из коробки», нет Windows-машины и нет желания возиться с Wine. Тогда [elmer-fem](elmer-fem.md) (Linux, 3D) или аналитика [magpylib](magpylib.md).
