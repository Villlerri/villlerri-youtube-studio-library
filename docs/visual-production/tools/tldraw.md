# tldraw

SDK бесконечного холста для React: рисование, фигуры, текст, стрелки, камера, совместная работа. Исходный код открыт для чтения, но лицензия не свободная: в боевой среде нужна лицензия tldraw. Для видео подходит как основа собственного «белого холста» с программной анимацией фигур и камеры.

## Что реально получается

Опора: страницы tldraw.dev (главная, анимация, экспорт, лицензия).

- Бесконечный холст со встроенными инструментами рисования, фигур, текста, стрелок. Плавные панорама и масштаб.
- Анимация фигур программно: `animateShape` и `animateShapes`, по умолчанию 500 мс и линейная лёгкость, параллельные анимации не мешают друг другу. Интерполируются положение, прозрачность, поворот. Размеры и свои свойства нужны через `getInterpolatedProps` фигуры.
- Анимация камеры: методы камеры принимают параметр `animation`, например `zoomToFit({ animation: { duration: 200 } })`. По умолчанию лёгкость ease-in-out cubic. Так реализуются наезд и перелёт к нужному месту доски. Это ближе всего к «непрерывной сцене» среди карточек этого класса.
- Экспорт: `editor.toImage` в PNG, JPEG, WebP или SVG, весь холст или выбранные фигуры.
- Совместная работа, агентские наборы: ИИ-агент управляет холстом (ролик выше).
- Рисование линий пером «вживую» с видимым процессом: штрихами можно рисовать, воспроизведение штрихов как анимации в источниках не описано.
- Видео: SDK не рендерит видео сам. Кадры собирает внешний код (запись экрана браузера, снимки `toImage`).
- Синхронизация с голосом: нет. Времена шагов агент задаёт программно (идея, не проверено).

## Слабые стороны

- Лицензия не свободная. Код в боевой среде только по лицензии: hobby (по заявке, не гарантируется, показывает водяной знак «made with tldraw»), 100-дневная проба, коммерческая по запросу.
- Нужен разработчик на TypeScript и React.
- Нет встроенного рендера в видео.
- Анимация для свойств, кроме положения, прозрачности и поворота, требует кода.
- Анимация фигур не учитывает настройку «уменьшить движение» ОС: проверять `getAnimationSpeed()` нужно самому (для ролика безразлично).

## Сложность

- Для человека (3 из 5): для собственного приложения нужны React и TypeScript, холст как инструмент проще. Оценка автора карточки.
- Для агента (3 из 5): агент пишет React-приложение и код анимации, ролик собирает записью холста (Playwright или аналог, не проверено). Нужно получить лицензию для использования вне разработки.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): API редактора (`animateShape`, камера, `toImage`), хранилище записей и сигналов. Рендер в видео придётся собирать самому.
- Воспроизводимость (3 из 5): код приложения лежит в git. Формат снимка холста и детерминизм анимации по кадрам не проверены (анимации идут по системе тактов редактора).

## Платформа и оборудование

- Браузер, React. Серверная часть мультиплеера на Cloudflare Durable Objects (стартовый набор Multiplayer).
- Требований к железу не нашёл.

## Экспорт

- `toImage`: PNG, JPEG, WebP, SVG. Параметр `background` можно отключить.
- Видео: нет, только через запись или покадровые снимки.

## Стоимость

Проверено 2026-10-14 по [странице лицензии](https://tldraw.dev/community/license) и [странице цен](https://tldraw.dev/pricing).

- По умолчанию SDK разрешён «только в разработке». Для production нужна пробная, коммерческая или hobby-лицензия.
- Hobby: бесплатно по заявке, для некоммерческих проектов, с водяным знаком. Выдаётся на усмотрение tldraw.
- Проба: 100 дней, без карты, одна на коммерческое подразделение. SDK во время пробы собирает сведения об использовании.
- Коммерческая лицензия: «value-based pricing», цена по запросу у отдела продаж. Может быть скидка для стартапов. Сумм на странице нет.
- Лицензионный ключ передаётся через `licenseKey`, проверяется на клиенте и работает без сети.
- Оценка стоимости 0 учитывает только использование в разработке (запись видео на своей машине). Использует ли такая запись «боевую среду», по тексту лицензии не ясно.

## Когда брать и когда нет

- Брать: если студия строит своё приложение для рисования и анимации доски (камера, наезд, фигуры) и готова оформить лицензию.
- Брать: агентская сцена, где ИИ управляет холстом.
- Не брать: чтобы быстро нарисовать схему. Тогда [Excalidraw](excalidraw.md): MIT, без лицензионных оговорок.
- Не брать: если нужен готовый рендер в видео.
