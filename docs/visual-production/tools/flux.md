# FLUX (Black Forest Labs)

Модели изображений и (с FLUX 3) видео от Black Forest Labs. Часть весов открыта (FLUX.1 [schnell], FLUX.2 [klein] 4B под Apache-2.0), часть открыта для некоммерческого использования (FLUX.2 [dev], [klein] 9B), остальное только через API. Для видео-сцен интереснее всего кадры-опоры и новая видеомодель FLUX 3.

## Что реально получается

Опора: документация BFL, README репозиториев, тексты лицензий. Генераций я не запускал.

- Изображения (FLUX.2, ноябрь 2025 — январь 2026): [dev] 32 млрд параметров, [klein] 4B и 9B (менее секунды на картинку), на API ещё [pro], [flex], [max]. Редактирование по тексту и с несколькими референсами, до 4 мегапикселей. Документация обещает точные цвета по hex-кодам и надёжный текст для инфографики и макетов интерфейсов; независимо не проверял.
- FLUX 3 Image: генерация и правка, до десяти референсов, ограничивающие рамки (bounding boxes) для расстановки элементов; это удобно для воспроизводимого кадра с заранее известной раскладкой.
- FLUX 3 Video (API): текст в видео, картинка в видео, продолжение видео, синхронный звук в одном вызове. Длительность 5–20 секунд или `auto`. Ключевые кадры: один кадр — начало, два кадра — начало и конец, до десяти кадров по таймкодам (раскадровка). Мультикадр: несколько планов и ракурсов в одном запросе с сохранением героя и стиля через склейки (по документации). Режим draft: быстрый предпросмотр на `hd`, затем `draft_enhance` для подтверждённого варианта.
- Разрешения видео: `hd`, `fhd`, `qhd`, `uhd` (UHD 3840×2176 для 16:9).
- Правка готового клипа: отдельный инструмент FLUX Video Edit [fast], апскейл видео до 4K.
- Вывод автора: FLUX хорошо готовит опорные кадры для видеомоделей других сервисов (первый и последний кадр) и годится для фонов. Видеомодель FLUX 3 даёт редкую возможность до десяти ключевых кадров по таймкодам. Риск физики общий для класса.

## Слабые стороны

- Лицензии открытых весов различаются (подробно ниже). Для студии «бесплатно и открыто» относится только к schnell и klein 4B.
- Ссылки на готовые изображения API живут 10 минут: файл надо сохранять сразу.
- Побитовой воспроизводимости API не обещает (в прочитанных страницах гарантий нет), проверять на практике.
- Видео FLUX 3 только через API, открытых весов у видеомодели нет (открыт только FLUX 3 Action для робототехники).
- Редкие для научпопа вещи, как векторные схемы, FLUX не делает: растровые картинки. Для SVG см. [Recraft](recraft.md).

## Сложность

- Для человека (2 из 5): веб-плейграунд и подсказки; для открытых весов Python и видеокарта.
- Для агента (2 из 5): REST API, SDK, MCP-сервер BFL (по документации). Агент запускает, скачивает за 10 минут и проверяет результат.

## Автоматизация и воспроизводимость

- Автоматизация (5 из 5): API, MCP-сервер, партнёрские площадки, ComfyUI-узлы для открытых моделей, обучение LoRA для [klein].
- Воспроизводимость (3 из 5): параметр seed и фиксированные открытые веса позволяют повторять локально, но API-модели могут обновляться, а аппаратный детерминизм не проверен.

## Платформа и оборудование

Облако (API, плейграунд). Локально FLUX.2 [klein] 4B помещается в около 8 ГБ видеопамяти (RTX 3090 и 4070 и выше); FLUX.2 [dev] (32B) требует видеокарты уровня H100, для потребительских есть квантованные версии. Запуск через [ComfyUI](comfyui.md) поддерживается.

## Экспорт

- Изображения: растровые, до 4 мегапикселей (FLUX.2). Конкретный формат выдачи API не проверял.
- Видео FLUX 3: MP4, до `uhd`, длительность до 20 секунд, звук включён по умолчанию.
- Векторов и альфа-канала в источниках нет.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://bfl.ai/pricing) и [публичным данным цен](https://docs.bfl.ml/quick_start/pricing.md). 1 кредит = $0.01.

- Изображения (первая мегапиксель-единица): FLUX.2 [klein] 4B $0.014, [klein] 9B $0.015, [pro] $0.03, [flex] $0.05, [max] $0.07; FLUX.1 [dev] $0.025, FLUX.1 [pro] $0.05, Kontext [pro] $0.04.
- FLUX 3 Video, в секунду результата: hd $0.15, fhd $0.24, qhd $0.28, uhd $0.41; draft $0.06; продолжение видео дороже ($0.21 / $0.27 / $0.31 / $0.45).
- Коммерческая лицензия на самостоятельный запуск: тарифы Builder, Professional, Enterprise (Builder: модели [klein], 10 000 картинок в месяц, один домен, до 10 лицензированных пользователей, без клиентской работы). Цена по запросу.
- Пример расчёта: 100 опорных кадров FLUX.2 [pro] = $3; 60 секунд видео FLUX 3 hd с 5 попытками = 300 секунд × $0.15 = $45. Оценка стоимости 1 для изображений; для видео уровень 2.

## Лицензия и права

- Код: репозиторий FLUX.1 (`flux`) под Apache-2.0 (файл LICENSE). В репозитории `flux2` файла LICENSE на главной ветке нет (404), лицензия его кода не подтверждена. Автокодировщик FLUX.2 под Apache-2.0.
- Веса, различия лицензий:
  - FLUX.1 [schnell]: Apache-2.0. Свободно, в том числе коммерчески.
  - FLUX.2 [klein] 4B и 4B Base: Apache-2.0.
  - FLUX.1 [dev], FLUX.2 [dev], [klein] 9B и 9B KV: некоммерческая лицензия BFL. «Non-Commercial Purpose» исключает работу, приносящую доход, взаимодействие с конечными пользователями, обучение других моделей для коммерции. Для коммерческого использования нужна лицензия от BFL (платная).
  - [pro], [flex], [max], FLUX 3: только API, условия сервиса.
- Результат по лицензии FLUX [dev] v2.0, п. 2(d): «Мы не заявляем прав на результат… Вы можете использовать результат для любых целей (включая коммерческие), кроме явно запрещённых». Нельзя обучать на результате модель, конкурирующую с FLUX [dev]. Требования: фильтры контента или ручная проверка до публикации, раскрытие ИИ там, где закон требует. Внутреннее противоречие: п. 4(a) запрещает использовать «данные, созданные моделью» в коммерческих и производственных целях. Две формулировки спорят. Вывод: для коммерческого ролика с картинками из [dev] нужен письменный ответ BFL или коммерческая лицензия, либо брать API/Apache-модели. Не юридическая консультация.
- Результат через API ([условия BFL](https://bfl.ai/legal/terms-of-service)): «Мы не заявляем прав на ваш контент (вход и результат)», использование для собственных целей с ограничениями условий и закона.
- Метки: упоминаний C2PA и водяных знаков в прочитанных страницах нет. Для YouTube реалистичные синтетические сцены нужно раскрывать в Studio (см. [обзор класса](../classes/10-generative.md)).
- Ассеты в комплекте: нет.

## Когда брать и когда нет

- Брать: опорные кадры и фоны для видеомоделей, правка по референсам с точной раскладкой, фоны с текстом инфографики (после проверки), видеоклипы с ключевыми кадрами по таймкодам.
- Брать для коммерции: FLUX.1 [schnell], FLUX.2 [klein] 4B или API.
- Не брать для коммерческого ролика: [dev] и klein 9B без договора с BFL.
- Не брать: векторные схемы (взять [Recraft](recraft.md)), точную физику и надписи в видео.
