# Pencil2D

Лёгкая бесплатная программа для рисованной покадровой анимации. Растровые и векторные слои, калька, слой камеры, звук. Нет твининга, костей и эффектов. Подходит для набросков, аниматиков и простых мультяшных вставок.

## Ссылки

- GitHub: https://github.com/pencil2d/pencil

  - [Intro to Animation using Pencil2D](https://www.youtube.com/watch?v=ZEuVjFua7nQ) — канал PSTV Philadelphia, вводный урок.

## Что реально получается

- Покадровая рисованная анимация на растровом или векторном слое, калька (onion skin), неограниченный холст, камера как отдельный слой с прямоугольником кадра ([руководство](https://www.pencil2d.org/doc/user-manual.html)).
- Для объясняющего видео: рисунок от руки кадр за кадром, например набросок схемы или рукописная вставка.
- Морфинг, кости, камера с глубиной, эффекты и композитинг — нет. Сглаживания между позами нет: все промежуточные кадры рисуют.
- Звук можно подложить под кадры; автоматического липсинка нет в просмотренных страницах.

## Слабые стороны

- Самый простой инструмент в классе: нет твининга, нет композитинга, нет автоматизации анимации.
- До версии 1.0. FAQ: автосохранение работает только после первого ручного сохранения, иначе возможен вылет из-за переполнения памяти.
- Видео-экспорт идёт через FFmpeg; в пакете Fedora по умолчанию `ffmpeg-free` с урезанным набором кодеков, для H.264 ставят OpenH264 ([страница загрузки](https://www.pencil2d.org/download/)).
- Весь труд по кадрам: полнометражная сцена дороже всех остальных вариантов по времени.

## Сложность

- Для человека (1 из 5): интерфейс из нескольких панелей, первую анимацию делают за час, как показывает руководство.
- Для агента (4 из 5): рисование кадров ручное. Командной строкой агент может только экспортировать готовый проект.

## Автоматизация и воспроизводимость

- Автоматизация (2 из 5): консольный экспорт `pencil2d проект.pclx -o выход --camera <слой> --width --height --start --end --transparency` (исходник `commandlineparser.cpp`). Скриптов для создания анимации нет.
- Воспроизводимость (2 из 5): проект в собственном файле (`.pclx`), экспорт воспроизводит результат при той же версии; ручная работа.

## Платформа и оборудование

Windows 7 и новее (64 и 32 бита), macOS 10.14 и новее (Intel), Linux (64 и 32 бита), FreeBSD. Есть пакеты для Arch, Debian и Ubuntu, Fedora, Flatpak и Homebrew ([страница загрузки](https://www.pencil2d.org/download/)). Холст большого размера требует больше памяти: камера по умолчанию 800×600.

## Экспорт

- Анимированный GIF: «File → Export → Animated GIF…».
- Видео: через FFmpeg; FAQ отсылает к руководству по проблемам экспорта видео.
- Последовательность изображений: экспорт есть, в 0.7.1 исправлены имена файлов ([ChangeLog](https://raw.githubusercontent.com/pencil2d/pencil/master/ChangeLog.md)).
- Командный экспорт: ключи `-o`/`--export` в исходнике; формат вывода по расширению не проверял.

## Когда брать и когда нет

- Брать: быстрые наброски, аниматик к ролику, простые рисованные вставки, обучение. Нулевой порог входа.
- Не брать: персонаж серии и сцены с камерой ([tahoma2d](tahoma2d.md), [opentoonz](opentoonz.md), [synfig](synfig.md)); студийное качество ([tvpaint](tvpaint.md), [toon-boom-harmony](toon-boom-harmony.md)).
