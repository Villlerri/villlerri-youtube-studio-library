# PixiJS

Быстрый 2D-рендерер для браузера на WebGL и WebGPU. Рисует 2D-графику; на главной странице заявлены спрайты, текст, фильтры. Движок рисует кадры; сцену, таймлайн и запись видео надо собирать вокруг него.

## Ссылки

- Официальный сайт: https://pixijs.com
- GitHub: https://github.com/pixijs/pixijs
- Документация: https://pixijs.com/8.x/guides/basics/getting-started
- Примеры, проверенные 2026-10-14 (страницы открывались, ролики не смотрел):
  - [Примеры PixiJS 8.x](https://pixijs.com/8.x/examples) — официальная песочница с запускаемым кодом.
  - [Ticker](https://pixijs.com/8.x/guides/components/ticker) — цикл анимации: `start`, `stop`, `deltaTime`, `minFPS`, `maxFPS`.
  - [Справочник Ticker](https://pixijs.download/release/docs/ticker.Ticker.html) — метод `update(currentTime)` можно вызывать вручную.

## Что реально получается

- 2D-сцены с большим числом объектов: диаграммы, частицы, спрайтовые персонажи, карточки, подписи. Сцены `diagram`, `character`, `typography`.
- Эффекты: на главной странице указан пакет Filters. Какие именно эффекты есть, не проверял; качество зависит от автора.
- Персонажи: на главной странице среди партнёрских библиотек указана Spine (скелетная анимация от Esoteric Software), см. [spine](spine.md).
- Непрерывность: объекты живут в одной сцене и двигаются по тикеру. Таймлайн сцен в библиотеке отсутствует; обычно берут [gsap](gsap.md).
- Камеры нет: масштаб и сдвиг делают контейнером. Морфинг контуров и «рисование линий» вживую не встроены.
- Голос: привязки к аудио в ядре нет; звук вынесен в отдельную библиотеку (Sound).
- Потолок качества (3 из 5): чёткая 2D-графика с фильтрами; без собственных ассетов и дизайна выглядит как учебный проект.

## Слабые стороны

- Нет собственной записи видео. Тикер питается от браузерной частоты кадров. Подвести его под фиксированный шаг можно ручным `ticker.update(time)`, но эта связка в документации Pixi не описана как приём записи.
- Нет готовых средств для формул и математики. Для объясняющих роликов с выкладками выбирают другие инструменты.
- API v8 сменил инициализацию на асинхронную (`await app.init()`), код версии 7 надо переносить.
- Серверный рендер WebGPU/WebGL требует headless-браузера с графикой.

## Сложность

- Для человека (3 из 5): нужен JavaScript и понимание сцены, текстур и тикера. Простая сцена за день, красивая подача — недели.
- Для агента (2 из 5): код и браузер, результат проверяется скриншотами. Руки нужны для графических ассетов и вкуса.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): библиотека не рендерит видео. Конвейер собирается из [remotion](remotion.md), [ccapture-js](ccapture-js.md) или Puppeteer-захвата, подробнее в обзоре [SVG, Canvas, WebGL](../classes/03-web-graphics.md).
- Воспроизводимость (4 из 5): проект — текст под git. Ручной вызов `ticker.update(currentTime)` в документации допустим, значит время можно подавать кадр за кадром. Запуск такого конвейера не проверялся.

## Платформа и оборудование

Любой современный браузер; для WebGPU нужен браузер с его поддержкой, иначе запасной WebGL. Для серверной записи нужен headless Chromium.

## Экспорт

Сама библиотека видео не экспортирует. Видео и кадры делает внешний захват. Прозрачность и разрешение определяются им.

## Когда брать и когда нет

- Брать: насыщенная 2D-сцена с тысячами элементов, фильтры и частицы, спрайтовые персонажи, если уже есть конвейер записи кадров.
- Не брать: основной инструмент для формул и графиков ([manim-ce](manim-ce.md), [d3](d3.md)), 3D ([three-js](three-js.md)), всё, где нужна готовая запись видео и озвучка.
