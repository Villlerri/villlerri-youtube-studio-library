# Lottie Creator (LottieFiles)

Браузерный редактор векторной анимации от компании Design Barn Inc. (LottieFiles, Канада). Слои, фигуры, текст, ключевые кадры, редактор кривых, маски, траектории, импорт SVG. Основной выход: Lottie JSON и dotLottie для сайтов и приложений, но есть и видео: MP4, WebM, MOV, GIF. Сделан для интерфейсов и коротких вставок, не для длинных сцен. Формат Lottie и его проигрыватели описаны в карточке [lottie](lottie.md). Для объясняющего канала главное: бесплатного коммерческого пути нет, условия сервиса прямо относят монетизируемые ролики YouTube к коммерческому использованию.

## Что реально получается

- Короткие векторные клипы: схемы, значки, подписи, появление блоков, движение по траектории, прорисовка контура (Trim Path), маски и режимы наложения. Ключевые кадры, редактор кривых (Graph Editor), родительские слои, вложенные сцены, копирование слоя с шагом (Advanced Duplicator). Это ближе к упрощённому After Effects, чем к программе для длинной сцены.
- Motion Copilot (с версии 2.0, 2026-07-22): ИИ внутри редактора строит слои, фигуры, тени и ключи по текстовой просьбе; результат редактируется, перед широкими правками показывает план, каждое действие откатывается. Лимит: 300 кредитов ИИ в месяц на тарифе Individual и 600 на Team (страница тарифов); сколько кредитов тратит одна просьба, не указано.
- Физика: плагин Physics Simulator создаёт ключи для падения, отскока и столкновения. Это не физический движок, а заготовка ключей.
- Импорт SVG, Lottie, изображений; PNG и JPG слоями можно перевести в вектор. Страница называет «Universal File Importer» для дизайна, анимации и видео, подробности не проверял.
- Интерактивность (State Machines, Motion Tokens) нужна для сайтов и приложений, в видео не нужна.
- Для объясняющего видео: вставки, анимированные схемы и подписи в плоском стиле, которые затем собираются в монтажной программе ([davinci-resolve](davinci-resolve.md), [after-effects](after-effects.md)). Формулы и графики функций редактор сам не строит. Рисования линий вживую рукой нет, есть прорисовка контура. Озвучки и синхронизации по голосу в описании нет.
- Видео получается при экспорте в MP4, WebM, MOV, GIF; WebM и MOV с прозрачностью упомянуты на странице тарифов («Transparent Video Exports: GIF, MP4, Transparent WebM & MOV»). Какое разрешение и частоту кадров можно выбрать, в документации не нашёл.

## Слабые стороны

- Коммерческое использование закрыто для бесплатного и индивидуального тарифов. Условия (2025-08-22): «Individual Plan and Free Plan are strictly for non-commercial use only», и в определение коммерческого использования входят «Monetized Content … such as YouTube videos». Нарушение грозит закрытием подписки и иском. Для монетизируемого канала нужен Team ($24.99 в месяц за место при оплате за год).
- Бесплатно можно создавать сколько угодно файлов, но экспортировать только пять анимаций (FAQ страницы Creator).
- Экспорт требует учётной записи LottieFiles и проходит в два шага: сохранить в рабочее пространство, затем скачать. Работа лежит в облаке LottieFiles; проект в виде файла, который можно положить под git, не нашёл (после экспорта остаётся Lottie JSON).
- Видео не главная цель: сервис нацелен на Lottie для сайтов. Lottie поддерживает не все возможности видеоредакторов; список поддержки на странице https://lottiefiles.com/supported-features не читал.
- Работает только в браузере на компьютере. Для мобильных не рекомендован; для скорости нужно включить ускорение GPU в браузере.
- Анимация держится на ручной сборке: автоматического морфинга формул и схем нет.
- Агент через MCP работает только с открытой вкладкой браузера и локальным мостом (см. «Автоматизацию»). Экспорт делается кнопкой в интерфейсе.

## Сложность

- Для человека (2 из 5): браузер, ничего ставить не нужно, интерфейс похож на привычные редакторы, есть уроки и сертификация от LottieFiles. Первую анимацию собирают за день. Тонкие приёмы (маски, кривые) требуют практики.
- Для агента (3 из 5): через MCP агент может создавать и править слои, ключи, кривые, маски и сцены, но нужен открытый редактор в браузере и ручной экспорт. Качество анимации по словам самой документации зависит от модели, лучше начинать со своих SVG.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): три способа управления агентом. Первый, локальный MCP-мост: пакет `@lottiefiles/creator-mcp` (npm, лицензия MIT, версия 0.2.2 от 2026-09-14, создан 2026-04-06), запускается через `npx`, требует Node.js 18+, открытую вкладку creator.lottiefiles.com и включённый в настройках режим локального MCP. Второй, WebMCP: браузерный ассистент напрямую (Chrome). Третий, встроенный Motion Copilot. Возможности у всех одинаковые (слои, фигуры, текст, эффекты, ключи, импорт, темы, сегменты, состояния). Есть «навык» для агентов `LottieFiles/motion-design-skill` (принципы тайминга и кривых). Командной строки для рендера в файл нет, экспорт идёт кнопкой Export.
- Воспроизводимость (3 из 5): итог в виде Lottie JSON (текст) или dotLottie (один файл `.lottie`) можно хранить под git. Но исходный проект живёт в облаке сервиса, ключи и слои агент повторить может, детерминированного рендера видео в документации не обещано.

## Платформа и оборудование

Любой современный настольный браузер (рекомендованы Chrome, Firefox, Safari, Edge), включённое ускорение GPU, доступ в интернет, учётная запись LottieFiles. Для MCP: Node.js 18+ и любой MCP-клиент (Claude, Cursor, Codex, VS Code и другие).

## Экспорт

- Форматы (страница форматов, документация): оптимизированный dotLottie и dotLottie (`.lottie`), оптимизированный Lottie JSON и Lottie JSON, MP4, WebM, MOV, GIF, Google Ads, TGS (стикеры Telegram).
- Для видео: MP4 для соцсетей и видеомонтажа, WebM для сайтов, MOV для профессионального монтажа (самый большой файл), GIF для почты. Прозрачность в WebM и MOV упомянута на странице тарифов, в документации экспорта не уточнена.
- CDN: хостинг Lottie по ссылке, версия «последняя» или зафиксированная. Лимит трафика CDN по тарифам: 10 ГБ Individual, 50 ГБ Team (страница тарифов); в условиях использования стоят 10, 25 и 500 ГБ — цифры у Team не сходятся.
- Разрешение, частота кадров, кодеки видео: не нашёл.

## Стоимость

- Individual: $19.99 в месяц за место при оплате за год, около $240 в год. Один редактор. Неограниченные загрузки, Lottie Creator, 300 кредитов ИИ в месяц, CDN 10 ГБ. Некоммерческое использование.
- Team: $24.99 в месяц за место при оплате за год, около $300 в год. Два редактора и больше, версии, комментарии, 600 кредитов ИИ в месяц, CDN 50 ГБ. Коммерческое использование разрешено, до десяти пользователей на домен компании.
- Team+: цена по запросу, 5–50 редакторов, шаблоны движения, Motion System. Enterprise: по запросу.
- Подписка: условия продажи говорят о годовом сроке с автопродлением, отказ за 30 дней до конца срока; платежи не возвращаются (текст помечен «последнее изменение 2022-08-10», срок в квадратных скобках, значит шаблон). Есть ли помесячная оплата, страница не показывает (ответ в блоке FAQ свёрнут).
- Для монетизируемого канала: Team, $24.99 в месяц (около $300 в год).

## Когда брать и когда нет

- Брать: нужны короткие плоские векторные вставки и значки, которые одновременно нужны в видео и на сайте; нужно быстро собрать анимацию без After Effects; есть бюджет на Team ($24.99 в месяц) и канал монетизируется; хочется смотреть, как агент сам строит анимацию в редакторе через MCP.
- Не брать: длинные непрерывные сцены, формулы и графики ([manim-ce](manim-ce.md), [motion-canvas](motion-canvas.md)); полноценная анимация персонажей и сложные эффекты ([after-effects](after-effects.md), [rive](rive.md)); бесплатный путь для монетизируемого канала ([glaxnimate](glaxnimate.md) бесплатен, лицензия открытая; для готовых клипов в формате Lottie можно взять [lottie](lottie.md) и свой проигрыватель); сборка видео пакетом без браузера ([remotion](remotion.md), [hyperframes](hyperframes.md)).
