# Matter.js

JavaScript-библиотека 2D-физики твёрдых тел для веба: столкновения, трение, упругость, связи, составные тела. Работает в браузере и в Node.js. Встроенный рендер на canvas простой, обычно физика связывается с p5.js, PixiJS или своей отрисовкой.

## Что реально получается

Сквозной пример (магнит на холодильнике). В физике Matter.js магнитов нет. Можно нарисовать магнитик-тело и притягивать его к двери собственной силой в обработчике (для притяжения есть плагин [matter-attractors](https://github.com/liabru/matter-attractors)). Показать поле и линии это не поможет: движок считает твёрдые тела, а не поля.

Что даёт для объясняющего видео:

- Механические мультяшные сцены: падение, столкновения, маятник, цепи, пружины, рычаги. Подходит для «объяснялок» на сценах-аналогиях (шарики вместо молекул, домино вместо цепной реакции).
- Time Scaling (замедление и ускорение), области запросов и лучи (Raycasting), составные и вогнутые тела, мягкие тела и ткань.
- Свой вид: тела — данные (позиции, углы), рисовать их можно чем угодно. Хорошо в паре с PixiJS, см. [pixijs](pixijs.md), и с p5.js, см. [p5js](p5js.md).
- Видео: встроенного нет. Кадры получают захватом холста, см. [ccapture-js](ccapture-js.md). Для фиксированных кадров нужен постоянный шаг времени, см. «Автоматизация».
- Непрерывная сцена: физический мир продолжается между сценами, тела можно оставить и менять камеру (в рендере по умолчанию есть «Views» — сдвиг и масштаб). Морфинг форм внутри физики нет.
- Рисование линий и голос: нет. Время событий задаётся кодом.

## Слабые стороны

- Только 2D. Физика приближённая, не научная: нет точных законов для жидкостей, упругости, полей.
- Жидкостей в списке возможностей нет. Мягкие тела и ткань есть в демо (Basic Soft Bodies, Cloth), но упрощённые.
- Последний релиз 0.20.0 вышел 2024-06-23. Новых релизов больше двух лет нет (см. «Активность»).
- Внешний вид по умолчанию — каркасы и плоские фигуры. Красота зависит от того, чем рисуете.
- Старые учебники написаны под API 2017 года и местами не работают.

## Сложность

- Для человека (2 из 5): знание JavaScript, физика готовая. Красивый вид требует отдельной работы.
- Для агента (2 из 5): код и запуск в Node или headless-браузере. Для кадров нужен захват холста.

## Автоматизация и воспроизводимость

- Автоматизация (4 из 5): физика работает в Node.js без браузера. Рендер видео требует браузера, но управляется скриптом.
- Воспроизводимость (3 из 5): в движке есть `Common.random` с зерном (`Common._seed`), новый `Matter.Runner` использует фиксированный шаг времени 1/60 с (запись в changelog 0.20.0). Заявления о побитовом детерминизме в README нет. Результат на разных браузерах может отличаться в мелочах, это не проверялось.

## Платформа и оборудование

Любой браузер и Node.js. Видеокарта не нужна. Поддержка мобильных касаний есть (README).

## Когда брать и когда нет

- Брать: 2D-механика для мультяшных аналогий, веб-интерактив, быстрое прототипирование.
- Не брать: нужна воспроизводимость до бита и точность — [box2d](box2d.md). Нужна научная точность полей, жидкостей — [taichi](taichi.md), [pyvista](pyvista.md), FEM-инструменты класса.
