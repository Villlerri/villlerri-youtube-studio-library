# Spline

Браузерный редактор 3D для интерактивной веб-графики с совместной работой. Версия V2 (август 2026) получила режим ИИ-агента и MCP. Подходит для лёгких стилизованных 3D-сцен и веб-встраивания, а не для физически точной графики.

## Ссылки

- Официальный сайт: https://spline.design/
- GitHub: открытого кода редактора нет; репозиторий https://github.com/splinetool/runtime вернул 404. Библиотека показа сцен есть на npm: https://www.npmjs.com/package/@splinetool/runtime
- Документация: https://docs.spline.design/ ([экспорт видео](https://docs.spline.design/exporting-your-scene/files/exporting-as-video), [FAQ](https://docs.spline.design/basics/faq))
- Примеры, проверенные 2026-10-14:
  - [Introducing Spline V2 — AI Agents, WebGPU and MCP (2026-08-20)](https://www.youtube.com/watch?v=i8g1dnPOrCc) — перестроенный редактор, режим агента, MCP, движок на WebGPU, PBR/HDR, скрипты.
  - [Spline MCP: Build 3D Web Experiences with AI](https://www.youtube.com/watch?v=tO4BrbNTqKA) — Claude строит в Spline сцену по эталонной картинке («floating park diorama») и веб-страницу вокруг неё.
  - [Customer story: Elecctro by Lynksen](https://www.youtube.com/watch?v=wO2UsnX4hl8) — 3D для объяснения сложной B2B-платформы; веб, не научно-популярное видео.

## Что реально получается

- Лёгкие 3D-сцены со скруглёнными формами, материалами, интерактивом на веб-странице. Хорошо смотрятся как вставка, обложка или фон.
- Анимация задаётся в редакторе. Видео экспортируется рендером заданной анимации, не записью экрана: по документации это «ensures consistent transition timing and smooth playback» и упрощает бесшовные циклы.
- Непрерывная сцена и камера: сцену можно собрать как одну композицию; детали камеры в проверенной документации не рассмотрены.
- Рисование линий и формулы: не для этого.
- Голос: нет привязки к озвучке.
- Агент: MCP позволяет ИИ-клиенту (Claude, Cursor, Gemini) создавать и править сцену из чата в десктопном приложении Spline (по описанию ролика). Результат нужно смотреть глазами.

## Слабые стороны

- Качество картинки ниже Blender: нет физически точного трассировщика (оценка по классу инструмента).
- Проект живёт в облаке, версионирование и git недоступны.
- Видео экспортируется только с планов Pro и Max (по странице цен); на Free веб-экспорт идёт с водяным знаком.
- Бесплатный план ограничен числом файлов («Limited Personal Files»).
- Условия использования обновляются: новые условия распространяются на данные «before, on, or after October 29, 2026».

## Сложность

- Для человека (2 из 5): интерфейс простой, первые сцены за часы–дни.
- Для агента (3 из 5): MCP и режим агента есть (V2, 2026-08-20), но их надёжность не проверена, а экспорт видео идёт через интерфейс. Часть работы руками.

## Автоматизация и воспроизводимость

- Автоматизация (3 из 5): MCP и агент в редакторе; в V2 заявлены «Custom Code/Scripting»; публикация сцены в виде встраиваемого просмотрщика. Командной строки для видео-рендера не найдено.
- Воспроизводимость (2 из 5): сцена хранится в облаке и в файле `.spline`; текстового проекта нет.

## Платформа и оборудование

Работает в браузере; есть десктопное приложение Spline (из описания ролика про MCP); список ОС для него не проверялся. V2 использует движок на WebGPU (по ролику); требования к видеокарте не проверялись.

## Экспорт

- Видео: WebM, MP4, последовательность изображений (FAQ документации). В разных версиях документации встречается GIF, текущую версию не уточнял.
- Изображения: PNG, JPG.
- 3D-форматы: GLTF, GLB, STL, USDZ.
- Веб: встраивание через `spline-viewer`, код (на странице цен: экспорт кода с плана Pro), мобильные приложения.
- В видеоэкспорте задаются длительность, частота кадров и разрешение; конкретные значения и лимиты длительности в проверенной документации не указаны.

## Стоимость

Проверено 2026-10-14 по [странице цен](https://spline.design/pricing). Цены за место, доллары США.

- Free: $0, файлы с лимитом, веб-экспорт с водяным знаком, библиотека Spline.
- Hobby: $15 в месяц или $12 при оплате за год ($144).
- Pro: $30 или $25 ($300 в год); видео-экспорт, экспорт кода, GLTF, USDZ, STL.
- Max: $70 или $60 ($720 в год).
- Enterprise: по запросу.
- Таблица тарифов в пересказе показала у Hobby «upload only» для видео и у Max «100MB max video size»; смысл не уточнён.

## Лицензия и права

- Код или программа: proprietary.
- Результат: по [условиям](https://spline.design/terms) раздел 5.2: «you retain all ownership rights in your User Content» (сцены, объекты, материалы, анимации, изображения, видео). Spline получает неисключительную лицензию на хранение, воспроизведение и изменение контента «solely as necessary to operate, provide, secure, and improve the Service» (5.3). Про коммерческое использование экспортов условия напрямую не говорят; раздел 2 разрешает экспорт изображений и анимаций.
- Ассеты в комплекте: контент Spline Community по умолчанию под «Standard Commercial License» (ремикс для личного и коммерческого использования); сторонний контент подчиняется своим условиям; условия Spline Library и бесплатных шрифтов не проверены.

## Активность и зрелость

Зрелость: `young`. Spline V2 вышел 2026-08-20 («complete rebuild of our 3d editor for the agentic era»). Пакет `@splinetool/runtime` на npm обновлён 2026-10-14 (версия 2.0.82). Развивает компания Spline.

## Когда брать и когда нет

- Брать: быстрая стилизованная 3D-вставка или интерактив, если нужен простой интерфейс и экспорт видео; прототип с ИИ-агентом.
- Не брать: научная точность, длинные сюжеты, воспроизводимый проект ([blender](blender.md), [godot](godot.md)); если нельзя держать проект в облаке.
