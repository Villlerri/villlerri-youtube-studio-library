# Как новому каналу пользоваться библиотекой

Библиотека общая для всех каналов студии. Она отвечает на вопрос «чем и как делать графику». Стиль канала — палитра, шрифты, характер движения, шаблоны сцен — живёт в проекте канала, не здесь.

## Что лежит в библиотеке

- [Навигация и краткий маршрут выбора](index.md).
- [Подбор по типу сцены и по качеству и затратам](selection.md).
- [Рекомендуемые связки инструментов](combos.md).
- [Качество: режиссура, композиция, ритм, типографика, переходы](craft.md).
- [Пример: магнит на холодильнике](examples/fridge-magnet.md).
- Обзоры классов в папке `classes/`, карточки инструментов в папке `tools/`.
- Сравнительные таблицы в папке `tables/`: [все инструменты](tables/tools.csv), [инструменты по типам сцен](tables/by-scene.csv), [цифры GitHub](tables/github.csv).
- [Методика и шкалы оценок](method.md), [шаблон карточки](templates/tool-card.md).

## Шаги для нового канала

1. Описать канал в его проекте: тема, аудитория, длина роликов, частота выпуска, кто делает графику (человек, агент, оба), бюджет на программы.
2. Выписать типы сцен канала по списку из [методики](method.md#типы-сцен) и отметить самые частые. Пример: физический канал — `mechanism`, `field`, `formula`, `micro`, `scale`.
3. Пройти [маршрут выбора](index.md#краткий-маршрут-выбора) и выбрать одну основную связку из [связок](combos.md). Дополнительные инструменты добавлять под конкретные сцены по [подбору](selection.md).
4. Открыть карточки выбранных инструментов и проверить дату в поле `checked`. Цена, лицензия или статус старше трёх месяцев — перепроверить по ссылкам из раздела «Источники» карточки.
5. Прочитать [раздел о качестве](craft.md) и записать в проекте канала свои правила переходов и ритма на его основе.
6. Сделать пилотную сцену на 20–30 секунд на выбранной связке до первого ролика. Образец сцены и порядка работы — [магнит на холодильнике](examples/fridge-magnet.md).
7. Зафиксировать в проекте канала: палитру, шрифты, характер движения (кривые смягчения, длительности), шаблоны повторяющихся сцен, настройки рендера (разрешение, частота кадров).

## Что где хранить

- В библиотеке: сведения об инструментах, способах и приёмах, полезные любому каналу.
- В проекте канала: стиль, шаблоны, исходники сцен, решения о том, что канал не использует.
- Канал не правит карточки под себя. Нашли новый инструмент или изменившуюся цену — обновить библиотеку для всех.

## Как добавить инструмент

1. Скопировать [шаблон](templates/tool-card.md) в `tools/<id>.md` и заполнить все разделы. Оценки — по шкалам [методики](method.md#оценки).
2. Добавить строку в раздел «Основные решения» обзора класса.
3. Обновить цифры GitHub и таблицы:
   - `python3 docs/visual-production/scripts/gh_stats.py`
   - `python3 docs/visual-production/scripts/build_tables.py`
4. Скрипт таблиц печатает ошибки полей и битые ссылки. Без ошибок — готово.

## Правила студии, которые действуют на любой канал

- Озвучка — только ElevenLabs. Метки времени слов для синхронизации тоже берутся оттуда или из выравнивания по готовой озвучке ([синхронизация](classes/12-sync.md)).
- Платные модели и сервисы — только по решению владельца и в пределах лимита расходов задачи. Карточки генеративных сервисов описывают возможности, но не означают разрешения ими пользоваться.
- Права на результат проверять до работы: у бесплатных тарифов бывают водяные знаки и запрет коммерческого использования. Монетизируемый канал — коммерческое использование.

## Для ИИ-агента

- Начинать с [index.md](index.md), затем [selection.md](selection.md), затем карточки.
- Для фильтра по полям читать [tables/tools.csv](tables/tools.csv): `agent_difficulty` 1–2 значит, что агент сделает сцену сам кодом и проверит рендер.
- Код инструментов из карточек не устанавливать без решения человека. Карточка — справка, не разрешение.
