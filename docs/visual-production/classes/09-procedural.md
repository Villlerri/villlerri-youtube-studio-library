# Процедурная графика

## Что сюда входит

Картинка, которую порождают правила, узлы или код, а не рисует рука: поля, частицы, шум, рои объектов, реакция на данные и звук. Здесь собраны нодовые среды реального времени (TouchDesigner, Notch, vvvv, cables.gl), творческий кодинг (Processing, p5.js) и шейдеры. Процедурные части 3D-пакетов и моушн-дизайна описаны в их собственных карточках.

## Когда этот класс нужен

- Невидимые явления: поля, волны, интерференция, потоки (`field`).
- Микромир и смена масштаба: рои частиц, зумы, фракталы (`micro`, `scale`).
- Симуляции с накоплением состояния: частицы, ткань, дым (`simulation`).
- Генеративные фоны и фактуры под закадровый текст.
- Кинетическая типографика на основе шума и данных (`typography`).
- Сцены, где важна смена параметров во времени, а не смена кадров: один объект непрерывно меняется.
- Серии вариаций из одного шаблона: другое зерно случайности или другие данные дают новый ролик.

## Основные решения

- [TouchDesigner](../tools/touchdesigner.md) — самый универсальный нодовый инструмент; Windows и macOS, запись без пропусков в режиме «не в реальном времени», бесплатная версия ограничена 1280x1280 и без H.264.
- [Notch](../tools/notch.md) — реал-тайм с офлайн-рендером на GPU и качеством студийного уровня; только Windows и сильная видеокарта, нужен тариф VFX, агент сцену собрать не может.
- [vvvv gamma](../tools/vvvv.md) — визуальные узлы плюс C#; только Windows, пошаговый офлайн-режим есть; бесплатно для некоммерческого использования.
- [cables.gl](../tools/cables-gl.md) — бесплатный открытый редактор WebGL в браузере; запись видео только в реальном времени.
- [Processing](../tools/processing.md) — Java-среда, надёжный вывод кадров: один вызов `draw()` даёт один кадр; Movie Maker требует проверки.
- [p5.js](../tools/p5js.md) — Processing для веба; низкий порог входа, запись ограничена, нужен внешний захват (карточка ведётся в классе веб-графики).
- [GLSL-шейдеры и Shadertoy](../tools/glsl-shadertoy.md) — метод для полей и фракталов; потолок качества самый высокий; чужие шейдеры лицензированы некоммерчески по умолчанию.
- [Houdini](../tools/houdini.md) — процедурная 3D-графика и симуляции (карточка ведётся в классе 3D).
- [Blender Geometry Nodes](../tools/blender-geometry-nodes.md) — процедурная геометрия внутри Blender (карточка ведётся в классе 3D).
- [Cavalry](../tools/cavalry.md) — процедурный моушн-дизайн (карточка ведётся в классе моушн-дизайна).

## Сравнение

### Потолок качества

- Notch и TouchDesigner (5): студийный уровень процедурной графики; решает художник.
- GLSL-шейдеры (5): лучшие работы показаны Inigo Quilez; предел задаёт мастерство автора.
- vvvv (4): зависит от движка Stride и работы автора, готовой эстетики нет.
- cables.gl, Processing, p5.js (3): аккуратная учебная и интерактивная графика.
- Houdini, Geometry Nodes, Cavalry: оценки в их карточках.

### Трудность для человека

- Processing и p5.js (2): простой язык, первая анимация за день.
- cables.gl (3): визуальные операторы понятны быстро, красивый результат требует WebGL-знаний.
- TouchDesigner, Notch, vvvv, GLSL (4): много типов операторов, привычка к «пересчёту каждый кадр», у vvvv ещё C#, у GLSL математика.

### Трудность для агента

- Processing, p5.js, GLSL (2): текстовый код, кадры проверяются на диске; для шейдеров безголовый `glslViewer`.
- vvvv (3): C#-узлы пишутся текстом, граф собирает человек.
- TouchDesigner, cables.gl (4): сцена строится мышью; в TouchDesigner внутри есть Python 3.11, но проект двоичный, нужен запущенный клиент.
- Notch (5): сцена только в интерфейсе; агент может лишь запускать пакетный рендер готового проекта.

### Автоматизация

- Processing (4): запуск из командной строки (`processing cli` с версии 4.4.3), `saveFrame()` и ffmpeg.
- GLSL (4): `glslViewer` рендерит без интерфейса и пишет последовательность PNG.
- TouchDesigner, Notch, vvvv, p5.js (3): TouchDesigner — Python и запись без пропусков; Notch — командная строка Builder и `NotchRenderNodeCLI` (экспериментальная); vvvv — C# и офлайн-запись кадров; p5.js — внешний захват.
- cables.gl (2): экспорт в веб и командная строка для экспорта; покадровой записи нет.

### Стоимость

- Бесплатно без оговорок: Processing (GPL и LGPL), p5.js (LGPL-2.1), cables.gl (MIT), `glslViewer` (BSD-3-Clause).
- TouchDesigner: бесплатная Non-Commercial до 1280x1280 и без выгрузки H.264/H.265/AV1; Commercial $600 разово (бессрочно, обновления на год), Pro $2,200.
- vvvv: некоммерческое бесплатно; коммерческая лицензия разработчика 540, 1080 или 2160 EUR в год (бессрочная, обновления на год).
- Notch: Indie $279 в год только для хобби (1080p, без блоков); VFX $1,399 в год или $139 в месяц; RFX от $2,589 в год.

### Плавность переходов и непрерывность сцены

- Все нодовые среды держат сцену как один живой граф: камера и объекты не пересоздаются между кадрами, поэтому «повтор одного кадра в разной крупности» превращается в непрерывное движение.
- Процедурные сцены часто копят состояние (частицы, симуляции). Запись должна идти без пропусков: TouchDesigner выключает флаг Realtime, vvvv включает `Is Incremental`, Notch использует `Preroll Time`, Processing пишет кадр на каждый вызов `draw()`, шейдеры считаются как функция времени. cables.gl записывает только в реальном времени.
- Морфинг, рисование линий и подпись — не встроенные приёмы, а то, что автор собирает из операторов; в шейдерах эти вещи делаются математикой.

## Другие решения

- [nannou](https://nannou.cc) — набор для творческого кодинга на Rust поверх игрового движка Bevy; релиз nannou-v0.20.0 от 2026-06-22.
- [openFrameworks](https://openframeworks.cc) — C++-набор для творческого кодинга; релиз 0.12.1 от 2025-10-15.
- [Cinder](https://libcinder.org) — рецензируемая открытая C++-библиотека для творческого кодинга; релиз v0.9.3 от 2025-11-02.
- [Vuo](https://vuo.org) — визуальное программирование; на сайте есть бесплатная Community Edition для личного использования и малых организаций, платформа не проверялась.
- [KodeLife](https://hexler.net/kodelife) — редактор шейдеров на GPU (GLSL, Metal, HLSL); настольные лицензии разовые, версия для проверки бесплатна.
- [Substance 3D Designer](https://www.adobe.com/products/substance3d/apps/designer.html) — нодовое создание процедурных материалов; входит в подписку Substance 3D Collection (US$59.99 в месяц); выгрузка анимации на странице не названа.
- [Hydra](https://hydra.ojack.xyz) — живое кодирование видеосинтеза в браузере; README называет проект экспериментальным.
- [glslViewer](https://github.com/patriciogonzalezvivo/glslViewer) — консольная утилита для шейдеров с безголовым режимом и записью последовательности PNG.
- [Nodes](https://nodes.io) — среда для идей с кодом от студии variable.io; на странице 1.0.0-beta, страница собрана 2024-02-23, актуальность не подтверждена.

## Вывод для объясняющих видео

Для поля, волны или роя частиц достаточно кода: Processing с `saveFrame()` или шейдер через `glslViewer` дают ровные кадры без дорогой лицензии и подходят агенту. Если нужен целый «нодовый» цех с художником, берите TouchDesigner: он есть на двух ОС, умеет рендерить без пропусков и стоит $600 разово. Notch даёт самую богатую картинку, но требует Windows, видеокарту уровня RTX 2080 и дорогой тариф VFX. cables.gl годится для бесплатных прототипов в браузере, но видео в нём пока только в реальном времени. Для научно-популярного ролика процедурную графику лучше использовать как фон и «поле», а формулы и подписи вести отдельным инструментом.
