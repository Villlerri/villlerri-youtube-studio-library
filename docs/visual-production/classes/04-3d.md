# 3D и Blender

## Что сюда входит

Пакеты и движки для трёхмерной сцены: моделирование, анимация, свет, камера, рендер. Главный инструмент класса — Blender: он свободный, управляется кодом и сам по себе закрывает 3D, 2D-рисование в пространстве и монтаж. Рядом стоят коммерческие пакеты (Cinema 4D, Houdini, Maya, 3ds Max), анимация персонажей в Cascadeur, игровые движки (Unreal Engine, Unity, Godot) и браузерный Spline. Карточки смежных 3D-инструментов из других классов перечислены ниже, в разделе «Основные решения».

## Когда этот класс нужен

- Устройство предмета: разрез, сборка, «как это работает» с непрерывной камерой.
- Смена масштаба: от кухни к атому в одной сцене, без склеек.
- Невидимые явления: силовые линии, потоки, волны (Geometry Nodes, Houdini).
- Микромир: молекулы, белки, клетка (Molecular Nodes).
- Физически честные симуляции: жидкость, дым, частицы, ткань (Houdini, Blender, свой код в Godot).
- Рисование «вживую» внутри 3D: линии, которые проявляются и огибаются камерой (Grease Pencil).
- Персонажи и сюжет: риггинг и анимация (Maya, Blender, Unreal).
- Заголовки и кинетическая графика с объёмом (Cinema 4D, Blender).

## Основные решения

- [Blender](../tools/blender.md) — основной выбор: бесплатный, GPL, сцена и рендер из Python и командной строки, потолок качества высокий.
- [Blender Geometry Nodes](../tools/blender-geometry-nodes.md) — процедурные сцены, поля, силовые линии, симуляции и частицы внутри Blender.
- [ElectroMag Nodes](../tools/electromag-nodes.md) — готовый платный набор Geometry Nodes (Lite $1, Pro $15 на Superhive) для силовых линий, плоскости и стрелок поля электростатики и магнитостатики; постоянных магнитов и железа нет, результат только внутри Blender.
- [Blender Grease Pencil](../tools/blender-grease-pencil.md) — штрихи в 3D, эффект «рисуется на глазах» (Build), раскадровка; главный кандидат для рисования вживую в 3D.
- [Molecular Nodes](../tools/molecular-nodes.md) — научная визуализация молекул в Blender; примеры в роликах Veritasium, Clockwork и NanoRooms по данным галереи аддона.
- [Cinema 4D](../tools/cinema-4d.md) — MoGraph и Redshift, быстрая выразительная графика; платная подписка, с 2026.4 встроен MCP-сервер для агентов.
- [Houdini](../tools/houdini.md) — сильнейшие симуляции; Apprentice бесплатен, но только для некоммерческих проектов; Indie $299 в год с лимитом дохода.
- [Unreal Engine](../tools/unreal-engine.md) — кинематографичный свет и камера в реальном времени; бесплатно до $1 млн дохода; есть официальный MCP (эксперимент).
- [Unity](../tools/unity.md) — C# и запись через Recorder; на нём Primer делал симуляции в 2020–2023 годах; условия Personal ограничены.
- [Godot](../tools/godot.md) — MIT, текстовые сцены, Movie Maker с ровным ритмом кадров (`--write-movie`); на нём Primer делает ролики с 2024 года.
- [Maya](../tools/maya.md) — стандарт персонажной анимации; $2010 в год; для научных схем избыточен.
- [3ds Max](../tools/3ds-max.md) — пакет Autodesk для жёсткого моделирования и визуализации предметов, Arnold в комплекте; только Windows, $255 в месяц или $2010 в год, Indie с лимитом дохода; для нового канала проще Blender.
- [Cascadeur](../tools/cascadeur.md) — анимация персонажей с физикой, автопозой и межкадрием; Free без коммерции, Indie $96 в год при выручке до $100 тыс.; своего рендера ролика нет, вывод в Blender или Unreal.
- [Spline](../tools/spline.md) — браузерный 3D с экспортом видео и MCP; быстро, но потолок качества ниже.
- [Мосты MCP для Blender, Unreal Engine и Cinema 4D](../tools/mcp-bridges.md) — способ дать агенту управлять запущенной программой; официальные мосты у Blender (лаборатория), Unreal 5.8 и Cinema 4D 2026.4, сторонние под MIT; главный риск — выполнение произвольного кода от модели.

Смежные карточки из других классов:

- [Three.js](../tools/three-js.md) — 3D в браузере на WebGL, сцена пишется кодом (класс web-graphics).
- [Babylon.js](../tools/babylonjs.md) — браузерный 3D-движок, альтернатива Three.js (класс web-graphics).
- [PyVista](../tools/pyvista.md) — Python-библиотека для научных 3D-данных (класс simulation).
- [Meshy](../tools/meshy.md) — сервис генерации 3D-моделей нейросетью (класс generative).
- [TRELLIS](../tools/trellis.md) — открытая модель генерации 3D-объектов (класс generative).

## Сравнение

- Потолок качества: Blender (Cycles), Cinema 4D (Redshift), Houdini (Karma), Maya (Arnold) и Unreal Engine дают уровень студийного рендера; Molecular Nodes добавляет его для молекул. 3ds Max (Arnold) на уровне Maya. Cascadeur не рендерит ролик сам, потолок задаёт программа, куда уходит анимация. ElectroMag Nodes наследует качество Blender, но внешний вид линий поля остаётся простым. Godot и Unity достаточны для стилизованной учебной графики (Primer). Grease Pencil — линейная стилизованная графика. Spline слабее: мягкие веб-сцены.
- Трудность для человека: проще всех Spline (часы–дни). Godot, Grease Pencil и Molecular Nodes требуют недель. Blender, Geometry Nodes, Cinema 4D, Unity и Unreal Engine требуют недель–месяцев. Houdini, Maya и 3ds Max — месяцы. Cascadeur и ElectroMag Nodes — недели.
- Трудность для агента: легче всего там, где сцена — текст и запуск из командной строки: Blender (скрипт `bpy`, `blender -b`) и Godot (`.tscn`, `.gd`, `--write-movie`). Molecular Nodes тоже через Python. Cinema 4D, Unreal Engine и Unity дают MCP или CLI для агентов (всё свежее, экспериментальное). Houdini и Maya скриптуются, но граф и риг приходится собирать на ощупь. Spline имеет MCP, но экспорт видео идёт через интерфейс. Cascadeur и 3ds Max скриптуются слабее Blender (в Cascadeur Python внутри программы, в 3ds Max Python 3, оба с окном и лицензией). Мосты MCP для Blender, Unreal Engine и Cinema 4D дают агенту управление запущенной программой, но выполняют код модели без защиты (см. [мосты MCP](../tools/mcp-bridges.md)).
- Автоматизация: выше всех Blender (CLI, `bpy` на PyPI, пакетный рендер); дальше Molecular Nodes, Geometry Nodes, Godot, Houdini (hython, husk), Unreal Engine (командный рендер MRQ). Cinema 4D, Maya, 3ds Max, Cascadeur, Unity, Grease Pencil и Spline автоматизируются частично. ElectroMag Nodes — через Python Blender, как любой Geometry Nodes.
- Стоимость: бесплатны Blender, Geometry Nodes, Grease Pencil, Molecular Nodes и Godot. Unreal Engine бесплатен до $1 млн годового дохода, дальше $1850 за место в год для не-игр. Unity Personal бесплатен, Pro $2310 в год. Spline от $12 в месяц, видео — с Pro ($25–30). Houdini Indie $299 в год. Cinema 4D около $839 в год (по сообщению прессы), Maya $2010 в год, 3ds Max $2010 в год ($255 в месяц). Cascadeur: Free без коммерции, Indie $96 в год, Pro $396 в год. ElectroMag Nodes: Lite $1 и Pro $15 разово (дополнение к Blender). Мосты MCP бесплатны, платите за программу и модель.
- Плавность переходов и непрерывность сцены: лучше всего Blender (одна сцена, одна камера, shape keys, Geometry Nodes), Unreal Engine (Level Sequence с непрерывной камерой) и Godot (Movie Maker даёт идеальный ритм кадров). Cinema 4D силён MoGraph-переходами форм. Grease Pencil держит рисунок в 3D-сцене и дорисовывает линии модификатором Build. Houdini и Molecular Nodes — для непрерывной динамики.

## Вывод для объясняющих видео

Начинать стоит с Blender: бесплатный, управляется кодом и хорошо подходит агенту; он даёт единую сцену с непрерывной камерой, морфинг через Geometry Nodes и рисование линий через Grease Pencil. Для молекул берите Molecular Nodes, для силовых линий и потоков — Geometry Nodes (готовый набор [ElectroMag Nodes](../tools/electromag-nodes.md) за $1–15, если нужны линии поля токов и зарядов), для «рисуется на глазах» — Grease Pencil с модификатором Build (готового публичного примера в научно-популярном ролике не найдено). Godot с Movie Maker стоит рассмотреть как второй путь для симуляций: Primer прошёл Blender (2018–2019), Unity (2020–2023) и Godot (2024–2025). Cinema 4D, Maya и Houdini брать только когда есть бюджет и конкретная причина: выразительная графика, персонажи, физически сложные симуляции. Unreal Engine нужен для кинематографичного света; перед использованием проверьте лицензию, если доход выше $1 млн.
