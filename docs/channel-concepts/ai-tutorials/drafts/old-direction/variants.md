# Три подачи на одной теме

Для Villlerri. 2026-10-17. Подачи пронумерованы 1–3, чтобы не путать с концепциями А–Г из [концепции](concept.md). Все три — для концепции А, на одной теме: пилот «20 чеков бесплатному ИИ без интернета». Отличаются подача, ритм, голос и оформление. У каждой подачи: видеопроба 30–45 секунд из настоящих снимков экрана и макет оформления канала.

Пробы без голоса: голос не синтезировался. Текст диктора идёт субтитрами. Цифры в пробах и макетах — только из [нашего прогона](pilot/example/results.md).

Ограничения проб:
- Кадры экрана сняты 2026-10-17 до сообщения 781, на общем сервере, не на ноутбуке. Новых запусков моделей для проб не было.
- Сервер был подключён к сети. Работа без интернета в пробах не показана; её снимают на ноутбуке для пилота.
- Фразы «without internet» и «offline» в макетах — для будущих видео канала, не о пробе.

## 1. Plain Laptop Lab — испытательный стенд

Макет: [1-plain-laptop-lab.html](mockups/1-plain-laptop-lab.html).

- Позиция: замер. Один вопрос, один набор файлов, один обычный компьютер, счёт в конце.
- Слоган: «Free AI. Ordinary laptop. Every result checked.»
- Кому подходит: тем, кто выбирает, какой бесплатный ИИ поставить, и хочет цифры.
- Визуальная грамматика: настоящий экран в тонкой рамке; сверху полоса паспорта — модель, размер файла, секунды; табло счёта заполняется по ходу; ошибка подчёркивается красным, верное — зелёная галочка.
- Палитра: бумага #F6F5F1, графит #1E1F1C, сетка #D9D6CC, ошибка #E4572E, верно #2E7D4F.
- Шрифты: IBM Plex Sans и IBM Plex Mono для цифр (обе OFL, файлы лицензий проверены в репозитории google/fonts 2026-10-17).
- Переходы: резкие склейки по счёту, «штамп» результата.
- Диктор: спокойный испытатель, сухо, «мы», числа словами просто.
- Структура 10–12 минут: вопрос и обещанный итог (0:00) → паспорт теста (0:30) → шаги на настоящем экране (1:00) → табло (6:00) → разбор каждой ошибки (8:00) → вывод и файлы (10:30).
- Удержание: итог обещан в первые 15 секунд, табло заполняется постепенно, ошибки разбираются по одной.
- Shorts: одна ошибка — один Short: «ИИ сказал X. В чеке Y».
- Компромисс: строго и сухо; новичку без вводных может быть тяжело.

## 2. Checked Offline — делаем вместе

Макет: [2-checked-offline.html](mockups/2-checked-offline.html).

- Позиция: медленный урок для человека без технической подготовки. «Поставьте на паузу и сделайте со мной». У каждого шага — проверка.
- Слоган: «Do it yourself, offline. Check every step.»
- Кому подходит: новичкам, людям старше 50, тем, кто боится «сломать компьютер».
- Визуальная грамматика: настоящий экран во весь кадр; крупное увеличение того места, куда нажать; жёлтый маркер вокруг курсора; плашка «Step 3 of 6»; карточки «Pause here»; список проверки с галочками.
- Палитра: сливки #FFF8EC, тёмно-синий текст #1F2A44, маркер #FFD966, бирюза #2A7F7F.
- Шрифты: Atkinson Hyperlegible для текста и субтитров (сделан Институтом Брайля для читаемости), Fraunces для заголовков. Обе OFL, проверены 2026-10-17.
- Переходы: мягкие наезды на нужную часть экрана, без резких склеек.
- Диктор: тёплый учитель, медленнее обычного, повторяет главное.
- Структура: что будет в конце (0:00) → что нужно (0:40) → 6 шагов, у каждого проверка → что может пойти не так → итог.
- Удержание: зритель делает вместе; каждые 1–2 минуты маленький результат.
- Shorts: один совет за 40 секунд.
- Компромисс: медленно; опытному зрителю скучно; видео длиннее при том же содержании.

## 3. Second Look AI — почему ИИ ошибается

Макет: [3-second-look-ai.html](mockups/3-second-look-ai.html).

- Позиция: сначала понятное объяснение на анимированных схемах, потом доказательство на настоящем экране. Урок о понятии живёт дольше урока по кнопкам.
- Слоган: «See why AI gets it wrong — before it costs you.»
- Кому подходит: тем, кто уже пробовал ИИ и хочет понимать, когда ему не верить.
- Визуальная грамматика: чек нарисован схемой; строки загораются по мере «чтения»; стрелка к выбранной сумме; ловушка подсвечена янтарным; рядом короткая настоящая запись как доказательство.
- Палитра: чернильно-синий #0F1B2D, меловой #F2F4F7, янтарь #FFB000.
- Шрифты: Space Grotesk для заголовков, JetBrains Mono для данных. Обе OFL, проверены 2026-10-17.
- Переходы: схема перетекает в запись экрана и обратно.
- Диктор: любопытный объясняющий, с аналогиями.
- Структура: ошибка-крючок (0:00) → как ИИ читает чек (1:00) → 5 ловушек, у каждой своя схема и запись (2:00–8:00) → как проверить (8:00) → итог.
- Удержание: каждая ловушка — маленькая загадка «найдите ошибку раньше ИИ».
- Shorts: одна ловушка за 45 секунд.
- Компромисс: анимация — самая дорогая часть производства; меньше «сделай сам».

## Рекомендация

Подача 1 как основа, с плашками шагов из подачи 2. Причины:

- В выдаче по локальным моделям наверху — замеры. Подача 1 ближе всего к ним.
- Табло и разбор ошибок — то самое отличие от «установи и поболтай».
- Плашки шагов из подачи 2 снимают главный риск подачи 1: новичок не потеряется.
- Подачу 3 дешевле всего обновлять: урок о понятии устаревает медленно. Но в производстве она дороже всех. Её приём хорош для отдельных выпусков вроде темы 3.

Окончательный выбор — за вами, после просмотра проб и макетов.
