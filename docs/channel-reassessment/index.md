- [evidence.md](evidence.md): реестр доказательств — число, знаменатель, дата, источник у каждого утверждения.
- [method.md](method.md): что прочитано, фильтр, выборка, определения, расчёты, пределы данных.
- [method-code.md](method-code.md): код замера и расчётов.
